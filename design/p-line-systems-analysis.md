## 一、现有系统审计

### 已体现高自由度的设计

| 系统 | 自由度表现 |
|------|-----------|
| 修炼系统 | 无职业锁定，任何玩家均可走纯散修路线，无门派绑定 |
| 反派线（VillainStoryline） | 每个反派提供击败与宽恕两条完整结局路径（Defeated / Redeemed） |
| 反派系统（AntagonistSystem） | 反派有动机、背景、行动节奏，不是纯数值Boss，随时间自动推进 |
| 门派系统（FactionSystem） | 5个门派有独立声望 + 同盟/敌对联动，一荣俱荣一损俱损 |
| 制作系统（CraftingSystem） | 50+配方覆盖R到SSR，多种装备类型和消耗品 |
| 修炼突破 | 带成功率 + 修为倒退惩罚，不是无脑升级 |

### 存在隐性限制的环节

| 限制点 | 问题 | 影响 |
|--------|------|------|
| 主线任务链（MainQuestChain） | 完全线性，mq_01→mq_12锁序，不支持跳过、并行、岔路 | 玩家被按头走剧情，违背"超高自由度"承诺 |
| 门派系统（FactionSystem） | 只有声望增减，无加入/退出/叛门/散修玩法闭环 | 门派只是一组数值，不是"可选择的身份" |
| 装备系统（EquipmentSystem） | 仅3个槽位（武器/防具/饰品），按item.value/10和/15计算加成 | build多样性极低，数值线性无阶梯 |
| 副本入口（DungeonEntrance） | 简单传送+生怪，无难度选择、队伍组建、风险提示前奏 | 副本无"体验弧线"，只是一个战斗房间 |
| 丹药炼器 | 仅有配方面板，无采集→鉴别→炼制→成品的完整链 | 缺少"自己做装备"的沉浸感和成就感 |
| 修炼至渡劫期 | 字符串提示"天劫降临"但无实际渡劫玩法实现 | 修炼系统最高潮阶段缺失 |
| 新区域探索 | 无任何系统支持——无地图迷雾、发现记录、风险评级 | 探索没有"发现感"，就是走到一个坐标 |

## 二、6系统详细设计草案

### 2.1 门派系统

玩家初至灵气大陆可选择入宗或散修。入宗需通过考核任务，获得宗门资源（功法、丹药、洞府、保护）但承担宗门义务（定期任务、贡献指标、站队支持）。退出宗门需经历"叛门"流程——轻则扣除修为、宗门声望清零并成为仇敌，重则触发追杀事件（原宗门派出执法弟子）。散修路线自由度最高，无强制义务但资源获取全靠自主探索，可接散修联盟悬赏任务弥补资源缺口。声望系统支持跨门派周旋——天元宗弟子可暗中帮青云门积累"暗线"，被发现后触发双倍惩罚。核心设计原则是"选择即代价"，每个选择都有可感知的收益与成本。

### 2.2 副本实例

发现副本入口时先触发环境预警（如"此地怨气翻涌，建议筑基以上才可进入"）。靠近入口后不直接传送，而是弹出副本信息面板：推荐境界、已知产出、历史探索记录、首通进度。玩家可选择单人挑战或招募队友（NPC或联机）。进入后副本由动态生成的若干房间序列组成，每层岔路提供非对称选择（宝库房间 / 捷径通道 / Boss房）。最终Boss击败后触发结算——不只是掉落清单，还包括"秘境感悟"（修为加成）和环境反哺（击败Boss后该区域灵气浓度下降、地图永续变化）。支持中途退出保存进度，下次可续关。

### 2.3 BOSS战

遭遇Boss时不是强制锁定战斗状态。先触发Boss出场演出，显示名号、境界和弱点情报（可提前侦察获得）。玩家有四种处理方式：(1)正面战斗——击败得完整掉落+修为；(2)外交谈判——满足Boss需求（如交出特定物品、答应某个条件）换取和平通过；(3)智取规避——利用地形陷阱、环境机关或特殊道具绕过Boss；(4)召唤援军——用传讯符或门派令召唤NPC盟友参战（消耗一次盟友帮助额度）。不同方式影响Boss势力的后续态度：击杀结仇、谈判保持中立、规避无损。战斗外允许撤退，但Boss记仇，下次遭遇时守卫更严密或开场就进入狂暴状态。

### 2.4 渡劫

修炼至渡劫期不再自动触发，而是玩家主动选择去"天劫台"引劫。渡劫分三阶段：雷劫（连续N道天雷轰击，需丹药回血+防御法宝+身法走位）→ 心魔劫（幻境试炼，根据玩家过往抉择生成个性化幻觉，考验道心稳固度）→ 天道问心（一句终极哲学式提问，无标准答案，回答影响渡劫后获得的道体特性）。准备阶段包含：炼制渡劫丹、布置小型防御阵法、请护法道友。渡劫失败不直接死亡——跌回当前境界大圆满并获得"渡劫经验"（下次成功率提升），但修为上限短暂锁定3天。散修全程无人护法，基础失败率+20%，但成功后获得的道体特性更稀有。

### 2.5 丹药炼器

完整体验弧线分为五个阶段：(1)探索感知——玩家运行功法感受天地灵气，高阶灵材需神识探索才能发现位置；(2)采集获取——低阶灵材直接采集，高阶灵材有伴生妖兽守护或需特殊工具（如千年玄冰需寒铁镐）；(3)鉴别分类——未鉴别的材料有"未知药性"属性，可自学鉴定术或付费找NPC鉴定，未鉴定材料炼制时有概率炼废；(4)炼制加工——丹炉操作要求控火（大火/中火/小火）、投放顺序、时机判断，不能一键制作，成品品质分为下品/中品/上品/极品四个档位；(5)使用循环——丹药带"抗性"机制、装备带耐久度，形成使用→消耗→再补给的循环。

### 2.6 新地图

玩家移动至区域边界时触发"前方未知区域"提示并显示预估风险等级。首次踏入新区域触发三阶段体验：(1)发现时刻——屏幕中央浮现区域名称、历史背景简述，解锁"探索者"成就；(2)确认安全——玩家需要寻找安全点（如野外商栈、传送阵）作为据点，据点激活后解锁传送和重生点；(3)深度探索——地图以迷雾形式呈现，只有玩家亲自走过的路径才会清除迷雾。探索深度决定信息完整度：浅探只知地形轮廓和主要道路，深入才能发现隐藏Boss巢穴、特殊产出点和NPC聚落。区域内有"地标"系统（灵气泉眼、远古遗迹残骸、秘境入口），发现地标提供额外经验和区域声望。

## 三、系统依赖关系图

### 文字关系描述

```
门派系统 ─┬─→ 装备系统    门派贡献兑换高阶装备图纸/成品
          ├─→ 丹药炼器    门派丹方库提供独家配方
          ├─→ BOSS战      门派任务链触发专属Boss遭遇
          └─→ 新地图      门派势力范围控制部分区域准入权限

副本实例 ─┬─→ BOSS战      副本终点必有Boss战
          ├─→ 丹药炼器    副本产出稀有灵材和高级材料
          └─→ 新地图      副本入口分布于已探索地图上

BOSS战   ─┬─→ 门派系统    Boss所属势力/阵营影响玩家门派声望
          ├─→ 渡劫         特定Boss掉落渡劫必需材料（如雷劫结晶）
          ├─→ 丹药炼器     Boss掉落稀有材料
          └─→ 装备系统     Boss掉落装备/装备图纸

渡劫     ─┬─→ 丹药炼器     渡劫需要丹药辅助（渡劫丹、回血丹）
          ├─→ BOSS战       心魔劫中的"内心Boss"基于玩家经历生成
          ├─→ 新地图       高级天劫台位于特殊区域需探索发现
          └─→ 修炼系统     渡劫是大境界突破链的终点环节

丹药炼器 ─┬─→ 装备系统     炼器产出可装备品
          ├─→ 渡劫          丹药是渡劫的核心准备工作
          ├─→ 副本实例      副本是高级材料的重要产出源
          └─→ 新地图        不同地图生态产不同灵材种类

新地图   ─┬─→ 副本实例     地图上分布副本入口
          ├─→ 丹药炼器     地图灵材种类构成采集生态
          ├─→ 门派系统     地图上的中立势力/聚落可发展关系
          └─→ BOSS战       地图守护者/区域领主即野外Boss
```

### 核心依赖链

**纵向主线链**（每个玩家必经，无论路线）：
```
新地图探索 → 采集灵材 → 丹药炼器 → 装备强化 → BOSS战 → 获取渡劫材料 → 渡劫
```

**横向社交/选择链**（可选，影响体验方向）：
```
门派系统 ←→ 门派任务 → 门派Boss → 门派装备
散修路线 ←→ 散修联盟悬赏 → 自由探索 → 无绑定奖励
反派交互 ←→ 击败/宽恕选择 → 剧情分支 → 结局分歧
```

**核心设计原则：门派系统横跨所有其他系统提供社交关系 + 任务目标 + 资源倾斜，但不阻断任何纵向链——纯散修玩家可独立走完纵向主线链，无需加入任何门派。**

## 四、数值设计原则

### 4.1 修为（Cultivation）

| 原则 | 规则 | 理由 |
|------|------|------|
| 边际递减 | 境界内层间差距 = 该境基础阈值 + 层数 ×（基础阈值/5） | 越往后升级越难，避免速通 |
| 境界门槛 | 大境界突破需满层 + 修为达标 + 材料/机缘 | 防止纯挂机升级 |
| 失败代价 | 突破失败扣除15%修为，上限锁定3天 | 让"赌突破"有真实焦虑感 |
| 修为纯度 | 嗑药/任务/杀怪的修为来源分别标记，纯度影响突破成功率 | 纯嗑药升上来的修士根基不稳 |

**建议新增"修为纯度"概念**：通过战斗和任务获得的修为纯度100%，嗑药获得的纯度仅50%。纯度影响大境界突破成功率（纯度每低10%，成功率-3%）。

### 4.2 灵石（Spirit Stones）

| 产出渠道 | 稳定性 | 占比预期 |
|----------|--------|---------|
| 任务奖励 | 稳定 | 30% |
| 妖兽掉落 | 中等 | 25% |
| 副本结算 | 高 | 30% |
| 丹药/装备交易 | 波动 | 15% |

**消耗优先级**：丹药（每日最大开支，约40%）→ 装备强化/维修（30%）→ 渡劫材料（20%）→ 其他（10%）。

**通胀控制**：灵石有不可逆消耗通道（装备强化失败消失、传送阵费用、NPC学习费用），确保灵石总量不会无限膨胀。无银行/利息系统。

### 4.3 药力与抗性

同种丹药设独立抗性计数器：
- 第1次服用：效果100%
- 第2次服用：效果70%
- 第3次服用：效果40%
- 第4次服用：效果0%（无效）

抗性自然消退速度：每游戏日 -1 计数（约7天后彻底恢复）。

替代方案：交替服用不同种类丹药可最大化收益。丹药设计上确保每种丹药有不可替代的用途（回血/回蓝/突破/解毒），不会出现"一种最优丹吃到老"的情况。

### 4.4 装备品质梯度

| 品质 | 颜色 | 特性 | 获取方式 |
|------|------|------|---------|
| R | 绿 | 基础属性 | 商店、低级掉落 |
| SR | 蓝 | 基础属性+1条词缀 | 副本、制作 |
| SSR | 紫 | 基础属性+2条词缀+1特效 | BOSS掉落、高阶制作 |
| UR | 金 | 基础属性+3条词缀+2特效 | 唯一Boss、世界事件 |

**关键设计**：SSR以上装备必须带"特效"（如"攻击附带5%吸血""受到致命伤害时保留1血"），不能只有数值碾压。UR装备每个世界仅可存在有限数量（不会烂大街）。

**当前公式问题**：AttackBonus = Weapon.value / 10，DefenseBonus = Armor.value / 15。线性函数导致高价值装备数值爆炸。建议改为**阶梯函数**，例如 value<100 → bonus=value/10，100≤value<500 → bonus=10+(value-100)/20，以此类推。

### 4.5 境界与实力换算

| 大境界 | 基准战力 | 约为前境倍数 |
|--------|---------|-------------|
| 凡人 | 1 | - |
| 练气 | 10 | 10× |
| 筑基 | 30 | 3× |
| 金丹 | 90 | 3× |
| 元婴 | 270 | 3× |
| 化神 | 810 | 3× |
| 渡劫 | 2430 | 3× |
| 大成 | 7290 | 3× |

**战斗规则**：差一个大境界以内（含）可以靠build和操作弥补；差两个大境界以上则人数和策略难以弥补（攻击-防御差距导致伤害几乎为0）。这确保了修真的阶级感，同时避免碾压型玩家破坏低境界区域的体验。

### 4.6 风险-收益比

| 行为 | 风险 | 收益倍数 | 说明 |
|------|------|---------|------|
| 散修渡劫（无人护法） | 失败率+20% | ×1.5 | 高风险高回报 |
| 越级探索（进入高2境区域） | 死亡概率高 | ×2~3 | 快速成长通道 |
| 叛门 | 追杀+声望清零 | 自由+宗门秘藏 | 故事转变资本 |
| 与Boss谈判而非击杀 | 少一份掉落 | 获得盟友+情报 | 长期投资 |
| 纯嗑药修炼 | 纯度低突破难 | 短期快 | 后期代价 |

**核心公式：玩家感知到的收益 / 玩家感知到的风险 ≈ 1.5~2**。确保每个选择在玩家视角看来"值得一试"，但又不是"闭眼选"。
