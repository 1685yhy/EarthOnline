## 一、审计方法

本次审计通过以下方式完成：
1. 扫描 `/Assets` 目录下所有视觉资产文件（.png/.jpg/.fbx/.obj/.glb/.mat/.prefab/.shader）
2. 通过 Unity MCP 读取当前场景层次结构和已加载对象
3. 读取 `design/levels/level-layout-v1.md` 提取设计文档中定义的所有实体
4. 读取 `design/registry/entities.yaml`（当前为空模板）
5. 通过 Unity MCP 检查材质、着色器等资产的具体配置

### 2.4 已有着色器能力

`PostProcess4K.shader` 已实现以下后处理效果，可直接启用：
- Bloom（亮度阈值 + 强度 + 颜色）
- 饱和度调节
- 对比度调节
- 色调过滤（暖色调）
- 暗角（Vignette）
- MotionBlur（参数已声明但未实际应用）

**缺口：** 缺少用于虚空边缘的紫色扭曲变体、境界突破的高光变体。

## 五、生成优先级排序

### 第一阶段：P0 — 必须立刻做（不然核心体验不存在）

玩家在新手村前 10 分钟就会直接触碰这些资产，缺失则无法形成"这是一个修真世界"的基本认知。

| 排序 | 资产 | 类别 | 对应缺口 | 首次遭遇时间 | 影响范围 |
|------|------|------|---------|------------|---------|
| P0-1 | **玩家角色模型 + 纹理** | 角色 | CH-01/02 | 0 分钟 | 核心身份认同 |
| P0-2 | **地面/地形材质纹理** | 环境 | 全部 ENV 间接依赖 | 0 分钟 | 整个世界基础 |
| P0-3 | **5 栋建筑 Prefab** | 场景 | BLD-01~05 | 0~5 分钟 | 新手村视觉锚点 |

## 七、总结与建议

### 7.1 关键数据

| 指标 | 数值 |
|------|------|
| 设计文档定义实体总量 | ~123 |
| 当前已实现视觉资产 | 0 |
| 当前完成率 | 0%（不含后处理基础设施） |
| P0 紧急缺口 | 5 |
| P1 高优先缺口 | 5 |
| P2 中优先缺口 | 8 |
| P3 低优先缺口 | 10 |
| 估算总生成量 | ~150+ 独立美术资产 |
| 达到可玩原型所需 | ~12 个核心资产（P0+P1） |

### 7.2 核心拦路石

1. **缺少玩家角色模型** — 最基本的身份认同缺失，没有"我"的概念
2. **缺少地面纹理** — 整个世界无视觉基础，脚下是灰色 Default 材质
3. **5 栋建筑全部为零** — 新手村从概念上不存在
4. **场景分叉** — 当前 SampleScene 仍是 BlockStack 原型，EarthOnline_Main 场景文件存在但未导入，需要决定统一策略

### 7.3 建议

1. **立即开始 MCP 生成**：从 P0-1（玩家角色模型）开始，每日 2~4 个资产的节奏
2. **先解决场景问题**：决定是复用 SampleScene 还是修复 EarthOnline_Main 的导入问题
3. **材质复用策略**：修真世界可大量使用 Shared Material，所有 NPC 共享 NPC_Mat（更换纹理），减少材质数量
4. **敌人变体策略**：40 种敌人可通过"基础模型 + 纹理/尺寸/粒子变体"实现，实际独立模型约需要 15~20 个基础骨架
5. **注册表初始化**：在生成资产前，补充 entities.yaml 的内容以建立资产-设计映射关系
