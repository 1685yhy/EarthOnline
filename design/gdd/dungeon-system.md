**文档状态：** V1.0 定稿

**日期：** 2026-07-12
**关联项目：** 灵气大陆 P线 第三梯队
**前置系统：** 新地图区域、门派系统、BOSS战系统（部分）、丹药炼器系统

## Chapter 1: Overview

副本实例系统是地球Online灵气大陆的"内容容器"。它为玩家提供有深度、可反复体验的活动空间——不是"重复劳动的换皮刷子"，而是**每次进都可能有不同体验的动态冒险**。

### 核心设计哲学

- **动态难度，不是等级锁区：** 副本根据玩家的境界动态调整敌人强度和掉落品质。低境界玩家进高难度副本不是被秒杀，而是"能够打但需要策略"。
- **岔路选择，不是线性走廊：** 每个副本由多个房间序列组成，岔路口提供非对称选择——宝库 / 捷径 / Boss房 / 隐藏层，玩家每次走的路线可以不同。
- **可反复刷，但有自然限制：** 副本可重复进入，但药抗性、产出递减、首通奖励一次性等机制防止"最优解刷100次"。
- **不支持强制战斗：** 玩家可以选择战斗、潜行绕过、外交谈判、环境利用——不锁死唯一的通关方式。
- **入口体验弧线：** 从发现入口到进入副本之间有一个完整的前奏——预警提示、信息面板、队伍组建、准备确认。不是"走到传送点按E进入"。

### 现有基础

`DungeonEntrance.cs` 当前实现了一个极简入口：靠近3m内按E传送至固定坐标（0, 2f, -25），生成2个固定数据（80HP/12攻击力）的虚空残影敌人。无难度选择、无房间生成、无岔路、无进度保存。

本GDD将在其基础上替换或重构，实现完整的副本实例生命周期。

### 现存问题（本GDD要解决的）

| 问题 | 表现 | 影响 |
|------|------|------|
| 无难度选择 | 固定2个80HP敌人，所有玩家体验一致 | 低境玩家过难，高境玩家无挑战 |
| 无岔路 | 传送后直接到达战斗点 | 没有探索感和可选择空间 |
| 无进度保存 | 退出后重置 | 不支持中长线探索 |
| 只有一个入口 | 硬编码坐标和敌人 | 不可扩展 |
| 强制战斗 | 只有战斗一个方案 | 违背"不强制战斗"原则 |

## Chapter 2: Player Fantasy

### 2.1 秘境探险家幻想

"我在妖兽森林深处发现了一个被藤蔓掩盖的石洞入口。靠近时系统提示：'此地怨气翻涌，建议筑基以上才可进入'。面板显示推荐境界是筑基中期，已知产出有玄铁和培元丹材料。我检查了一下装备——够了，进去。"

### 2.2 岔路抉择幻想

"第一层有三条路：左边是宝库标识（可能有稀有材料，但守卫森严），中间是主通道（直接通向第二层入口），右边有奇怪的灵气波动（可能是隐藏房间）。我选了左边——潜行绕过守卫，偷了三块玄铁，但触发了一个警报机关，第二层的敌人都被惊动了。"

### 2.3 越级挑战幻想

"我是练气期，这个副本推荐筑基。但我不怕——我炼了一堆丹药，还买了隐匿符。我不走主路，全程潜行绕怪，专门搜刮低风险区域。秘境感悟给了一大笔修为——这比在外面打怪快多了。下次我试着引一个筑基怪到陷阱里弄死它……"

### 2.4 重复刷本但每次不同幻想

"这个副本我刷了五次了。第一次走了宝库路线，第二次走了隐藏Boss路线，第三次触发了一个稀有事件（一个路过的游商NPC在副本里卖东西），第四次两个岔路都被封了被迫走主路……每次的掉落也不太一样，没有'最优路线'这回事。"

### 2.5 副本改变世界幻想

"我把黑风洞的Boss打掉了。走出副本后，系统弹出提示：'黑风洞的妖兽失去首领，该区域灵气浓度下降20%，玄铁矿脉产量增加。妖兽残部部分逃离，部分聚集至南侧200米处形成新的小型巢穴。'——我的行为真的改变了这个地图。"

## Chapter 3: Detailed Rules

### 3.1 副本入口与发现

#### 3.1.1 入口类型

| 类型 | 特征 | 示例 |
|------|------|------|
| 固定入口 | 可见的洞穴/建筑入口，常驻存在 | 山洞、遗迹门、传送阵 |
| 隐藏入口 | 需要特殊条件才能发现 | 灵气波动异常处、需要钥匙/道具解锁 |
| 临时入口 | 限定时间内存在或触发后消失 | 门派战后的战场废墟、天灾/异象开启 |
| 门派专属 | 只有特定门派成员可进入 | 门派秘境、传承试炼地 |

#### 3.1.2 发现与预警阶段

玩家首次靠近副本入口（范围 2× 进入距离）时触发三个阶段预警：

1. **环境感知（远距离，范围 ~15m）：**
   - 画面边缘轻微变色/灵气粒子效果
   - 屏幕中央浮现提示文字（如"你感到前方有异样的灵气波动……"）
   - 小地图上出现灰色入口标记

2. **风险提示（中距离，范围 ~8m）：**
   - 弹出一屏提示："【副本名称】—— 推荐境界：[境界名]"
   - 如果玩家境界低于推荐境界，额外显示红色警告
   - 进入前可随时退开，提示自动消退

3. **信息面板（近距离，范围 ~3m）：**
   - 不再直接传送，而是弹出完整副本信息面板（见3.1.3）

#### 3.1.3 副本信息面板

面板包含以下信息（按视觉优先级排列）：

| 信息项 | 说明 |
|--------|------|
| 副本名称 | + 简短描述（一句背景设定） |
| 推荐境界 | 如"筑基中期 ~ 金丹初期" |
| 已知产出 | 列出可获得的物品类型（非精确清单） |
| 历史探索记录 | 全服统计：进入次数/通关次数/平均用时 |
| 首通进度 | 是否已有首通记录 + 首通者名字 |
| 环境特性 | 如"此区域禁止飞行""受重伤后自动传送出本" |
| 建议队伍 | 单人/推荐组队人数 |

#### 3.1.4 进入选择

面板下方提供选项：

- **单人挑战** —— 实例只属于该玩家
- **招募队友** —— 可邀请NPC盟友（消耗盟友额度）或联机玩家
- **观看来路** —— 播放一小段剧情演出（首次进入时强制，之后可选跳过）
- **暂离** —— 离开入口范围，面板关闭

选择"单人挑战"或"招募队友"后，进入队伍确认阶段（3.2）。

### 3.2 队伍组建

#### 3.2.1 单人模式
- 直接进入，无需等待
- 副本参数按单人难度调整（怪物数量减少、Boss血量降低）

#### 3.2.2 NPC队友

玩家可消耗"盟友额度"邀请最多2名NPC队友：

| NPC来源 | 消耗 | 说明 |
|---------|------|------|
| 门派同门 | 门派贡献 30 | 需要加入门派，消耗贡献 |
| 散修联盟盟友 | 灵石 200 | 不限身份 |
| 已结识的剧情NPC | 友好度 10 | 需先完成相关支线任务 |
| 雇佣兵 | 灵石 500 或 物品 | 中立NPC，无消耗但有忠诚度 |

NPC队友在副本中的行为：
- 自动跟随玩家
- 低智能（不主动探路、不开机关）
- 战斗时自动攻击最近的敌人
- 死亡后不可复活，战斗结算时减少奖励系数

#### 3.2.3 联机队友

- 联机模式下最多允许4名玩家组队
- 副本掉落全员独立（每人一份掉落池）
- Boss击杀经验全员平分
- 队内伤害免伤（不触发友伤）

### 3.3 副本内部结构

#### 3.3.1 房间序列生成

副本由若干"房间"通过"连接通道"组成序列。房间布局在玩家进入时根据**种子算法**动态生成：

```
入口房间 → 岔路1 → [房A(战斗) | 房B(宝库) | 房C(隐藏)]
                        ↘ 连接通道 ↘
                            汇合房间 → 岔路2 → ... → Boss房间
```

**每次进入的种子不同**，因此岔路位置、房间类型、敌人配置都会变化。

#### 3.3.2 房间类型

| 类型 | 标签 | 内容 | 特点 |
|------|------|------|------|
| 战斗房 | 剑图标 | 1~3波怪物 | 可战斗，也可潜行绕过 |
| 宝库房 | 宝箱图标 | 若干宝箱（需要开锁/解谜） | 可能有守卫或陷阱 |
| 解谜房 | 齿轮图标 | 需完成一个机关谜题才能通过 | 无战斗，但有时间限制 |
| 休息房 | 篝火图标 | 安全区域，可回血/存档 | 100%出现一次，位置不固定 |
| 隐藏房 | 问号图标 | 特殊内容（商人/奇遇/Boss） | 不在常规岔路中，需特定条件触发 |
| Boss房 | 骷髅图标 | 最终Boss战斗 | 击败后副本通关 |

#### 3.3.3 岔路选择

每个岔路口提供2~3个选择，每个选择有明确的标签和视觉标识：

- **主路（剑标识）：** 通向下一层入口，敌人标准数量
- **支路A（宝箱标识）：** 资源路线，宝箱多但战斗更多
- **支路B（问号标识）：** 未知路线，可能是捷径（少战斗）也可能是陷阱
- **Boss路（骷髅标识）：** 直接通向Boss房（跳过中间层，但无积累准备）

岔路的数量 = `2 + floor(随机值 × 2)`，最少2条，最多3条（加上Boss直通路可达4条）。

#### 3.3.4 副本层数

副本按"深度"分层，标准配置3~5层：

- **层数决定难度递增系数：** 每层敌人属性提升 10%
- **每层末尾必有岔路**（最后一层只有Boss房）
- **第1~2层**有休息房（至少1个）
- **第3层及以上**可能需要Boss钥匙（击杀特定小怪掉落）

### 3.4 动态难度系统

#### 3.4.1 难度适配规则

副本的基础参数根据以下因素动态调整：

```
副本难度评级 = 玩家境界等级 × 副本难度系数 + 队伍人数加成

副本难度系数（可配置）：
  简单 = 0.7
  普通 = 1.0
  困难 = 1.4
  噩梦 = 1.8

队伍人数加成：每多1名玩家 +0.1
```

**敌人属性 = 基础属性 × 副本难度评级**

#### 3.4.2 难度选择机制

玩家在进入前的信息面板上可选择难度等级：

| 难度 | 推荐 | 敌人强度 | 掉落倍率 | 说明 |
|------|------|---------|---------|------|
| 简单 | 低于推荐境界 | 0.7× | 0.8× | 适合练手或采集资源 |
| 普通 | 匹配推荐境界 | 1.0× | 1.0× | 标准体验 |
| 困难 | 高于推荐境界 | 1.4× | 1.5× | 挑战向，掉落更好 |
| 噩梦 | 远高于推荐境界 | 1.8× | 2.0× | 极难，顶级掉落 |

**特殊规则：**
- 选择"困难"或"噩梦"时，副本还可能触发额外机制（如随机禁魔区域、反伤光环）
- "噩梦"难度有概率掉落副本专属UR级材料或图纸
- 难度选择不影响副本的任务目标（完成简单难度也算通关）

#### 3.4.3 动态事件

除了难度系数，副本内还会随机触发动态事件（独立于种子生成）：

| 事件 | 触发概率 | 效果 |
|------|---------|------|
| 妖兽暴动 | 15% | 某一房间怪量 × 2，但掉落 +50% |
| 灵气潮汐 | 10% | 所有技能冷却 -30%，持续30秒 |
| 地脉不稳 | 10% | 部分房间地形变化（新的通道/堵塞） |
| 游商NPC | 5% | 副本内出现商人，可购买特殊物品 |
| 陷阱区 | 20% | 下一个房间布满陷阱，通过后额外宝箱 |
| 世界Boss乱入 | 2% | 该副本的最终Boss被一个世界Boss取代（超高难+超高奖） |

### 3.5 战斗与非战斗路径

#### 3.5.1 潜行绕过

- 每个战斗房提供潜行路径（需要隐匿技能 >= 门槛值）
- 潜行成功：不触发战斗，获得少量探索经验
- 潜行失败：进入战斗，但敌人首次反应延迟2秒
- 潜行消耗：耐力或隐匿符

#### 3.5.2 外交/谈判

- 特定房间（如"智慧守卫"类型）可与之谈判：
  - 交出特定物品（灵石/材料）换取安全通过
  - 回答守卫的问题（正确答案可免费通过）
  - 展示门派身份（特定门派成员可免战）
- 谈判失败：进入战斗，且敌人获得"被激怒"buff（攻击+15%）

#### 3.5.3 环境利用

- 每个副本有环境特性，玩家可利用：
  - 引怪至陷阱（如落石、火焰喷射）
  - 破坏承重柱让天花板坍塌（一次性秒杀区域怪物）
  - 利用地形优势卡位（狭窄通道一夫当关）
- 环境利用成功：不消耗玩家资源，但环境破坏后会改变副本地形（后续玩家路过时有所不同）

#### 3.5.4 撤退

- 玩家可在任何时候（非战斗状态）选择撤回副本入口
- 撤退条件：找到一个**安全出口点**（通常是已走过的休息房或入口房间）
- 撤退后副本进度保存（见3.7进度保存）
- 战斗中不可撤退（除非使用特定道具如"遁地符"）

### 3.6 Boss战与结算

#### 3.6.1 Boss战前奏

到达Boss房间前触发：

1. Boss出场演出（播放一段预设动画或特效）
2. 显示Boss信息：名号、境界、已知弱点（根据玩家情报收集程度）
3. 选择交互方式（见BOSS战系统GDD的四种方式）

#### 3.6.2 结算内容

击败Boss后触发完整结算面板：

| 结算项 | 说明 |
|--------|------|
| 掉落清单 | BOSS掉落物（品质、数量、图表展示） |
| 秘境感悟 | 固定修为加成（按难度×系数） |
| 首通奖励 | 首次通关该副本的额外奖励（一次性） |
| 评价等级 | 基于全程表现（用时 / 击杀数 / 死亡次数 / 探索率）的评级 |
| 限时奖励 | 特定时间内的通关额外奖励 |

#### 3.6.3 环境反哺

每次通关副本后，该副本所在的**地图区域**发生永久性变化：

| 变化类型 | 概率 | 说明 |
|---------|------|------|
| 灵气浓度下降 | 100% | 击败Boss后该区域灵气 -20%（持续7天后逐渐恢复） |
| 产出变化 | 50% | 某类材料产率改变（根据Boss类型决定增加/减少） |
| 怪物生态 | 60% | 部分小怪刷新率降低，或出现新的怪物类型 |
| 入口状态 | 30% | 副本入口的外观变化（如藤蔓恢复 / 石门关闭） |

这些变化是**地图全局可见**的——其他玩家也会看到入口的变化。这强化了"玩家行为改变世界"的沉浸感。

### 3.7 进度保存与续关

#### 3.7.1 自动保存点

- 每个休息房触发一次自动保存
- 岔路口选择后触发一次保存（防止玩家sl刷掉落）
- 保存内容包括：当前层数、已消灭的敌人ID列表（死亡的不再重生）、已开启的宝箱、当前位置

#### 3.7.2 手动退出与续关

- 玩家可在休息房选择"保存并退出"
- 退出后副本实例保留 **48小时**（现实时间）
- 48小时内再次进入该副本入口可续关（选择"继续上次进度"）
- 超过48小时或玩家通关后，实例销毁
- 续关后所有玩家的位置在休息房

#### 3.7.3 产出递减机制（防刷）

| 同副本进入次数（连续7天内） | 掉落倍率 |
|---------------------------|---------|
| 1 ~ 3 次 | 100% |
| 4 ~ 5 次 | 70% |
| 6 ~ 7 次 | 40% |
| 8次以上 | 10%（仅保底掉落） |

- **计数器每7天重置一次**
- **首通奖励不受递减影响**（一次性）
- 如果玩家通关后不结算（直接退出），不计入次数
- 产出递减每次进入副本时检查，不是按结算次数

## Chapter 4: Formulas

### 4.1 房间生成算法（种子）

```
副本种子 = GetDeterministicSeed(playerId, dungeonId, date)
房间序列 = GenerateRoomSequence(seed, layerCount)

岔路口选择数 = 2 + random(seed, layerId) % 2  // 2~3个选择
```

种子算法保证：同一副本在同一天内同一玩家进入的seed相同（可续关），但每天不同，不同玩家更不同。

### 4.2 动态难度公式

```
敌人基础属性 = EnemiesConfig[dungeonId][layerId]

难度系数 = 玩家境界等级 × 选择难度系数 + 队伍人数 × 0.1

敌人最终属性 = 敌人基础属性 × 难度系数

境界等级映射：
  练气 = 1    筑基 = 2   金丹 = 3   元婴 = 4
  化神 = 5    渡劫 = 6   大成 = 7

选择难度系数：
  简单 = 0.7    普通 = 1.0    困难 = 1.4    噩梦 = 1.8
```

### 4.3 掉落品质公式

```
掉落品质 = 基础品质 + 难度修正 + 随机波动

基础品质（按房间类型）：
  小怪掉落:   R ~ SR
  精英怪:     SR ~ SSR
  Boss掉落:   SSR ~ UR
  宝箱（普通）: R ~ SR
  宝箱（精英）: SR ~ SSR
  秘境感悟:   修为 × (1 + 难度系数 × 0.5)

难度修正（品质提升概率）：
  简单:  0%
  普通:  +10% 概率提升一档
  困难:  +25% 概率提升一档
  噩梦:  +40% 概率提升一档 + 5% 概率跃升两档
```

### 4.4 秘境感悟修为公式

```
秘境感悟修为 = 基础修为 × 难度系数 × 探索率系数

基础修为 = dungeonId 对应的固定值（按推荐境界范围配置）

探索率系数 = 0.5 + 已探索房间数 / 总房间数 × 0.5

探索率系数范围：0.5 ~ 1.0（全探索则满收益）
```

### 4.5 通关评价公式

```
评价得分 = 时间得分 + 击杀得分 + 探索得分 - 死亡扣分

时间得分 = max(0, 基础时间限制 - 实际用时) × 5
击杀得分 = 击杀敌人数量 × 2
探索得分 = 已探索房间数 × 10
死亡扣分 = 死亡次数 × 30

评价等级：
  S: 得分 >= 200  → 额外掉落 + 称号
  A: 得分 >= 150  → 额外掉落
  B: 得分 >= 100  → 标准结算
  C: 得分 >= 50   → 标准结算 -10%
  D: 得分 < 50    → 标准结算 -30%
```

### 4.6 NPC队友成本公式

```
招募单价 = 基础费用 × (1 + 招募次数 × 0.2 - 友好度折扣)

基础费用：
  门派同门:      30 贡献
  散修联盟盟友:  200 灵石
  剧情NPC:       10 友好度
  雇佣兵:        500 灵石

招募次数：同一NPC本月内的招募次数（每周刷新）
友好度折扣：每10点友好度 -5%（上限 -30%）
```

## Chapter 5: Edge Cases

### 5.1 所有队友死亡（单人模式）

- 玩家本人死亡 → 触发"濒死"状态，10秒内可使用丹药回血
- 10秒内未回血 → 副本失败
- 副本失败：传送至副本入口，掉落50%已获得的未绑定物品（Boss掉落未拾取的不损失）
- 可消耗"替身法宝"复活一次（一次性道具）

### 5.2 所有队友死亡（组队模式）

- 当所有玩家死亡时，副本失败
- 已结算给各玩家的独立掉落保留
- 可用队长道具"还魂丹"全员复活一次（消耗品）

### 5.3 资源消耗枯竭

- 玩家在副本内用尽丹药且无回血手段 → 可消耗灵石通过"传送阵"提前退出
- 传送阵位于每个休息房内
- 退出后副本进度保存，但传送退出记为"未通关"，不计入通关评价

### 5.4 退出后45秒内重新进入

- 为防止SL刷怪/刷掉落，退出后短时间内重新进入会被强制使用同一个seed
- 前一个实例未销毁（仍在48小时内）时，自动续关而非新开

### 5.5 副本被其他玩家清空

- 副本实例是**每个玩家/队伍独立**的，其他玩家清空不影响自己的实例
- 但地图层面的环境反哺是全局共享的——如果其他队伍先清除了Boss，该地图区域的灵气浓度已经下降了
- 灵气浓度下降不影响副本内部的难度，只影响地图上的采集效率和战斗

### 5.6 副本入口被破坏

- 某些特殊事件（如天灾、大型BOSS战）可能物理破坏副本入口
- 入口被破坏后，该副本不可进入，直到7天后入口恢复
- 正在副本内的玩家不受影响（出口仍可用）
- 入口恢复后种子重置，房间布局重新随机

### 5.7 退出时Boss正在被攻击

- 当玩家在Boss战中时，不可保存退出
- 只有脱离战斗状态后才可保存退出
- 离线/断线：重新上线后从最后一个休息房复活，Boss满血重置

### 5.8 不同境界玩家组队

- 动态难度以队伍中**最高境界的成员**为准
- 低境队友在高难副本中会承受额外的压力（怪物等级超标）
- 低境队友可获得额外经验补偿（越级挑战经验加成）

## Chapter 8: Acceptance Criteria

### AC-1：副本入口与信息面板

- [ ] 玩家靠近副本入口时依次触发三个阶段（环境感知/风险提示/信息面板）
- [ ] 信息面板包含副本名称、推荐境界、已知产出、历史记录等完整信息
- [ ] 玩家可选择"单人挑战""招募队友"或"暂离"
- [ ] 隐藏入口需要特定条件才能触发发现

### AC-2：动态难度

- [ ] 进入前可选择4个难度等级（简单/普通/困难/噩梦）
- [ ] 不同难度的敌人属性按公式动态调整
- [ ] 困难以上难度会触发额外机制
- [ ] 动态难度影响掉落品质倍率

### AC-3：岔路与房间类型

- [ ] 每次进入副本的房间布局和岔路不同（种子算法驱动）
- [ ] 至少6种房间类型（战斗/宝库/解谜/休息/隐藏/Boss）
- [ ] 每个岔路口至少2~3个选择，每个选择有明确的标签和视觉标识
- [ ] 隐藏房间需要特定条件触发

### AC-4：非战斗路径

- [ ] 战斗房可潜行绕过（需要隐匿技能门槛）
- [ ] 特定房间可外交谈判（消耗物品/回答问题/展示身份）
- [ ] 环境利用机制可用（陷阱/落石等一次性环境杀）
- [ ] 非战斗状态可随时撤退

### AC-5：Boss战与结算

- [ ] 到达Boss房前触发演出和情报显示
- [ ] 结算面板包含掉落清单、秘境感悟、评价等级
- [ ] 通关后环境反哺触发（灵气浓度变化/产出变化/入口外观变化）
- [ ] 评价等级影响额外奖励

### AC-6：进度保存与续关

- [ ] 休息房自动保存进度
- [ ] 退出后48小时内可续关
- [ ] 续关后从休息房继续
- [ ] 死亡后触发濒死状态，10秒内可用丹药回血

### AC-7：队伍系统

- [ ] 单人模式自动调整难度（怪物数量减少）
- [ ] NPC队友可通过消耗门派贡献/灵石/友好度招募
- [ ] 联机模式最多4人，掉落独立，经验平分
- [ ] NPC队友死亡后不可复活，影响奖励系数

### AC-8：产出递减防刷

- [ ] 连续进入同副本7天内触发产出递减
- [ ] 递减到最低10%后不再降低
- [ ] 7天后计数器重置
- [ ] 首通奖励不受递减影响

### AC-9：边缘情况

- [ ] 所有队友死亡后触发副本失败机制
- [ ] 退出后短时间重新进入强制使用同一种子
- [ ] 副本入口被破坏后7天恢复
- [ ] 不同境界玩家组队以最高境界为准
