## 1. Overview

丹药炼器系统（Alchemy & Crafting System）是地球Online的核心行为层——它定义了玩家"在世界上做什么"。本系统将现有的扁平配方系统（有材料→点制造→得物品）重构为一条完整的五阶段体验弧线：**探索感知 → 采集获取 → 鉴别分类 → 炼制加工 → 使用循环**。玩家不再是在菜单中点一个按钮就造出物品，而是需要亲身去寻找灵材、辨别药性、控火操作、以及承受丹药的抗性衰减。每一个成品都有来历——不仅是一个数值道具，而是一段故事。从修真界的根基——打坐修炼用的丹药、探险用的装备，到渡劫用的天材地宝——都由这个系统产出。系统同时支撑起灵石经济循环：采集→加工→出售→购买材料再采集，形成可持续的玩家驱动经济。

## 2. Player Fantasy

**"我亲手做出了改变命运的东西"——从采集到炼制的完整拥有感。**

玩家的核心幻想是：这颗丹药不是系统给的，是我在暴雨中攀上绝壁采到了千年灵芝，在丹炉前守了三个时辰控火，中间炸了一次炉损失了一半材料，最后出炉的那一刻——炉盖掀开，紫气升腾——上品丹药成了。那一刻的成就感不是一个掉落面板能给予的。

### 2.1 具体时刻

**采集的惊喜**：运行功法感知天地灵气，突然在岩石缝隙中发现一株发光的灵草——不是地图标记告诉你的，是你自己"看见"的。你蹲下来小心翼翼地采集，可能还要跟守护妖兽打一架。这一刻，这个世界是真的有"藏起来的宝藏"。

**鉴别的悬念**：采到一株未鉴定的草药，不知道它的真实药性。找人鉴定可能暴露宝物位置、引来觊觎；自己试药可能中毒或浪费材料——这是一个真实的选择困境，没有正确答案。

**炼制的紧张**：丹炉点火后，你需要控制火候——大火、中火、小火的切换时机直接影响丹药品质。投入灵材的顺序也有讲究。屏幕上的温度条、药液的颜色、升起的烟雾——都在给你反馈。误判一步，整炉材料化为灰烬。这是"指尖上的赌博"。

**成品的狂喜**：当"上品"两个字弹出，伴随着特殊的音效和特效——你知道这不是运气，是你在前面的所有决定（在哪里采的材料、鉴定的准确性、控火的节奏）共同作用的结果。这不是系统随机数送你的，是你亲手挣来的。

**传承的厚重**：锻造一把剑不只是放材料进去——你放入的每一份材料都有自己的故事（来自 ItemDatabase）。当你拿起成品时，你能感受到它的来历。这把"断水"剑不仅仅是攻击+10的装备——它是王铁柱的心血，是你继承了他的技艺。

**越级炼制的冒险**：你的炼丹等级还不够炼制高阶丹药，但你冒险尝试了——使用高阶丹炉、稀有材料、赌上全部身家。成功了是跨越式的飞跃，失败了倾家荡产。这种赌博式的心跳是系统最吸引人的部分。

### 2.2 幻想关键词

| 关键词 | 对应的玩家体验 |
|--------|--------------|
| 发现 | 自己"看见"灵材，而非被地图标记指引 |
| 鉴别 | 未知药性带来的悬念和选择困境 |
| 操控 | 火候、投料顺序、淬火时机——指尖的精细操作 |
| 赌博 | 每一次高品质炼制都是一场与概率的博弈 |
| 拥有 | "我做的"带来的远高于"我捡的"的成就感 |
| 传承 | 每一件装备背后有故事，有温度 |
| 经济 | 采集→加工→交易构成自洽的玩家经济循环 |

## 3. Detailed Rules

### 3.1 五阶段体验弧线

```
探索感知 → 采集获取 → 鉴别分类 → 炼制加工 → 使用循环
     ↑                                          │
     └──────────────────────────────────────────┘
              产出再利用/资源回收
```

### 3.2 阶段一：探索感知（Perception）

玩家通过运行功法（"神识探查"）来感知周围的灵材，而非依靠UI标记。

**感知规则：**
- 基础感知范围：`PerceptionRadius = 10m + 玩家境界系数 × 5m`
- 普通灵材在感知范围内自动显示为"灵气光点"（绿色光晕）
- 稀有灵材需要主动使用"神识探查"技能才能发现（消耗少量灵力）
- 极高品阶灵材需要特定境界或特殊道具（"天眼神通"）才能感知
- 已发现的灵材会短暂标记在迷你地图上（存在标记上限，旧的会被新的覆盖）
- 环境干扰：在灵气混乱区域（战场、魔气区域）感知范围缩小至1/3

**灵材能级与感知表现：**

| 能级 | 感知表现 | 发现难度 |
|------|---------|---------|
| 低级 | 微弱绿色光点，容易忽略 | 低（被动感知可见） |
| 中级 | 稳定绿色光晕 | 低（被动感知可见） |
| 高级 | 强烈绿光，带有"灵气脉动"动画 | 中（需主动感知） |
| 天材地宝 | 冲天光柱，区域可见 | 低（但会有其他玩家竞争） |

### 3.3 阶段二：采集获取（Gathering）

发现灵材后，玩家需要执行采集操作。

**基础采集规则：**
- 普通灵材：靠近按F采集，无需工具，无失败风险
- 高级灵材：需要特定工具，采集有进度条（可被打断）
- 伴生守护：高级灵材通常有妖兽守护，需先击败或引开
- 采集消耗：每次采集消耗少量体力值（体力归零时无法采集）
- 采集冷却：同一个灵材点采集后进入刷新倒计时

**工具-灵材匹配表：**

| 灵材类型 | 需要工具 | 无工具后果 |
|---------|---------|-----------|
| 草本类（草药、灵花） | 玉锄头 | 采集速度-50%，损伤概率+30% |
| 木本类（灵木、树皮） | 采木锯 | 无法采集或采集量减半 |
| 矿物类（矿石、结晶） | 寒铁镐 | 无法采集 |
| 液体类（灵泉、露水） | 玉瓶 | 无容器则无法采集 |
| 特殊类（兽骨、龙鳞、古物） | 无（直接拾取） | — |

**工具品质梯度：**

| 品质 | 效果加成 | 获取方式 |
|------|---------|---------|
| 基础 | 无加成 | 商店购买（低价） |
| 精良 | 采集速度+30%，暴击率+5% | 副本掉落、炼制 |
| 传说 | 速度+60%，暴击率+15%，稀有产出率+10% | BOSS掉落、高级炼制 |

**采集判定逻辑：**
```
GatherSuccess = 基础成功率(0.9) + 工具品质加成 + 熟练度加成 - 采集难度系数
```
- `GatherSuccess < 0` 时不可采集（需要升级工具或提升境界）
- 成功：获得正常数量，可能有额外暴击产出
- 失败：获得一半数量或一无所获（根据资源点类型）
- 大成功（暴击）：获得双倍数量或额外稀有掉落

### 3.4 阶段三：鉴别分类（Identification）

采集到的灵材可能处于"未鉴定"状态。

**未鉴定状态：**
- 未鉴定灵材的属性面板显示为"未知药性 / 未知用途"
- 无法直接作为炼器材料使用（系统提示"材料属性未知，无法投入"）
- 但可以冒险直接使用（"试药"），后果未知

**鉴定方式对比：**

| 方式 | 成功率 | 费用 | 风险 |
|------|--------|------|------|
| 自学鉴定术 | 公式计算 | 消耗灵力 | 失败时损失灵材 |
| NPC鉴定 | 100% | 灵石 | 信息泄露可能 |
| 试药鉴定 | 无（直接出效果） | 消耗灵材 | 中毒/反噬 |

**自学鉴定：**
```
IdentifyChance = 0.5 + 炼药等级 × 0.003 + 鉴定工具加成 - 灵材鉴定难度
```

- 成功：灵材完整属性解锁
- 失败：灵材消失（消耗了），获得少量经验

**NPC鉴定：**
- 固定费用（`BaseCost = 50 灵石 × 灵材品阶系数`）
- 100%成功
- 有概率泄露信息（`LeakChance = 0.2`）：NPC可能告知其他玩家或势力该灵材的位置信息
- 泄露后可能引发：其他玩家前来抢夺、势力派人"保护"该资源点

**试药鉴定：**
- 直接使用未鉴定灵材
- 效果完全随机——可能是正面（发现新药性）、负面（中毒 debuff）、或平淡（无效果，但灵材消耗）
- 试药结果记录在玩家的"药性笔记"中（永久记录，可供后续参考）

### 3.5 阶段四：炼制加工（Processing）

本系统的核心环节，分为**炼丹（丹炉）**和**炼器（炼器台）**两个子分支。

#### 3.5.1 通用规则

- 需要相应设备（丹炉 / 熔炉 / 炼器台 / 铁砧 / 淬火池）
- 设备品质影响炼制成功率和成品品质上限
- 每次炼制消耗材料，投入后不可撤回
- 炼制结果受多个变量影响

**设备类型与其功能：**

| 设备 | 用途 | 品质影响 | 耐久消耗/次 |
|------|------|---------|------------|
| 丹炉 | 炼丹 | 品质上限+炸炉概率 | 1-5 |
| 熔炉 | 熔炼矿石 | 熔炼温度+纯度 | 2-8 |
| 铁砧 | 塑形装备 | 塑形精度 | 0.5-1 |
| 淬火池 | 淬火处理 | 淬火效果 | 1-3 |
| 炼器台（开光） | 灵力注入 | 灵力传导效率 | 2-4 |

**设备耐久：**
- 每台设备有最大耐久度（100-1000不等）
- 每次使用消耗耐久度
- 耐久归零时设备损坏，无法使用
- 可维修：消耗材料 + 灵石，恢复耐久度
- 设备维修需要有"炼器基础"技能或找NPC维修

#### 3.5.2 炼丹子规则

**控火系统：**

三档火候及其特性：

| 火候 | 升温速率 | 作用 | 风险 |
|------|---------|------|------|
| 大火 | +8°C/秒 | 快速激发药性，适合沸腾期 | Overheat累积，易炸炉 |
| 中火 | +2°C/秒 | 稳定融合，适合融合期 | 均衡，低风险 |
| 小火 | -1°C/秒 | 缓慢提纯，适合提纯期 | 过度冷却导致药性不足 |

**炼制四阶段（按时间推进）：**

1. **沸腾期（开始后0-10秒）**
   - 最佳火候：大火
   - 目的：快速加热激发灵材的药性
   - 错误后果：中火/小火导致药性激发不充分（品质-0.1）

2. **融合期（10-30秒）**
   - 最佳火候：中火
   - 目的：让不同灵材的药性融合
   - 错误后果：大火过度导致药性相互冲突，小火融合不充分

3. **提纯期（30-45秒）**
   - 最佳火候：小火
   - 目的：去除杂质，提升纯度
   - 错误后果：大火烧毁提纯中的精华

4. **收丹期（最后5秒）**
   - 火候根据丹药类型决定（配方指定）
   - 错误后果：收丹期失误会导致之前的所有努力降级一档

**投料顺序：**
- 配方明确标注了材料的推荐投放顺序（"先主药→再辅药→最后药引"）
- 完全按顺序投放：OrderScore = 1.0（不影响品质）
- 顺序错误：每错一次 OrderScore -= 0.15
- 完全不按顺序：可能触发"变异炼制"（见变异系统）

**炸炉系统：**

炸炉触发条件：`ExplosionChance > Random.Range(0,1)`

```
ExplosionChance = 0.05 × OverheatFactor × EquipmentHealthFactor

OverheatFactor = 1.0 + 连续大火秒数 × 0.1
EquipmentHealthFactor = 1.0 + (1 - 当前耐久/最大耐久) × 0.5
```

炸炉效果：
- 投入材料损失 50-100%
- 丹炉耐久度 -20~50
- 玩家受到爆炸伤害（`Damage = 炉温 × 0.5`）
- 概率产生"废渣"（可回收少量通用材料）
- 范围3-8m内其他玩家受到溅射伤害

**丹药品质判定：**

```
FinalQuality = BaseQuality × TemperatureScore × OrderScore × MaterialScore × EquipmentModifier
```

| FinalQuality | 品质 | 效果倍率 | 额外特性 |
|-------------|------|---------|---------|
| < 0.4 | 失败（炸炉或废渣） | — | 回收少量材料 |
| 0.4 ~ 0.6 | 下品 | 50%-70% | 无 |
| 0.6 ~ 0.8 | 中品 | 80%-100% | 无 |
| 0.8 ~ 0.95 | 上品 | 110%-130% | 无 |
| ≥ 0.95 | 极品 | 140%-160% | 额外特效（丹药专属） |

#### 3.5.3 炼器子规则

**炼器四步流程：**

```
熔炼 → 塑形 → 淬火 → 开光
```

**第一步：熔炼**
- 将矿石/材料投入熔炉
- 控制熔炼温度（过高浪费燃料、过低熔化不充分）
- 温度不足：材料纯度损失（`MeltEfficiency = 0.5~0.8`）
- 温度过高：燃料过快消耗（额外花费）
- 熔炼耗时：10-30秒（根据材料类型）

**第二步：塑形**
- 将熔液倒入模具，用灵力锤击塑形
- 出现力度条（类QTE机制）——需在绿色区域按下
- 完美击中：塑形精度+1
- 普通击中：塑形精度+0.5
- 未击中（力度条跑出范围）：塑形精度-0.3
- 塑形精度累计影响最终品质

**第三步：淬火**
- 将成型器具浸入淬火液
- 淬火液类型决定附加属性：

| 淬火液 | 附加属性 | 获取方式 |
|--------|---------|---------|
| 普通水 | 无（基础） | 随处可取 |
| 灵泉 | 灵力亲和+5% | 灵气泉眼采集 |
| 妖兽血 | 攻击力+5% | 妖兽掉落 |
| 龙血 | 攻击力+15%、抗性+10% | 龙系BOSS掉落 |
| 冥河水 | 暗属性+10%、附带腐蚀效果 | 特殊区域采集 |
| 星辰露 | 全属性+5%、额外词缀概率+10% | 天象事件采集 |

- 淬火时间（浸泡时长）影响效果：
  - 过短（<3秒）：淬火不完全，效果-50%
  - 理想（3-8秒）：完整淬火效果
  - 过长（>15秒）：过淬，装备变脆（耐久度上限-10%）

**第四步：开光**
- 最后一步，向装备注入灵力使其"活"过来
- 灵力注入量决定装备的灵力亲和度（影响装备特效触发概率）
- 注入量由玩家当前灵力值和等级决定
- 开光时机影响：
  - 在灵气浓郁的地点开光：额外+5%~15%
  - 在天象事件（流星雨、灵气潮汐）期间开光：额外+10%~30%
  - 在魔气污染区域开光：可能给装备附加负面属性

**装备品质判定：**

```
EquipmentQuality = CraftingScore / 100

CraftingScore = MeltScore × 0.2 + ShapeScore × 0.2 + QuenchScore × 0.3 + AwakenScore × 0.3
```

| EquipmentQuality | 品质 | 词缀数 | 特效数 |
|----------------|------|--------|--------|
| < 0.5 | R | 0 | 0 |
| 0.5 ~ 0.75 | SR | 1条 | 0 |
| 0.75 ~ 0.92 | SSR | 2条 | 1个 |
| ≥ 0.92 | UR | 3条 | 2个 |

#### 3.5.4 变异系统（Optional Rule）

当玩家不按标准配方操作时，可能触发变异：

**触发条件（满足任一）:**
- 投料顺序与标准配方完全不同（反序或随机）
- 加入了配方未列出的额外材料
- 在特殊天象期间炼制（血月、流星雨、日食）
- 在特殊地点炼制（灵气泉眼中心、古战场遗址）
- 使用非标准设备

**变异结果：**

| 变异类型 | 触发概率 | 结果 |
|---------|---------|------|
| 普通变异 | 0.15 | 产出与标准配方不同的物品（全新丹药/装备） |
| 配方变异 | 0.05 | 变异成功后保留为"自创配方" |
| 融合变异 | 0.02 | 两个无关配方材料融合，产出"混沌型"物品 |
| 危险变异 | 0.03 | 产出有强力副作用物品 |

- 变异可命名：玩家可为自己的变异产物命名
- 自创配方可分享：通过配方卷轴抄录，出售或赠送给其他玩家
- 变异配方有"唯一发现者"标记，给发现者提供声望加成

### 3.6 阶段五：使用循环（Usage Cycle）

#### 3.6.1 丹药抗性机制

**同种丹药服用效果衰减：**

| 服用次数 | 效果倍率 | 显示 |
|---------|---------|------|
| 第1次 | 100% | 效果正常 |
| 第2次 | 70% | "药效减弱" |
| 第3次 | 40% | "效果大幅降低" |
| 第4次及以上 | 0% | "已产生完全抗性" |

**抗性恢复：**
- 每游戏日自动 -1 计数（约7天彻底恢复）
- 高品质丹药抗性衰减更慢：

| 品质 | 抗性衰减速度（/次） |
|------|-------------------|
| 下品 | -33%（3次全抗） |
| 中品 | -30%（4次全抗） |
| 上品 | -20%（5次全抗） |
| 极品 | -10%（10次全抗） |

**策略提示：** 交替服用不同种类丹药可最大化收益。丹药设计上确保每种丹药有不可替代的用途（回血 / 回蓝 / 突破 / 解毒），不会出现"一种最优丹吃到老"的情况。

#### 3.6.2 装备耐久度

- 每次战斗消耗耐久度（被命中消耗护甲耐久，攻击消耗武器耐久）
- 耐久度归零时装备暂时失效（不消失，但属性暂停生效）
- 可维修：消耗绑定材料+灵石，恢复耐久度至最大值
- 维修可在炼器台进行，也可找NPC铁匠
- UR品质装备有"不朽"属性——永不损坏，但非常稀有

#### 3.6.3 装备强化

在炼器台进行装备强化（镶嵌 / 附魔 / 铭文）：

```
EnhanceChance = 0.8 × EquipmentQualityModifier × MaterialsQuality × (1 - CurrentLevel × 0.1)
```

- 强化消耗妖兽材料 + 灵石 + 灵力
- 失败时只损失材料，装备不毁
- 强化等级上限：R=5, SR=7, SSR=9, UR=12
- 强化到+5以上时，每次成功有"附赠词缀"概率（+5~10%、+10~20%）

## 4. Formulas

### 4.1 炼丹品质判定

```
FinalQuality = BaseQuality × TemperatureScore × OrderScore × MaterialScore × EquipmentModifier
```

**BaseQuality：** 配方的随机基底（`0.3~1.0`），代表配方的内在品质波动范围。

**TemperatureScore：**
```
TemperatureScore = 1.0 - (|ActualAvgTemp - OptimalTemp| / OptimalTemp) × 0.5
```
- `ActualAvgTemp` = 玩家在整个炼制过程中的平均炉温
- `OptimalTemp` = 配方推荐温度
- 完美控火时 TemperatureScore ≈ 1.0，严重偏离时 ≈ 0.5

**OrderScore：**
```
OrderScore = Clamp(1.0 - 错误投放次数 × 0.15, 0.4, 1.0)
```
- 一次全部正确投放 → 1.0
- 错3次以上 → 0.4（下品底线）

**MaterialScore：**
```
MaterialScore = average(每种投入材料的品质系数)
```
- 普通材料 = 0.7, 良好 = 0.85, 优质 = 1.0, 完美 = 1.2

**EquipmentModifier：**
```
EquipmentModifier = 丹炉品质系数 × (1 - 丹炉磨损系数 × 0.01)
```
- 新手丹炉 = 0.8, 精良丹炉 = 1.0, 传说丹炉 = 1.2
- 磨损系数 = 1 - (当前耐久 / 最大耐久)

### 4.2 炸炉判定

```
ExplosionChance = BaseExplosionRate × OverheatFactor × EquipmentHealthFactor
```
- `BaseExplosionRate = 0.05`（基础5%）
- `OverheatFactor = 1.0 + 连续大火秒数 × 0.1`（5秒大火 → 1.5）
- `EquipmentHealthFactor = 1.0 + (1 - 当前耐久/最大耐久) × 0.5`

炸炉判定：`if Random.Range(0,1) < ExplosionChance → 炸炉`

### 4.3 炉温变化

```
温度变化 = 火候升温速率 × 设备导热系数 + 环境偏移
```

| 变量 | 说明 |
|------|------|
| 大火 | +8°C/秒 |
| 中火 | +2°C/秒 |
| 小火 | -1°C/秒 |
| 设备导热 | 普通=1.0, 精良=1.2, 传说=1.0 |
| 环境偏移 | 火山+10°C, 冰原-10°C, 正常=0°C |

### 4.4 采集产出

```
OutputQuantity = BaseQuantity × ToolMultiplier × ProficiencyMultiplier
CritChance = 0.1 + 工具暴击加成 + 熟练度暴击加成
if Roll < CritChance → OutputQuantity ×= CritMultiplier(2)
```

```
GatherSuccess = 0.9 + ToolBonus + ProficiencyBonus - Difficulty
if GatherSuccess < 0 → 不可采集
if GatherSuccess < Random(0,1) → 失败（获一半或零产出）
```

### 4.5 鉴定判定

```
IdentifyChance = 0.5 + ProficiencyBonus + EquipmentBonus - HerbDifficulty
```
- `ProficiencyBonus = 炼药等级 × 0.003`
- `EquipmentBonus` = 鉴定工具品质系数（0~0.2）
- `HerbDifficulty` = 灵材鉴定难度（0.1~0.8）

### 4.6 装备属性

```
EquipmentStats = BaseStats × MaterialMultiplier × EquipmentQuality × EnhancementMultiplier
```

- `MaterialMultiplier = average(各材料属性系数)`，范围0.7~1.3
- `EquipmentQuality` = 炼器品质（0-1）
- `EnhancementMultiplier = 1.0 + 强化等级 × 0.1`

词缀生成：
```
AffixCount = 
  EquipmentQuality < 0.5 → 0
  0.5 ≤ EquipmentQuality < 0.75 → 1
  0.75 ≤ EquipmentQuality < 0.92 → 2
  EquipmentQuality ≥ 0.92 → 3
```

### 4.7 丹药药力

```
药力效果 = BaseEffect × QualityMultiplier × ResistanceMultiplier × ProficiencyMultiplier
```

- `BaseEffect` = 丹药基础数值
- `QualityMultiplier`：下品=0.5~0.7, 中品=0.8~1.0, 上品=1.1~1.3, 极品=1.4~1.6
- `ResistanceMultiplier`：第1次=1.0, 第2次=0.7, 第3次=0.4, 第4+=0.0
- `ProficiencyMultiplier = 1.0 + 炼药等级 / 200`

### 4.8 装备强化

```
EnhanceChance = 0.8 × EquipmentQualityModifier × MaterialsQuality × (1 - Level × 0.1)
```

| 装备品质 | EquipmentQualityModifier |
|---------|------------------------|
| R | 0.8 |
| SR | 1.0 |
| SSR | 1.2 |
| UR | 1.5 |

各等级强化成功率（SR品质, 普通材料）：
```
+0→+1: 80%
+1→+2: 72%
+2→+3: 64%
...
+9→+10: 8%
```

丹药炼制系统既是产出系统也是消耗系统：

| 环节 | 灵石流向 | 占比预期 |
|------|---------|---------|
| NPC购买工具/设备 | 流出 | 15% |
| NPC鉴定费用 | 流出 | 5% |
| 设备维修 | 流出 | 10% |
| 购买基础材料 | 流出 | 20% |
| 出售成品给NPC | 流入 | 35% |
| 玩家间交易 | 内部循环 | 15% |

## 5. Edge Cases

### 5.1 背包已满时炼制成功

**处理：**
- 炼制品临时存储在"炼制结果暂存区"（最多5个槽位）
- 暂存区满则炼制失败但材料不消耗，提示"请清理背包"
- 暂存物品保留24小时，超时通过邮件发送

### 5.2 炼制中断线

**处理：**
- 根据离线前的火候状态判定结果：
  - 最后状态为"大火"且持续>30秒：炸炉
  - 中火/小火：继续至结束，品质系数-0.1惩罚
- 结果存暂存区，下次登录弹窗通知

### 5.3 多人在同一采集点

**处理：**
- 普通资源：各采各的（独立实例）
- 稀有资源：先到先得，抢完显示"已被采集"残留
- 天材地宝：全区域竞争，PVP区域可掠夺
- 采集行为在PVP区域可被其他玩家"拦截"（打断并进入对战）

### 5.4 材料品质不达标

**处理：**
- 配方有材料最低品质限制，低于下限无法投入
- 允许"降级炼制"——用高级材料炼低级配方（产出高品质低级品）
- 允许材料替代——某些材料可用功能近似的替代（系统提示"材料不匹配，可能影响成品"但不禁止）

### 5.5 炸炉波及他人

**处理：**
- 范围3-8m效果
- 溅射伤害：炉温 × 0.3
- 范围内其他玩家的设备受冲击（耐久度-5~15）
- 多人模式下炸炉对其他玩家可见（冒黑烟、热浪效果）
- 恶意炸炉可被判定为PVP行为

### 5.6 全抗性满（"药石无灵"）

**处理：**
- 所有丹药类型抗性计数≥4时触发
- 效果：所有丹药效果降低80%（非完全无效）
- 持续7游戏日后自然消退
- 可通过"药浴洗髓"任务提前清除（一次性任务）

### 5.7 炼制出不可用装备

**处理：**
- 高阶装备有境界要求（"金丹期以上可装备"）
- 未达要求无法装备，可保留或交易
- 可"沉睡"：装备保留但无效果，到达需求境界时自动激活并获得"破境之礼"（额外属性加成）
- 可"降阶镶嵌"：消耗额外材料降低装备需求境界（同时降低部分属性）

### 5.8 配方数量过多

**处理：**
- 配方无数量限制，全部永久保留
- 提供配方搜索（按名称/类型/材料过滤）
- 提供配方收藏（快捷栏5-10个常用配方）
- 基础配方自动掌握，高级配方通过卷轴学习
- 配方可抄录分享（消耗材料和灵力，生成可交易的配方卷轴）

### 5.9 极端环境炼制

**处理：**
- 环境温度自动偏移炉温 ±5~15°C
- 同区域灵材有"环境适应性"——在本域炼制时品质系数+0.05
- 特定丹药必须特定环境（"冰心丹"需冰川环境，"烈火丹"需火山环境）
- 极端环境下不可使用普通丹炉（需特殊设备）
