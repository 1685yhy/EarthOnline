## 1. Overview

新地图系统（New Maps System）是地球Online的世界层基础设施。它将灵气大陆从静态场景集合转变为活的、会呼吸的生态系统——每个区域拥有独立的生态、资源、NPC势力和隐藏内容。系统以三大支柱构建：**迷雾系统**（未见之地保持隐藏）、**发现系统**（探索本身就是奖励）、**风险预警系统**（世界告诉你危险程度，但永不阻止你踏入）。玩家可以从新手村直接走向魔渊禁地，系统会警告"前方极度危险"，但不会锁门。真正的开放世界从这张地图开始。

## 2. Player Fantasy

**"穿越到未知之地"——每一次迈入新区域都是一场微型冒险。**

玩家的核心幻想是：我确实不知道山那边有什么。地图上只有我走过的地方才亮起来。当我第一次踏上荒漠边境，屏幕中央浮现区域名称和一行古文字背景介绍，背景音乐切换为异域调式——我意识到自己进入了一个全新的世界。

### 2.1 具体时刻

**初次踏入**：迷雾消散的动画伴随区域名称浮现，一行历史背景文案触发。玩家获得"探索者"成就的第一块碎片。这个瞬间是每次区域切换的情感高潮——游戏在说："你来了，这里有一段故事。"

**发现据点**：在未知区域找到第一个安全点（野外商栈、废弃传送阵），解锁传送和重生。这是从"探索模式"切换到"活动模式"的转折点——玩家从"我该怎么活下来"变为"我可以在这里做什么"。

**发现地标**：偶然撞见远古遗迹、灵气泉眼、隐藏秘境入口——没有UI标记指引，全靠眼神和直觉。地标自带一段环境叙事（残破石碑上的铭文、被藤蔓覆盖的雕像）。这是"世界在讲自己的故事"的时刻。

**风险评估的紧张感**：界面角落显示当前区域的预估风险等级。当风险从"安全"变为"危险"再变为"极度危险"时，玩家的心率也随之升高——不是数值变化的焦虑，而是"我可能真的会死在这里"的沉浸式紧张。当玩家以低境界身份踏入高危险区域却成功找到宝物时，这种"偷渡成功"的快感是自由探索的核心奖励。

**区域声望的反馈**：帮助某区域的NPC解决麻烦后，商人对你打折、守卫对你点头致意、情报贩子愿意透露更多秘密。世界对玩家的态度因玩家的行为而改变——这是"世界记住你了"的深层满足感。

### 2.2 幻想关键词

| 关键词 | 对应的玩家体验 |
|--------|--------------|
| 未知 | 迷雾遮罩下的世界充满神秘感，每一步都是发现 |
| 自主 | 没有强制路径的完全自由探索，玩家决定下一步去哪 |
| 风险 | 风险评级创造决策焦虑——"我该不该进去？"本身就是乐趣 |
| 回报 | 探索驱动型奖励链——你走得越远、越冒险，收获越丰厚 |
| 归属 | 区域声望让玩家在每个地区建立自己的名声 |

## 3. Detailed Rules

### 3.1 世界分区

整个灵气大陆划分为 N 个地理区域（Region），每个区域包含以下数据定义：

**区域数据定义：**
```
Region
├── regionId: string            — 唯一标识（如 "qinyun_mountains"）
├── displayName: string         — 显示名称（如 "青云山脉"）
├── biomeType: enum             — 生态类型（Forest / Desert / Snow / Swamp / Volcano / Sea / Cave / Lawless）
├── baseRiskRating: int (1-100) — 风险基准等级
├── defaultOwner: string|null   — 默认归属势力ID（门派或无主）
├── description: string         — 区域背景描述
│
├── resourcePool: ResourceDef[] — 区域可采集灵材列表及刷新率
├── landmarkList: LandmarkDef[] — 固定生成的POI列表
├── hiddenDiscoveryList: HiddenDef[] — 需特定条件触发的隐藏点
├── npcPool: NPCDef[]           — 区域内NPC列表
├── factionRelations: Dict      — 势力关系表
│
├── maxConcurrentEvents: int    — 动态事件槽位上限
├── eventPool: EventDef[]       — 可触发的动态事件列表
└── transitionZones: Transition[] — 区域间过渡带定义
```

**生态类型及示例：**

| 生态 | 示例区域 | 特征 |
|------|---------|------|
| Forest | 青云山脉 | 木材类灵材丰富，妖兽种类均衡 |
| Desert | 流沙荒漠 | 火系灵材，耐旱妖兽，白天气温影响体力 |
| Snow | 冰封雪原 | 水系/冰系灵材，严寒环境消耗加快 |
| Swamp | 瘴气沼泽 | 毒系灵材，视线受阻，移动减速 |
| Volcano | 烈焰谷 | 火系/矿物类稀有材料，高温区域持续掉血 |
| Sea | 无尽海 | 水系灵材，岛屿探索，需船只 |
| Cave | 地脉洞天 | 矿产丰富，光线限制，易迷路 |
| Lawless | 三不管地带 | 高回报高风险，无势力管辖，PVP自由区 |

### 3.2 迷雾系统（Fog of War）

#### 3.2.1 初始状态

所有区域对玩家完全笼罩在迷雾中。世界地图只显示地形轮廓（山脉/河流/海洋的大致形状），不显示任何名称、POI、资源标记。

#### 3.2.2 迷雾三层级

| 层级 | 名称 | 显示内容 | 触发条件 |
|------|------|---------|---------|
| Layer 0 | 未探索 | 只显示基础地形轮廓 | 初始状态 |
| Layer 1 | 浅探 | 地形细节、道路、主要地标图标 | 玩家经过或目视可见范围内 |
| Layer 2 | 深入 | 所有POI、资源分布热区、NPC聚落、隐藏入口提示 | 该区域探索度达到阈值 |

**Layer 1 显示的内容：**
- 已走过的路径轨迹
- 地形高度差（山丘/山谷/河流）
- 主要道路
- 大型地标图标（遗迹/主城/传送阵）
- 已发现的快速旅行点

**Layer 2 额外显示的内容：**
- 中小型POI图标（资源点/小聚落/洞穴入口）
- 资源分布热区（用颜色标记高密度区域）
- NPC聚落名称
- 隐藏入口的特殊标记（"此处似有古怪..."提示）
- 副本入口标记

#### 3.2.3 迷雾消散机制

**常规消散：**
- 玩家移动时，以玩家为中心半径 = `BaseRevealRadius + PerceptionBonus` 的圆内迷雾永久消散至Layer 1
- 消散跟随玩家实时进行，无延迟
- 已消散区域不会因为玩家离开而重新被迷雾覆盖

**高处视野：**
- 玩家在山顶、瞭望塔、飞行坐骑上时，获得临时大范围视野
- 半径扩大至 `BaseRevealRadius × HeightMultiplier`
- 持续时间：玩家停留在高处期间持续生效，离开后30秒内消退
- 消退过程是渐变的（从边缘向中心收缩），给玩家一个"视野在收回"的视觉效果

**道具消散：**
- "破障符"：揭示以使用点为圆心、固定半径内的大范围Layer 2信息（一次性）
- "详细地图卷轴"：将整个目标区域降至Layer 1并标记所有主要地标（可通过NPC购买或任务获得）
- "神识玉佩"：永久提高玩家的迷雾消散半径（装备类）

**特殊规则：**
- 死亡后已探索区域不重置迷雾
- 只有特定事件（如"空间震荡""天道紊乱"）会导致某区域重新被迷雾覆盖——此类事件极其罕见且有叙事解释
- 区域在发生灭世级动态事件时，迷雾可能临时回退（事件结束后恢复）

### 3.3 发现系统（Discovery System）

扩展原有的 HiddenDiscovery.cs，分为三个发现等级：

#### 3.3.1 三级发现体系

| 等级 | 名称 | 规模 | 触发方式 | 奖励 | 地图标记 |
|------|------|------|---------|------|---------|
| 一级 | 地标（Landmark） | 最大 | 靠近自动触发，无隐藏条件 | 区域名称解锁、探索经验、区域声望+10 | 永久图标 |
| 二级 | 兴趣点（POI） | 中等 | 进入触发半径且迷雾已消散 | 探索经验、声望+3、可能附带宝箱/材料 | 问号标记 |
| 三级 | 隐藏发现（Hidden） | 最小 | 需特定条件组合触发 | 稀有道具/功法/装备、修为、声望+5 | 无自动标记 |

#### 3.3.2 地标（Landmark）

**特征：**
- 通常是区域入口、显眼位置的地理性标志
- 无隐藏条件，靠近必然触发
- 每个区域至少有2-3个地标

**触发流程：**
1. 玩家进入 `LandmarkTriggerRadius`（默认15m）
2. 屏幕中央浮现区域名称+背景文案
3. 触发"发现地标"成就/进度
4. 地标被永久记录在世界地图上
5. 如果地标附带快速旅行功能，同时解锁传送点

**示例：**
- "青云山脉界碑"——刻着山脉历史的古老石碑
- "落星湖"——传说中流星坠落形成的湖泊，湖畔有残破祭坛
- "上古传送阵遗迹"——虽已废弃但仍有灵力波动

#### 3.3.3 兴趣点（POI）

**特征：**
- 中等规模，需要主动探索才能发现
- 必须在该位置已消散迷雾（Layer 1及以上）后才可触发
- 每个区域5-15个POI

**触发流程：**
1. 玩家进入 `POITriggerRadius`（默认10m）
2. 触发小型发现动画（闪光/粒子效果）
3. POI信息注册到地图
4. 地图上显示问号标记
5. 探索度+1~2%

**类型示例：**
- **资源型**："隐蔽药圃"——自然生长的灵材丛
- **战斗型**："废弃妖兽巢穴"——可能残留宝物
- **剧情型**："采石场废墟"——散落的日记碎片揭示区域历史
- **功能性**："山间猎户小屋"——提供临时休息和交易

#### 3.3.4 隐藏发现（Hidden Discovery）

**特征：**
- 最小规模但最珍贵
- 需要特定条件组合才能触发
- 每个区域2-5个隐藏发现
- 是探索系统中最具"惊喜"价值的内容

**触发条件（可组合）：**
- **境界条件**：角色境界 ≥ 特定值（如金丹期以上才能感知到隐藏的洞府入口）
- **道具条件**：持有特定道具（如"神秘铜钥匙"才能打开隐藏门）
- **前置任务**：已完成某个相关任务
- **时间条件**：特定时辰（如子时、月圆之夜、日落时分）
- **天气条件**：特定天气（暴雨时雷击木显现、大雾中隐藏岛屿浮现）
- **技能条件**：使用特定技能才能发现（"神识探查""望气术"）
- **概率条件**：检测通过后才触发（见公式章节）

**触发流程：**
1. 玩家接近隐藏点位置（进入 `HiddenDetectionRadius`）
2. 系统检查所有条件是否满足
3. 概率条件进行判定
4. 满足时：触发发现事件，播放特殊视觉效果（金光、音效），给予奖励
5. 不满足但已部分满足条件时：显示朦胧提示（"这里似乎有什么东西..."）
6. 发现后不自动地图标记，但玩家可以手动放置标记

**奖励类型：**
- 稀有功法残页
- 唯一装备/武器
- 高品质灵材
- 大量修为点数
- 隐藏剧情线索
- 特殊称号

**示例：**
- 暴雨天才会出现的"雷击木"——吸收天雷之力的珍贵材料
- 只有金丹期才能感知到的"微光洞府"——前辈修士留下的遗产
- 持有神秘钥匙才能打开的"无门之门"——隐藏副本入口
- 月圆之夜在特定坐标处出现的"幻月莲"

### 3.4 风险评级系统（Risk Rating System）

#### 3.4.1 核心哲学

**不阻止，只预警。** 系统从不阻止玩家进入任何区域，只在进入前提供清晰的风险情报，让玩家自己做决定。

#### 3.4.2 风险等级显示

| 风险因子区间 | 显示文字 | 玩家体验 | 怪物行为 |
|------------|---------|---------|---------|
| < 0.2 | 安全 | 可安心探索 | 怪物不主动攻击，采集无干扰 |
| 0.2 ~ 0.4 | 低风险 | 稍有戒备 | 少数怪物主动攻击，威胁可控 |
| 0.4 ~ 0.6 | 中等风险 | 需要谨慎 | 大部分怪物主动攻击，需经常回复 |
| 0.6 ~ 0.8 | 高风险 | 推荐组队 | 几近全部怪物主动攻击，精英怪出没 |
| ≥ 0.8 | 极度危险 | 死亡率极高 | BOSS级单位可能出现，建议撤退 |

#### 3.4.3 提示层级

**第一层：边缘预警**
- 玩家靠近区域边界约50m时触发
- 屏幕边缘出现淡红色光晕
- 显示文字："前方是[区域名称]，预估风险等级：[中等]"
- 不阻断移动，仅做视觉/文字提示

**第二层：踏入确认**
- 玩家跨域区域边界时触发
- 屏幕中央弹出风险确认面板：
  - 区域名称及背景简述
  - 风险等级（数值 + 颜色）
  - 已知威胁类型（如果有前置探索记录）
  - 建议准备项（非强制性）——"建议携带解毒丹""建议组队前往"
  - 操作提示：按 F 确认进入
- 如果未操作，3秒后自动关闭并进入区域

**第三层：持续反馈**
- 进入后游戏HUD角落持续显示当前区域风险等级
- 图标样式：菱形徽章，颜色从绿（安全）渐变到红（极度危险）
- 风险等级因动态事件或时间变化时，图标有过渡动画
- 玩家可以随时点击查看详细风险分析

#### 3.4.4 风险的实际影响

风险评级不阻止玩家进入，但影响以下游戏机制：

| 受影响的系统 | 影响方式 |
|------------|---------|
| 怪物AI | 高风险区怪物索敌半径扩大至1.5倍，警戒时间延长至2倍 |
| 采集干扰 | 高风险区采集时有更高概率被怪物袭击打断 |
| 精英遭遇率 | 风险因子每+0.2，精英怪物生成概率×1.5 |
| 传送冷却 | 传送读条 = 基础值 × (1 + RiskFactor × 0.5) |
| 死亡惩罚 | 死亡修为损失 = 基础值 × (1 + RiskFactor × 0.5) |
| 陷阱触发 | 高风险区陷阱密度和触发概率增加 |

### 3.5 快速旅行系统（Fast Travel System）

在现有 FastTravel.cs 基础上进行完整重构。

#### 3.5.1 传送点类型

| 类型 | 特征 | 发现方式 | 费用系数 |
|------|------|---------|---------|
| 村落传送阵 | 主要聚落，最常用 | 初次到访自动发现 | 1.0x（最低） |
| 野外哨站 | 区域NPC据点 | 探索发现 | 1.2x |
| 隐秘传送阵 | 连接两个特定位置 | 需要任务或隐藏条件 | 1.5x |
| 破损传送阵 | 需修复后使用 | 发现后还需修复 | 1.0x（但需修复材料） |

#### 3.5.2 解锁规则

- 每个传送点首次到达时自动发现（保持在范围内3秒）
- 传送至某点需要该点已发现
- 额外限制条件：
  - **区域稳定度**：区域发生灭世级动态事件时，区域内所有传送点临时禁用
  - **声望门槛**：位于敌对势力控制区域的传送点，需声望≥冷淡(-199)以上才可使用
  - **战斗状态**：战斗中不可使用传送
  - **物理状态**：处于空中、水下、禁锢状态时不可使用传送

#### 3.5.3 传送流程

1. 玩家在已发现的传送点上按 F 打开传送菜单
2. 菜单显示所有已发现传送点的列表，包含：名称、所属区域、距离、费用
3. 高风险区域的传送点用红色标记显示
4. 选择目标点后开始读条
5. 读条期间玩家可移动但不可进入战斗（轻微减速）
6. 读条完成，消耗灵石，传送完成

#### 3.5.4 打断规则

- 读条中受到伤害 → 打断
- 读条中被控制技能命中 → 打断
- 打断后不消耗灵石
- 打断后触发30秒"传送紊乱"debuff：期间不可使用传送
- 在PVP区域：其他玩家可以看到传送读条条并有打断机会

#### 3.5.5 死亡传送

- 玩家死亡后默认回到最近已激活的安全点（聚落/哨站）
- 如果最近的安全点在死前最后经过的区域外，则回到相邻区域的最近安全点
- 不消耗灵石
- 死亡后重置所有传送的冷却

### 3.6 区域声望系统（Area Reputation）

每个主要区域拥有独立的声望值（范围 -1000 ~ 1000）。

#### 3.6.1 声望获取

| 行为 | 声望变化 | 备注 |
|------|---------|------|
| 完成区域内NPC委托任务 | +20 ~ +100 | 根据任务难度 |
| 首次发现重要地标 | +10 | 一次性 |
| 击败威胁区域安全的BOSS | +50 ~ +200 | 根据BOSS威胁等级 |
| 向区域商会捐献材料 | +1 ~ +5/次 | 每日有上限 |
| 消灭区域内敌对怪物 | +0.1 ~ +0.5/只 | 微小累积 |
| 击杀区域内友好NPC | -50 ~ -200 | 根据NPC身份 |
| 偷窃区域内NPC | -10 ~ -30 | 被发现时 |
| 破坏区域环境（如过度采集） | -1 ~ -5/次 | 触发提示 |

#### 3.6.2 声望等级及效果

| 声望值区间 | 等级 | 效果 |
|-----------|------|------|
| ≥ 800 | 崇拜 | 商品6折、隐藏任务解锁、专属称号、传送免费、守卫行礼 |
| 500 ~ 799 | 尊敬 | 商品8折、特殊任务解锁、NPC提供情报、通行证生效 |
| 200 ~ 499 | 友好 | 商品9折、基础任务解锁、允许通行 |
| -199 ~ 199 | 中立 | 常规交易、无特殊待遇、表情不变 |
| -200 ~ -499 | 冷淡 | 商品价格上浮20%、部分NPC拒绝交易、守卫警觉 |
| -500 ~ -799 | 敌对 | NPC主动攻击（部分）、无法使用传送点、商店关闭 |
| ≤ -800 | 仇恨 | 区域守卫追杀、强制驱逐出区域、悬赏通缉 |

#### 3.6.3 声望衰减

每日有自然衰减，收敛于0（中立）：
- 崇拜/仇恨：每日衰减约0.1点（基本不衰减）
- 尊敬/敌对：每日衰减约0.5点
- 友好/冷淡：每日衰减约1.5点
- 中立：在0附近波动，不受主动衰减影响

实际衰减量受玩家在该区域的活跃度影响——常去的区域声望更稳定。

### 3.7 区域生态系统

每个区域像一个微型沙盒，拥有自洽的生态逻辑。

#### 3.7.1 资源生态

**灵材资源：**
- 每种灵材有固定的刷新位置（或多个潜在刷新点）
- 刷新周期：普通灵材1-3游戏日，稀有灵材7-30游戏日
- 采集要求：部分灵材需要特定境界或工具
- 采集后该位置进入倒计时，未到刷新时间不产出

**妖兽资源：**
- 种类：每种区域有3-8种不同的妖兽
- 等级分布：妖兽境界与该区域风险等级匹配
- 刷新位置：固定刷新点 + 随机游走区
- 掉落表：每种妖兽有独特的掉落列表，包括材料和稀有掉落

**特殊资源点：**
- 灵石矿脉：可反复采集的灵石来源
- 灵泉：可取水炼丹，有冷却时间
- 天材地宝：一次性采集的极品灵材，通常需要隐藏发现触发

#### 3.7.2 NPC生态

**固定NPC：**
- 商人、铁匠、药师、情报贩子——常驻特定位置
- 任务发布者——提供区域特有的支线任务
- 传送阵管理员——管理传送服务

**巡逻NPC：**
- 区域守卫——维护治安，对声望过低的玩家采取行动
- 门派巡查弟子——门派控制区域特有的巡逻力量
- 商队——沿道路定期往返

**随机NPC：**
- 旅行商人——短暂停留后离开，携带稀缺商品
- 逃亡者——触发临时护送任务
- 采集者——与玩家竞争资源，可能引发冲突

**隐藏NPC：**
- 需要特定条件出现（如声望等级、境界要求、持有特定物品）
- 通常提供稀有的交易、任务或情报

#### 3.7.3 势力生态

- 每个区域可能被0-3个势力控制或部分控制
- 势力间关系（同盟/敌对/中立）影响NPC对玩家的态度
- 玩家在区域内的行为不仅影响区域声望，还影响相关势力的声望
- 势力间的冲突可能触发区域动态事件

### 3.8 探索深度系统（Exploration Depth）

每个区域有独立的探索度（0-100%），反映玩家对该区域的掌握程度。

#### 3.8.1 探索度阶段

| 探索度 | 阶段名称 | 解锁内容 |
|-------|---------|---------|
| 0-20% | 初来乍到 | 只显示走过的基本地形和路径 |
| 20-40% | 熟悉地形 | 主要道路和大型地标显示，快速旅行点可见 |
| 40-60% | 深入腹地 | 中小型POI出现在地图上，资源热区高亮 |
| 60-80% | 了如指掌 | 隐藏发现入口提示出现，NPC聚落全部标记 |
| 80-100% | 完全掌控 | 所有隐藏内容定位，传送点全部激活，获得"探索大师"称号 |

#### 3.8.2 探索度获取

| 行为 | 探索度增量 | 备注 |
|------|-----------|------|
| 首次踏入区域 | +5% | 一次性 |
| 发现地标 | +3~5% | 根据地标重要性 |
| 发现POI | +1~2% | 根据POI类型 |
| 发现隐藏内容 | +2~3% | 一次性 |
| 完成区域任务 | +2~5%/任务 | 根据任务链长度 |
| 走过覆盖面积 | +0.1%/覆盖1%面积 | 持续累积 |

### 3.9 动态事件系统（区域层）

每个区域可独立触发动态事件，增加世界的活力和不可预测性。

#### 3.9.1 事件类型

| 事件类型 | 描述 | 影响 |
|---------|------|------|
| 妖兽潮 | 大量妖兽涌入区域 | 风险等级临时+2，经验获取提升 |
| 灵脉爆发 | 区域内灵气浓度暴涨 | 修炼速度提升，稀有灵材刷新 |
| 商队遇袭 | 商人NPC被攻击 | 可救援获得声望，或趁乱获取资源 |
| 天降异象 | 流星雨/血月/极光 | 隐藏发现触发概率提升，探索经验×1.5 |
| 门派巡逻 | 控制势力加强巡查 | 敌对玩家被驱逐风险增加 |
| 秘境开门 | 隐藏秘境入口暂时开放 | 限时进入机会，稀有产出 |

#### 3.9.2 事件管理

- 每个区域有事件槽位上限（`maxConcurrentEvents`，默认3-5）
- 达到上限时新事件进入等待队列
- 互斥事件合并为连锁事件
- 事件有持续时间和冷却时间
- 事件结束后的区域状态恢复有渐变过渡

## 4. Formulas

### 4.1 风险因子计算

```
RiskFactor = Clamp01((BaseRiskRating - PlayerEffectivePower) / BaseRiskRating)
```

其中：
```
PlayerEffectivePower = PlayerBasePower × (1 + EquipmentBonus) + PartyBuff
PlayerBasePower = CultivationStageBaseValue + (StageLevel × StageLevelMultiplier)
BaseRiskRating = RegionBaseRisk + ActiveEventModifier + TimeOfDayModifier
```

- `RiskFactor` ∈ [0, 1]，映射到章节3.4.2的风险等级表
- `ActiveEventModifier`：动态事件发生时 ±10~30
- `TimeOfDayModifier`：夜晚高风险区域 +10~20，低风险区域 -5~-10
- `CultivationStageBaseValue`：凡人=1, 练气=10, 筑基=30, 金丹=90, 元婴=270, 化神=810, 渡劫=2430, 大成=7290
- `StageLevelMultiplier`：每小层的增幅系数（默认 = StageBase / 5）

**示例：**
- 玩家：筑基3层（PlayerBasePower = 30 + 3×6 = 48），无装备加成
- 区域：烈焰谷（BaseRiskRating = 65），白天（无时间修正），无事件
- RiskFactor = (65 - 48) / 65 = 0.262 → **低风险**

### 4.2 探索经验公式

```
ExploreXP = BaseRegionXP × FirstTimeMultiplier × DepthMultiplier × RiskMultiplier
```

其中：
```
BaseRegionXP = RegionLevel × 10
FirstTimeMultiplier = 首次踏入该区域 ? 2.0 : 1.0
DepthMultiplier = 1.0 + (当前探索度 × 0.5)
RiskMultiplier = 1.0 + (RiskFactor × 0.5)
```

**示例计算：**
- 玩家首次踏入等级30的区域，RiskFactor=0.4：
  - BaseRegionXP = 30 × 10 = 300
  - FirstTimeMultiplier = 2.0
  - DepthMultiplier = 1.0 + 0.0 × 0.5 = 1.0
  - RiskMultiplier = 1.0 + 0.4 × 0.5 = 1.2
  - ExploreXP = 300 × 2.0 × 1.0 × 1.2 = **720 exp**

- 同一区域，探索度60%时再次探索：
  - ExploreXP = 300 × 1.0 × (1.0 + 0.3) × 1.2 = **468 exp**

### 4.3 隐藏发现检测概率

```
DetectionChance = BaseDetectionProbability / (1 + (DistanceToDiscovery / IdealDetectionRadius)^2)
```

其中：
```
BaseDetectionProbability = 0.6（基础60%）
DistanceToDiscovery = 玩家与隐藏点之间的实际距离
IdealDetectionRadius = 区域设定值，通常3-8m
```

**额外修正：**
- 玩家境界大于区域推荐境界：每高1个大境界 +5% DetectionChance
- 使用"神识探查"技能：DetectionChance = 1.0（必定发现，技能持续期间）
- 持有特定"寻宝道具"：+15%
- 夜间在有夜视加成时：+10%
- 当前区域有"天降异象"事件：+20%

**示例：**
- 距离隐藏点5m，IdealDetectionRadius=6m，无修正：
  - DetectionChance = 0.6 / (1 + (5/6)^2) = 0.6 / (1 + 0.694) = 0.6 / 1.694 = **35.4%**

### 4.4 快速旅行费用与时间

```
TravelCost = BaseCost × DistanceMultiplier × RegionRiskFactor
```
其中：
```
BaseCost = 50 灵石
DistanceMultiplier = Distance / 1000（距离以米为单位，最小1.0）
RegionRiskFactor = 1.0 + RiskFactor × 0.5
```

**示例：**
- 传送距离3000m，目标区域RiskFactor=0.6：
  - TravelCost = 50 × (3000/1000) × (1.0 + 0.6×0.5) = 50 × 3 × 1.3 = **195 灵石**

```
FastTravelCastTime = 3.0s × (1.0 + RiskFactor × 0.5)
```
- 低风险区域 (RiskFactor=0.1)：3.15秒
- 极度危险区域 (RiskFactor=0.9)：4.35秒

```
FastTravelCooldown = 10.0s / (1.0 + ExplorationDepth × 0.5)
```
- 探索度0%：10.0秒
- 探索度100%：6.67秒

### 4.5 迷雾消散半径

```
RevealRadius = BaseRevealRadius × (1 + PerceptionStatModifier × 0.01)
```
其中：
```
BaseRevealRadius = 15m（默认）
PerceptionStatModifier = 玩家的感知属性值（每点+1%）
```

**高处加成：**
```
HeightRevealRadius = RevealRadius × HeightMultiplier
HeightMultiplier = 3.0（默认），根据高度动态调整为1.5~5.0
```

**道具加成：**
- 使用"破障符"：半径+20m，持续10秒
- 装备"神识玉佩"：RevealRadius +5m（装备时永久生效）

### 4.6 区域声望衰减

```
DailyDecay = BaseDecayRate × ReputationLevelDecayFactor × ActivityFactor
```

其中：
```
BaseDecayRate = 5（每日基础衰减量）
ReputationLevelDecayFactor：
  崇拜（≥800）/ 仇恨（≤-800）：0.02
  尊敬（500~799）/ 敌对（-500~-799）：0.1
  友好（200~499）/ 冷淡（-200~-499）：0.3
  中立（-199~199）：0.5

ActivityFactor = 1 / (1 + 最近7天在该区域活跃小时数 × 0.1)
  活跃小时数越多，衰减越慢
```

**示例：**
- 友好声望（DecayFactor=0.3），最近7天活跃10小时：
  - ActivityFactor = 1 / (1 + 10 × 0.1) = 0.5
  - DailyDecay = 5 × 0.3 × 0.5 = **0.75/天**
  - 从友好（+200）衰减到中立（0）约需266天——几乎不用担心

### 4.7 动态事件触发概率

```
EventTriggerChance = BaseEventProbability × PlayerActivityModifier × TimeModifier × DayCountModifier
```

其中：
```
BaseEventProbability = 0.05（每游戏小时5%基础概率）
PlayerActivityModifier：
  玩家在该区域活跃（杀怪/采集/任务）：×2.0
  玩家在区域内但静止/挂机：×1.0
  玩家离线：×0.2
  玩家在该区域死亡：×1.5（持续1游戏小时）

TimeModifier：
  白天（6:00-18:00）：×1.0
  夜晚（18:00-6:00）：×1.5
  特殊天象（血月/流星雨/日食）：×3.0

DayCountModifier：= 1 + (LastEventDaysAgo / 7) × 0.5
  距离上次事件越久，概率越高
```

## 5. Edge Cases

### 5.1 玩家越过未开放区域

**场景**：玩家走到了开发尚未完成的区域边界（版本未开放或预留区域）。

**处理规则：**
- 未开放区域以"有叙事解释的天然屏障"形式呈现——无尽山脉、虚空裂缝、上古结界
- 屏障前有环境叙事提示前路不通（"前方空间扭曲，贸然前进恐有去无回"）
- 不使用突兀的空气墙——所有屏障都有视觉和叙事合理性
- 如果玩家通过bug/外挂越过屏障：
  - 服务端检测到玩家进入了未加载区域
  - 强制执行"空间乱流"效果
  - 将玩家传送回最近的已知安全点
  - 附加临时"空间紊乱"debuff（5分钟内无法使用传送）

### 5.2 区域重叠与过渡带

**场景**：两个相邻区域的边界并非明确的一条线，而是渐变过渡区域。

**处理规则：**
- 过渡带宽度由 `BoundaryTransitionWidth`（默认50m）控制
- 过渡带同时拥有两个区域的轻度特征（混合资源、混合怪物类型）
- 风险等级 = 两个区域的平均值
- 玩家的探索度在两个区域同时推进（但进度减半）
- 动态事件在过渡带有交互可能性——如森林的妖兽潮冲入荒漠区域触发跨区域事件
- 过渡带内的迷雾消散同时影响两个区域

### 5.3 动态事件冲突

**场景**：同一区域同时触发多个动态事件。

**处理规则：**
- 事件优先级：灭世级 > 区域级 > 局部级
- 达到事件槽位上限时：新事件加入等待队列
- 互斥事件检查：系统自动判断事件兼容性
  - 兼容事件（如"商队遇袭"+"雷雨天气"）：叠加触发，互相影响
  - 互斥事件（如"妖兽潮"+"妖兽之王降临"）：合并为连锁事件
- 事件冲突时，世界状态取并集——两个高风险事件叠加可能使区域风险等级临时提升2个级别
- 玩家可选择性参与，不强制响应任何事件

### 5.4 新玩家踏入进行中事件

**场景**：妖兽潮事件正在进行时，一个刚踏入该区域的玩家完全不知情。

**处理规则：**
- 玩家首次踏入事件区域时：弹出事件预警（不同于普通风险预警）
- 告知当前正在发生的事件名称、持续时间和影响范围
- 事件期间的风险等级修正立即应用到 RiskFactor 计算中
- 与事件相关的怪物和NPC对玩家有独立的反应逻辑
- 事件期间的隐藏发现可能与事件主题相关

### 5.5 多人探索同一隐藏点

**场景**：两个玩家同时接近同一个隐藏发现位置。

**处理规则：**
- 每个玩家的隐藏发现有独立的 `_discovered` 实例状态
- 第一个玩家触发后，隐藏点对第一个玩家变为已发现，但对第二个玩家仍然可发现
- 一次性内容（如拾取型宝箱）：第一个玩家拾取后，对第二个玩家表现为"已打开的宝箱"
- 多人组队模式下：发现位置在队伍内共享，队长或发现者可在队伍频道标注

### 5.6 快速旅行被中断

**场景**：传送读条过程中受到攻击。

**处理规则：**
- 读条中受到任何伤害或被控制技能命中 → 打断
- 不消耗灵石，不进入冷却
- 触发"传送紊乱"debuff（30秒内禁止传送）
- PVP区域：其他玩家可看到读条并主动打断
- 玩家移动不打断读条（防止误操作），但快速移动（闪避/冲刺）打断

### 5.7 战斗状态下跨越区域边界

**场景**：玩家被怪物追击，后退跨过了区域边界。

**处理规则：**
- 怪物有活动范围绑定，追到边界后仇恨丢失并返回
- 跨入区域的怪物与当前区域的关系影响行为：
  - 新区域风险低于怪物所在区域：怪物因"环境不适"加速返回
  - 新区域风险远高于怪物所在区域：怪物畏惧不前
  - 两个区域为友好势力关系：守卫NPC可能协助玩家

### 5.8 玩家死亡在无据点的未知区域

**场景**：玩家越级冒险进入高危险区域，被秒杀，但该区域没有任何已发现的据点。

**处理规则：**
- 复活点选择：最近的已探索安全点（不一定是当前区域内）
- 如果整个区域无安全点：回到相邻区域的最近安全点
- 死亡后该区域的风险预警不会再次弹出——但世界地图上会标记一个"死亡记录点"
- 死亡修为损失按风险因子计算：`LossMultiplier = 1.0 + RiskFactor × 0.5`

### 5.9 高等级玩家回访低等级区域

**场景**：金丹期玩家回到新手村所在的低等级区域。

**处理规则：**
- 风险等级显示为"安全"，RiskFactor 接近0
- 探索经验极少（RiskMultiplier ≈ 1.0，BaseRegionXP 低）
- 怪物不主动攻击（境界差距过大时AI判定为"不可战胜"）
- 隐藏发现仍然可触发（已错过的不会自动补发）
- 区域声望系统正常运作
- 传送费用降低（RegionRiskFactor ≈ 1.0）

## 6. Dependencies

### 6.1 直接依赖（必须就绪）

| 依赖系统 | 关系说明 | 需要的接口 |
|---------|---------|-----------|
| 场景加载系统 | 区域切换时的场景加载管理与过渡动画 | 区域边界数据、加载进度UI |
| 玩家状态 | 提供玩家境界、属性数据用于风险计算和发现检测 | CultivationStage、PerceptionStat、Inventory |
| 时间/天气系统 | 影响隐藏发现条件、风险等级修正、事件概率 | TimeOfDay、WeatherType、SpecialAstralEvent |

### 6.2 间接依赖（涉及联动）

| 依赖系统 | 关系说明 |
|---------|---------|
| 门派系统（FactionSystem） | 门派控制区域的门派声望影响玩家在该区域的待遇 |
| 副本系统（DungeonEntrance） | 地图上显示副本入口位置，探索度计入区域探索度 |
| BOSS系统 | 区域领主/野外BOSS作为区域生态的一部分，击败影响区域稳定度 |
| 丹药炼器系统 | 区域资源产出是炼器的材料来源，与采集系统联动 |
| 渡劫系统 | 天劫台等渡劫地点位于特定区域 |
| 快速旅行（FastTravel.cs） | 新地图系统提供传送点数据，FastTravel执行传送逻辑 |
| 隐藏发现（HiddenDiscovery.cs） | 新地图系统提供三级发现框架，扩展原有实现 |

### 6.3 依赖链图

```
新地图系统核心
├── 依赖: 场景加载系统（区域切换）
├── 依赖: 玩家状态系统（境界/感知属性）
├── 依赖: 时间/天气系统（条件触发）
│
├── 子系统: 迷雾系统 → 依赖: 地图UI系统
├── 子系统: 发现系统 → 依赖: HiddenDiscovery.cs（扩展）
│                      → 联动: BOSS系统（隐藏BOSS发现）
│                      → 联动: 副本系统（副本入口POI）
│
├── 子系统: 风险评级 → 依赖: 玩家修炼系统（境界数据）
│                      → 联动: 门派系统（区域控制）
│
├── 子系统: 快速旅行 → 依赖: FastTravel.cs（重构）
│                      → 联动: 门派系统（声望限制）
│
├── 子系统: 区域声望 → 联动: 门派系统（关联势力）
│
├── 子系统: 探索深度 → 联动: 所有发现/任务/采集行为
│
└── 子系统: 动态事件 → 联动: BOSS系统（事件BOSS）
                       → 联动: 天气系统（事件触发条件）
```
