## 1. Overview

渡劫系统是玩家修炼之旅的终极考验，也是地球Online六大系统的交汇点。玩家修炼至渡劫期（Tribulation Realm）大圆满后，不再自动触发天劫——而是需要主动前往分布于世界各地的**"天劫台"**（Tribulation Platform）引劫。整个渡劫分三阶段：**雷劫**（物理/装备考验）、**心魔劫**（意志/历史考验）、**天道问心**（哲学/价值观考验），每阶段都依赖玩家在丹药、装备、阵法、门派等系统中的积累。

### 1.1 三大设计原则

| 原则 | 系统含义 |
|------|---------|
| **玩家自选突破时机** | CultivationManager 到达 Tribulation Realm + MaxLayer 后不再自动触发 AttemptBreakthrough，改为检测天劫台交互事件 |
| **系统交汇点** | 读入丹药背包/装备槽/阵法状态/护法列表，综合计算 ReadinessScore，所有外部系统产出的集中验证 |
| **失败不死亡** | 失败时修为跌回大圆满（回退而非清零），获得渡劫经验下次叠加成功率，但触发短暂修为上限锁定 |

### 1.2 与 CultivationManager.cs 的衔接

现有 `CultivationManager.cs` 中 `AttemptBreakthrough(Realm.Tribulation)` 输出"天劫降临"但无实际渡劫玩法。渡劫系统上线后：

- 从 Tribulation → GreatAscension 的突破不再走原有的成功率判定逻辑
- 改为调用 `TribulationManager.StartTribulation(player, platform)`
- `OnRealmBreakthrough` 事件在渡劫成功后触发，替代原有 `AttemptBreakthrough` 的日志输出
- 境界阈值 `_breakthroughThresholds[Realm.GreatAscension] = 10000` 作为渡劫条件验证的参考值
- 原有的 `_breakthroughThresholds` 和 `MaxLayer` 参数继续用于渡劫资格判断

## 2. Player Fantasy

**"我选择命运的时刻"——玩家站在天劫台上俯瞰大地，天道在头顶凝聚雷云，整个世界都聚焦在这一刻。**

### 2.1 七个具体时刻

1. **发现天劫台**：在世界游历中偶然发现一座远古台座，台面刻满雷纹，残留着前人渡劫的焦痕——"我可以在这里渡劫"的认知在玩家脑中生根。这个发现本身就是一个微型冒险成就。

2. **决定引劫**：修炼至渡劫期大圆满后，站在天劫台上按下"引劫"键。天空瞬间变色，天道威压如实质般降临——没有确认弹窗，没有撤回按钮。这是不可撤回的瞬间，玩家的心跳跟着背景音乐加速。

3. **雷劫第一道**：第一道天雷撕裂天空直劈而下，整个屏幕白光一闪——"这就是天劫的力量。"天雷不是站桩挨打的固定伤害，而是需要走位躲避、丹药续命、法宝硬扛的实时操作。每多扛过一道，玩家的信心就多一分。

4. **心魔幻境**：天雷结束，世界突然寂静。下一秒，玩家被拉入幻境——幻境中浮现的是玩家在游戏里做过的关键选择：背叛过的NPC、放过或击杀的Boss、偷学门规功法的代价、见死不救的路人。心魔劫没有标准攻略，每个玩家的心魔都是自己走过的路。

5. **天道问心**：幻境消散后，万籁俱寂。天地之间只剩玩家和一道柔和的光。光中浮现一行文字——"何为道？" 玩家不需要去网上查"正确答案"，因为根本没有正确答案。玩家的真实回答将定义渡劫后道体的特性。

6. **渡劫成功**：金光万道，天道认可。玩家感受到一股前所未有的力量涌入身体——大成期。获得的道体特性将定义玩家后续的游戏风格，散修可能获得令全服侧目的稀有混沌体。

7. **渡劫失败**：最后一道天雷散去，玩家倒在天劫台上。视野模糊，装备碎裂——但没有死。当玩家浑身焦黑地爬起来时，天道在上空留下一道裂痕，仿佛在说"还不够"。修为跌回大圆满，但天道也给了教训和经验。下次再来。

### 2.2 幻想关键词

| 关键词 | 对应的玩家体验 |
|--------|--------------|
| **主动** | 不是系统自动触发，是玩家自己选择和决定的时刻 |
| **准备** | 丹药、装备、阵法、护法——所有积累的集中检验 |
| **紧张** | 天雷越来越密集、心魔越来越真实、成败一线的压迫感 |
| **自省** | 心魔劫让玩家回顾自己在游戏中的选择，产生情感冲击 |
| **塑造** | 天道问心没有标准答案，回答决定玩家独特的道体走向 |
| **成长** | 失败不可怕——每次失败都让下次更接近成功 |
| **殊途** | 散修渡劫更难但如果成功，获得的道体和成就感远超他人 |

## 3. Detailed Rules

### 3.1 天劫台系统（Tribulation Platform）

天劫台是散布在灵气大陆各区域的特殊交互点，玩家需要达到渡劫期大圆满才能激活。

#### 3.1.1 天劫台数据定义

| 字段 | 类型 | 说明 |
|------|------|------|
| platformId | string | 唯一标识（如 "qinyun_tribulation_01"） |
| displayName | string | 显示名称（如 "擎天峰天劫台"） |
| location | Vector3 | 世界坐标 |
| regionId | string | 所属区域ID |
| tier | enum | Normal / Ancient / Secret |
| baseQuality | int (1-2) | 基础道体品质（台座本身决定） |
| difficultyModifier | float (0.6-1.4) | 难度系数倍率 |
| requiredRealm | Realm | 使用要求（Tribulation） |
| cooldownHours | int | 使用后冷却小时数 |
| isPvpZone | bool | 是否PVP区域（结界可被攻击） |
| specialDescription | string | 天劫台背景描述文本 |
| lastUsedTimestamp | DateTime | 上次被使用的时间戳 |

#### 3.1.2 天劫台三种品质

| 类型 | 难度系数 | 基础道体品质 | 冷却(h) | 分布说明 | 特征 |
|------|---------|-------------|---------|---------|------|
| 普通(Normal) | ×1.0 | 1 | 24 | 每个主要区域1-2座，地图可见 | 标准雷纹台座，无特殊效果 |
| 远古(Ancient) | ×1.2 | 2 | 72 | 隐藏/高危险区域，需探索发现 | 体积更大，台座布满远古符文，渡劫时有历史回响叙事，道体品质+1 |
| 隐秘(Secret) | ×0.8 | 1 | 168 | 极少数特殊位置，需隐藏发现 | 天劫动静小，不触发世界公告，不被其他玩家感知 |

#### 3.1.3 天劫台使用流程

1. **资格检测**：玩家进入天劫台触发范围（10m）后，系统检测是否满足条件
2. **交互提示**：满足条件时出现交互键提示"引劫（按F）"；不满足时显示原因（"需要渡劫期大圆满" / "天劫台冷却中，剩余XX小时"）
3. **确认面板**：按F后弹出渡劫确认面板，包含：
   - 当前 `ReadinessScore`（见3.2节）
   - 预估成功率范围（如"45% ~ 60%"）
   - 该天劫台的名称、背景、特殊效果
   - 列出四类准备的详细清单（已准备/建议项）
   - "引劫"按钮 和 "再准备一下"按钮
4. **弃权**：选择"再准备一下"关闭面板，无任何代价
5. **引劫**：选择"引劫"后，触发渡劫开始。天劫台周围立刻升起结界屏障，天空变色，进入三阶段渡劫

#### 3.1.4 结界规则

- 渡劫开始后，以天劫台为中心半径30m生成结界
- 结界内只有渡劫玩家可活动
- 结界外观为半透明金色光罩，外部可看到内部轮廓
- 结界耐久度：`MaxDurability = 100`
- 结界受攻击规则见5.3节（PVP干扰）

### 3.2 准备系统（Preparation）

玩家渡劫前的准备工作是决定成功率的核心因素。四种准备维度各有不同权重，综合计算 ReadinessScore。

#### 3.2.1 四维准备体系

**丹药（权重 0.25）：**

| 丹药名称 | 效果 | 生效阶段 | 品质影响 | 来源系统 |
|---------|------|---------|---------|---------|
| 渡劫丹 | 全属性+20%，持续渡劫全程 | 全程 | 品级越高属性加成越高 | 炼丹系统 |
| 回血丹 | 雷劫阶段恢复生命值（比例为品质×15% MaxHP） | 雷劫 | 品级决定回复量 | 炼丹系统 |
| 凝心丹 | 心魔阶段意志抗性+30% | 心魔劫 | 品级影响抗性（下品20%/中品30%/上品40%/极品50%） | 炼丹系统 |
| 天道丹(稀有) | 天道问心阶段获得一次"重新回答"机会 | 天道问心 | 无品质影响 | 隐藏配方 |
| 九转还魂丹(传说) | 渡劫失败时不损失任何修为 | 失败时 | 唯一传说品质 | 唯一制作/世界事件 |

规则：
- 每种丹药在渡劫中只生效一次
- 丹药抗性在渡劫中独立计算（不与常规药抗共享）
- 渡劫中使用丹药有3秒公共冷却

**装备（权重 0.30）：**

| 装备名称 | 效果 | 品质影响 | 来源系统 |
|---------|------|---------|---------|
| 抗雷甲 | 天雷伤害减免 | R:20%/SR:30%/SSR:40%/UR:60% | 炼器系统/BOSS掉落 |
| 避雷靴 | 移动速度+15%，有概率完全闪避天雷 | SR:5%/SSR:10%/UR:15% | 炼器系统 |
| 辟邪佩 | 心魔强度-20%，意志受击扣减-20% | 全品质统一 | 副本掉落 |
| 定心冠 | 心魔劫清醒时间窗口延长+3秒 | 品质越高延长越多 | 门派贡献兑换 |
| 天机镜(传说) | 天道问心阶段显示回答选项的潜在影响 | 唯一 | 隐藏BOSS掉落 |
| 替身傀儡(消耗品) | 自动承受一道致命天雷 | 单次消耗 | 炼器系统 |

装备评分公式：`EquipmentScore = 各装备位品质等级总和 / 满分配置品质等级总和`（满配：6个有效装备位均为UR）

**阵法（权重 0.20）：**

| 阵法名称 | 效果 | 来源系统 |
|---------|------|---------|
| 雷纹防御阵 | 每道天雷吸收15%伤害转化为灵气 | 阵法系统（需补充实现） |
| 宁心静气阵 | 心魔幻境清晰度降低，破解成功率+10% | 阵法系统 |
| 天道共鸣阵 | 天道问心契合度+0.15（影响最终附魔） | 宗门阵法传承 |
| 四象护法阵(门派专属) | 护法效果+25%，仅限门派弟子使用 | 门派阵法传承 |

规则：
- 玩家需要提前在天劫台周围3个固定阵眼位置布置阵法
- 每个阵眼可放置一个阵法卷轴，消耗对应布阵材料
- 阵法在渡劫期间持续生效，但可能被天雷破坏（每承受一道天雷有10%概率被破坏一个阵眼）
- 散修不可使用门派专属阵法

**护法（权重 0.25）：**

| 护法类型 | 效果 | 上限人数 | 来源系统 |
|---------|------|---------|---------|
| 同门护法 | 每名提供天雷减伤+3% | 门派弟子最多4人 | 门派系统 |
| 长老护法 | 雷劫阶段每30秒自动恢复10%生命 | 最多1人 | 门派贡献/声望 |
| 挚友护法 | 替玩家承受一道天雷（自动触发） | 最多1人 | 社交系统/NPC好感 |
| 机关傀儡 | 承受前3道天雷（被破坏后无效） | 最多2具 | 炼器系统 |
| 雇佣兵护法 | 效果为门派护法的70%，费用更高 | 散修最多3人（总护法上限） | 散修联盟/悬赏系统 |

规则：
- 护法在渡劫开始前邀请/布置完毕，位置固定在天劫台结界外
- 护法进入渡劫后不可移动、不可更换
- 护法被击杀/离开后，对应效果立即消失，不可补充
- 护法自身在护法期间受到保护（不会被天雷意外击杀）

#### 3.2.2 散修准备限制

| 维度 | 门派弟子 | 散修 |
|------|---------|------|
| 护法上限 | 最多6人（4同门+1长老+1挚友） | 最多3人（雇佣兵） |
| 护法效果 | 100% | 70% |
| 门派阵法 | 可用门派专属阵法 | 仅通用阵法 |
| 长老救援 | 长老可中断渡劫保人（消耗大量贡献） | 无救援机制 |
| **补偿：道体品质+1** | — | 基础道体品质+1 |

#### 3.2.3 准备评分计算

```
各分项得分（0-1区间）：
PillScore = min(已准备渡劫有效丹药种类数 / 5种建议类型, 1.0)
EquipScore = 各装备位的品质等级总和 / 满分配置(6×4=24)   // R=1, SR=2, SSR=3, UR=4
FormScore = 已激活阵法的效果值总和 / 10 （3个满配阵法各最高3.33分）
EscortScore = 已邀请护法人数 / 该路线护法上限

ReadinessScore = Clamp01(
    PillScore × 0.25 +
    EquipScore × 0.30 +
    FormScore × 0.20 +
    EscortScore × 0.25
)
```

ReadinessScore 影响：
- < 0.3：系统强烈建议"准备严重不足，死亡风险极高"
- 0.3 ~ 0.6：基础难度，无额外奖励
- 0.6 ~ 0.8：天雷数量-2，准备加成功率达上限的70%
- > 0.8：天雷数量-4，准备加成功率达上限，幸运一击概率+10%
- = 1.0（完美准备）：额外闪避光环，首道天雷自动闪避

### 3.3 第一阶段：雷劫（Thunder Tribulation）

雷劫是渡劫的第一道鬼门关——天雷连续轰击，强度逐级递增。

#### 3.3.1 天雷机制

**天雷数量：**

```
ThunderCount = 9  // 基础9道
    + (isAncientPlatform ? +3 : 0)    // 远古天劫台更危险
    + (isSolo ? +3 : 0)               // 散修无人分担
    + KarmaPenalty(业力修正, 0 ~ +5)  // 业力越高天雷越多
    - ReadinessBonus(max -4)          // 准备越充分天雷越少
    + MercyDebuff(max +2)             // 失败次数过多时微增
```

**天雷伤害计算：**

```
// 每道天雷基础伤害（匹配玩家自身强度）
BaseBoltDamage = PlayerMaxHP × 0.15 × (1 + RealmFactor)
RealmFactor = (PlayerEffectivePower - 2430) / 2430
// 2430 = 渡劫期基准战力（来自SystemAnalysis的4.5节）

// 逐道递增
BoltDamage_i = BaseBoltDamage × (1 + 0.15)^i
// i = 0, 1, 2, ..., ThunderCount-1

// 减伤后实际伤害
FinalDamage = BoltDamage_i
    × (1 - ArmorReduction)         // 抗雷甲减免
    × (1 - FormationReduction)     // 阵法减免
    × (1 - EscortCount × 0.05)    // 每名护法5%减免
    × (1 - PVPInterference)       // PVP区域受攻击时的额外增伤
```

**天雷预兆：**
- 天雷降落前1.2秒，地面出现直径3m的雷光预兆圈
- 预兆圈由淡蓝变为亮白，越靠近落下时间颜色越亮
- 玩家移动出预兆圈范围可避免直接命中
- 即使走出预兆圈，距离圈边缘≤2m仍受一定溅射伤害

#### 3.3.2 雷劫阶段操作

玩家在雷劫阶段可执行的操作：
1. **移动走位**：无冷却，避开预兆圈核心区域
2. **服用丹药**：使用快捷键服用渡劫丹/回血丹，每种丹药3秒独立冷却
3. **使用防御技能**：如有护盾类功法可额外减伤（30秒冷却）
4. **反击（可选）**：特定雷系功法或法宝可反击天雷，吸收部分能量转化为修为——但反击需要精确时机（天雷落下前0.3秒内按键）

#### 3.3.3 雷劫阶段特殊表现奖励

| 表现条件 | 奖励 |
|---------|------|
| **完美闪避**：未被任何天雷直接命中 | 心魔劫初始难度-15%；道体品质结算+1 |
| **雷能吸收**：成功反击吸收≥3道天雷 | 获得额外修为+渡劫期解锁雷属性主动技能"天雷引" |
| **赤膊渡劫**：无装备/丹药/阵法/护法状态下完成雷劫 | 解锁成就"赤膊渡劫"，道体品质结算+1 |
| **天雷淬体**：不闪避、不使用任何减伤手段扛过全部天雷 | 体质永久+5%（隐藏奖励） |

### 3.4 第二阶段：心魔劫（Heart Demon Tribulation）

天雷结束后，玩家意识被拉入幻境。心魔幻境基于玩家在游戏世界中的行为历史生成，每个玩家面对的心魔都是独一无二的。

#### 3.4.1 心魔生成机制

系统从以下维度扫描玩家历史数据：

| 数据维度 | 来源模块 | 记录内容 |
|---------|---------|---------|
| 道德选择 | AntagonistSystem + 任务日志 | 击杀/放过NPC记录、任务选择偏向 |
| 人际关系 | NPC好感系统 + 社交系统 | 背叛/帮助/无视的关键角色 |
| 修炼方式 | PlayerStats + CraftingSystem | 嗑药获得的修为占总修为比例 |
| 门派关系 | FactionSystem | 叛门历史、门派贡献态度 |
| BOSS交互 | BossSystem | 击杀/谈判/欺骗/绕过BOSS的记录 |
| 重复行为 | 系统日志 | 单一行为重复次数（如刷同一副本>50次） |

#### 3.4.2 七种心魔类型

| 心魔类型 | 触发条件 | 幻境内容 | 考验目标 | 破解关键 |
|---------|---------|---------|---------|---------|
| 悔恨心魔 | 击杀过友好NPC或有过重大任务失败 | 重现被击杀NPC站在面前质问 | 直面过去的选择错误 | 真诚道歉而非辩解 |
| 贪痴心魔 | 嗑药修为占比 > 50% | 幻境中拥有无限丹药，但全部无效 | 放下对捷径的依赖 | 主动放弃所有丹药 |
| 杀戮心魔 | 击杀数 > 区域平均值 × 2 | 被所有已击杀敌人灵魂包围 | 化解内心杀意 | 选择放下武器 |
| 情劫心魔 | 社交/剧情中有深度绑定关系 | 重要的人面临生死抉择 | 超越私情的大爱 | 选择放手而非强留 |
| 背叛心魔 | 有过叛门记录 | 原门派师兄弟和师父围攻质问 | 为自己的选择承担责任 | 不辩解、不后悔 |
| 执念心魔 | 单一行为重复 > 50次 | 无限循环该行为的幻境 | 跳出舒适区和执念 | 主动打破循环模式 |
| 虚无心魔 | 所有玩家都可能触发（保底心魔） | 无尽虚空，绝对的孤独 | 在失去一切后找到存在的意义 | 定义自己的答案 |

玩家触发的心魔数量：`1 + min(符合条件的特殊心魔数, 2)`（1-3个），先触发符合条件的特殊心魔（可多个），最后补充虚无心魔兜底。

#### 3.4.3 心魔劫机制

```
DemonDifficulty = BaseDifficulty × (1 + KarmaModifier × 0.1)
    × (1 - MindResistanceItems)
    - (isSolo ? 0.10 : 0)  // 散修心志更坚韧
```

| 参数 | 说明 |
|------|------|
| BaseDifficulty | 基础难度（取决于玩家境界） |
| KarmaModifier | 业力修正（击杀数/背叛数等，正值增难） |
| MindResistanceItems | 凝心丹(+0.30) + 辟邪佩(+0.20) + 宁心阵(+0.10) |

**意志值系统：**

```
初始意志值 = 100

每次被心魔击中或做出错误选择：
意志值扣减 = 20 × (1 - 总抗性率)
// 总抗性率 = 凝心丹率(0.30) + 辟邪佩率(0.20) + 阵法率(0.10)
// 最大抗性率 0.60，最小扣减 = 20 × 0.40 = 8

意志值 ≤ 0 → 渡劫失败
```

#### 3.4.4 心魔破解方式

每个心魔幻境提供至少3种破解路径：

| 破解方式 | 基础成功率 | 条件说明 | 成功效果 |
|---------|-----------|---------|---------|
| **正面化解** | 60% + 意志属性修正 | 通过对话/行为选择正确应对心魔 | 心魔完全消散，获得心魔对应属性的永久+2%抗性 |
| **强力破除** | 40% | 需要消耗"破妄丹"或有强力神识技能 | 心魔被暴力击碎，无额外奖励但快速通过 |
| **取巧绕过** | 30% | 需发现幻境中的逻辑漏洞或环境可利用物 | 心魔被绕过，但获得"心魔残留"debuff（心魔劫结束后仍有少许负面影响） |
| **求助护法** | 80% | 必须至少有一名护法在线且未被击杀 | 护法感应到玩家心魔波动，远程输送灵力稳定心神 |

心魔劫阶段玩家有3次失误机会——第3次失误或被心魔击中将导致失败。

#### 3.4.5 心魔劫失败细分

| 失败方式 | 触发条件 | 惩罚 |
|---------|---------|------|
| 被心魔吞噬 | 意志值归零或连续3次错误选择 | 修为跌回大圆满 + 上限锁定3天 + "心魔缠身"debuff（7天内修炼速度-20%） |
| 幻境中主动放弃 | 玩家选择放弃 | 修为跌回大圆满 + 上限锁定1天，无额外debuff |
| 被护法强行唤醒 | 意志值≤20时护法触发救援 | 修为跌回大圆满，无锁定，下次渡劫心魔劫难度-10% |

### 3.5 第三阶段：天道问心（Heavenly Dao Questioning）

心魔劫全部破除后，万籁俱寂。天地间浮现一道柔和的金光，天道在玩家面前提出一个终极问题。

#### 3.5.1 问题池

天道根据玩家数据从以下问题库中选择一句（或生成变体）：

| # | 问题 | 适合的玩家类型 |
|---|------|--------------|
| 1 | "何为道？" | 所有玩家（最经典） |
| 2 | "力量为何？" | 战斗/输出导向玩家 |
| 3 | "修行所求为何？" | 探索/收藏导向玩家 |
| 4 | "若天道不公，你当如何？" | 有过叛门/反叛经历的玩家 |
| 5 | "何为善？何为恶？" | 在道德选择中有过挣扎的玩家 |
| 6 | "孤独之路与众人同行，何者为道？" | 散修 or 社交深度玩家 |
| 7 | "若有来生，仍择此路否？" | 有过重大失败/挫折的玩家 |

#### 3.5.2 回答方式

玩家通过以下方式之一回答：
- **文字输入**：自由输入回答文本（PC端支持打字，主机端支持软键盘）
- **选项选择**：每个问题提供4-5个预设回答选项（适配移动端和手柄操作）

选项设计示例（以"何为道？"为例）：

- "道在我心，我即道。" → 道之心=守，力量观=内求
- "道是天地运行的法则，我愿遵循。" → 道之心=守，力量观=外求
- "道是通往至高力量的道路。" → 道之心=破，力量观=外求
- "道无处不在，吾于万物中求道。" → 道之心=离，力量观=兼修
- "我不知道，但我会用一生去寻找。" → 道之心=无，力量观=兼修

#### 3.5.3 解析维度

系统从四个维度解析玩家的回答：

| 维度 | 取值范围 | 解析依据 | 示例 |
|------|---------|---------|------|
| **道之心** | 守 / 破 / 离 / 无 | 回答中的目标指向和态度 | "守护众生"→守 / "打破一切规则"→破 |
| **力量观** | 内求 / 外求 / 兼修 | 力量来源的描述 | "力量在心中"→内求 / "力量来自天地"→外求 |
| **情绪基调** | 积极 / 平静 / 悲壮 / 超然 | 回答的语气和用词色彩 | 包含"希望"→积极 / 包含"坦然"→平静 |
| **执念度** | 强 / 中 / 弱 | 回答的确定性和情感强度 | "绝不后悔"→强 / "或许"→弱 |

#### 3.5.4 道体生成

根据解析结果组合生成道体特性：

**基础特性（由道之心决定）：**

| 道之心 | 道体名称 | 基础特性 |

## 4. Formulas

### 4.1 引劫资格检测

```
CanInitiateTribulation = (
    PlayerRealm == Tribulation &&
    PlayerLayer >= MaxLayer &&
    HoursSinceLastUse >= CooldownHours &&
    currentPlatform.IsActive &&
    currentPlatform.requiredRealm <= PlayerRealm
)
```

### 4.2 渡劫整体成功率

```
TribulationSuccessRate =
    0.30                          // 基础成功率30%
    + ReadinessScore × 0.30       // 准备加成（最高+30%）
    + min(历史失败次数 × 0.05, 0.25)  // 失败经验加成（最高+25%）
    + ClearedDemonCount × 0.05    // 每破解一个心魔+5%
    + DaoAnswerFit × 0.05         // 天道问心契合度+0~5%
    + (ReadinessScore > 0.8 ? 0.10 : 0)  // 完美准备额外+10%
    - (isSolo ? 0.20 : 0)         // 散修惩罚-20%
```

**典型场景参考值：**

| 场景 | 计算过程 | 结果 |
|------|---------|------|
| 裸渡散修 | 30% - 20%(散修) + 0%(无准备) | **10%** |
| 部分准备散修 | 30% + 10%(Readiness=0.35) - 20%(散修) + 5%(1次失败) | **25%** |
| 中等准备门派弟子 | 30% + 18%(Readiness=0.6) + 5%(1次失败) + 5%(1心魔) | **58%** |
| 完美准备门派弟子 | 30% + 30%(Readiness=1.0) + 10%(完美额外) + 15%(3心魔) + 25%(5次失败)+5%(契合) | 约**100%** |
| 多次失败后中等准备 | 30% + 15%(Readiness=0.5) + 25%(5次失败上限) + 10%(2心魔) | **80%** |

### 4.3 准备评分（ReadinessScore）

```
PillScore = min(已备有效丹药种类数 / 5种建议类型, 1.0)
EquipScore = 各装备位品质等级之和 / (6部位 × 4满品质) = 总和 / 24
FormScore = 已布置阵法的总效果值 / 10.0（3个满配各3.33分）
EscortScore = 已邀请护法人数 / 对应路线护法上限(门派6/散修3)

ReadinessScore = Clamp01(
    PillScore × 0.25 +
    EquipScore × 0.30 +
    FormScore × 0.20 +
    EscortScore × 0.25
)
```

### 4.4 天雷伤害

```
// 每道天雷基础伤害（匹配玩家自身强度）
BaseBoltDamage = PlayerMaxHP × 0.15 × (1 + RealmFactor)
RealmFactor = (PlayerEffectivePower - 2430) / 2430
// 2430 = 渡劫期基准战力（来自SystemAnalysis的4.5节）

// 逐道递增
BoltDamage_i = BaseBoltDamage × (1 + 0.15)^i
// i = 0, 1, 2, ..., ThunderCount-1

// 减伤后实际伤害
FinalDamage = BoltDamage_i
    × (1 - ArmorReduction)         // 抗雷甲减免
    × (1 - FormationReduction)     // 阵法减免
    × (1 - EscortCount × 0.05)    // 每名护法5%减免
    × (1 - PVPInterference)       // PVP区域受攻击时的额外增伤
```

### 4.5 心魔劫意志值

```
初始意志值 = 100

单次扣减 = 20 × (1 - 总精神抗性)
总精神抗性 = min(凝心丹(0.30) + 辟邪佩(0.20) + 宁心阵(0.10), 0.60)

实际最大失败前容错：
- 无抗性：100 / 20 = 5次失误
- 全抗性(60%)：100 / (20 × 0.40) = 12.5次失误
```

### 4.6 道体品质

DaoBodyQuality = min(

## 5. Edge Cases

### 5.1 渡劫中玩家断线/退出

**断线保护：**
- 渡劫开始后5分钟内断线：系统判定为"渡劫中断"，按失败处理但不扣修为、不锁上限、不消耗天劫台冷却
- 5分钟后断线：按当前阶段状态判定：
  - 雷劫阶段断线 → 直接判定失败（标准惩罚）
  - 心魔劫阶段断线 → 判定失败（标准惩罚）
  - 天道问心阶段断线 → 默认使用"无心"回答（道之心=无），继续推进至结算

**防止利用：**
- 断线保护每日限1次
- 第2次断线无论时长均按标准失败处理
- 断线与重连的时间戳记录在服务端日志

### 5.2 多人同时在同一座天劫台

- 每座天劫台同一时间只能被一个玩家使用
- 结界升起后，其他玩家无法进入结界范围（但可以看到内部渡劫特效）
- 结界外玩家可以看到：雷云积聚、天雷劈落、金光/黑光结算特效
- 其他玩家不可与渡劫中的玩家进行任何交互（交易、组队邀请、私聊除外）
- 渡劫结束后结界消失，天劫台恢复正常

### 5.3 PVP干扰

- 位于PVP区域的天劫台，结界可被攻击
- 结界耐久度 = 100
- 每造成10点结界伤害，渡劫者雷劫增伤+5%
- 结界耐久度归零：结界破碎，渡劫直接失败（按标准失败惩罚）
- 攻击者获得临时称号"破劫者"（持续24小时）
- **保护区域**：门派控制区域的天劫台结界不可被攻击（安全区）

### 5.4 渡劫时背包满

- 背包满不影响渡劫流程（渡劫不需要背包操作）
- 渡劫成功后如背包满，道体直接应用（不占背包），成就直接发放
- 其他物品奖励通过游戏内邮件系统发放（保留30天）

### 5.5 跨境界回访天劫台

- 已突破至大成期的玩家可回到之前渡劫的天劫台
- 交互触发"重游故地"事件：区域名称浮现+回忆叙事文本+少量修为奖励
- 天劫台对大成期玩家不再可激活（不可重复渡劫同一境界）
- 大成期玩家可观摩其他玩家渡劫（站在结界外观摩位）

### 5.6 使用不同天劫台

- 同一境界只可渡劫一次（渡劫成功后不可再次引劫）
- 在渡劫期大圆满状态下，玩家可前往任意已发现的天劫台
- 不同天劫台冷却独立计算
- 玩家在A台渡劫失败后不受B台冷却影响（可立即去B台尝试）
- 但连续失败积累的"渡劫经验"在所有天劫台共享

### 5.7 隐藏天劫台被多个玩家发现

- 隐藏天劫台被发现后在地图上永久标记
- 所有玩家都可以使用（不是唯一绑定）
- 但隐藏天劫台每次使用后冷却时间更长（7天/168小时）
- 隐藏天劫台不会因为使用者多而降低品质

### 5.8 护法中离

- 护法离场（离线、主动退出、被击杀）→ 该护法提供的减伤和效果立即消失
- 护法离开后不可重新加入该次渡劫
- 长老护法被击杀：停止自动恢复效果
- 挚友护法触发替死效果：自动退出护法状态，不可再次替死
- 机关傀儡被全部摧毁：傀儡护法效果全部消失

### 5.9 天道问心答案解析失败

- 如玩家输入无法被有效解析（纯乱码、表情符号、URL等），系统标记为"无心"
- 道之心=无，力量观=兼修，情绪基调=平静，执念度=弱
- 道体名称为"凡人道体"，品质根据其他条件正常计算
- 玩家可看到解析结果的反馈（"天道对你的回答沉默不语..."）

## 6. Dependencies

### 6.1 直接依赖（必须就绪）

| 依赖系统 | 关系说明 | 需要的接口 |
|---------|---------|-----------|

| 关联系统 | 关系说明 |
|---------|---------|
| **丹药系统**（Alchemy/Crafting） | 提供渡劫丹、回血丹、凝心丹等所有渡劫相关丹药的制作和品级 |
| **装备系统**（Equipment） | 提供抗雷甲、避雷靴等抗雷装备，读取装备数据和减伤属性 |

| **新地图系统** | 提供天劫台的区域分布、发现状态、风险评级影响 |

| **时间/天气系统** | 可选关联：某些时辰/天气影响渡劫难度 |

渡劫系统核心

    └── 失败 → PlayerStats修为回退 + 锁定状态
