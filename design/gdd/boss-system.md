## 1. Overview

BOSS 战系统是地球Online中最高密度的战斗体验容器。它重新定义了"BOSS 战"——不是血条倍数+大伤害的数值堆砌，而是每个 BOSS 都有独特的行为机制、可侦察的弱点、多阶段的战斗转换、以及四种完全不同的应对路径（正面战斗、外交谈判、智取规避、召唤援军）。BOSS 是地图生态的顶点——每个区域至少有一个区域领主 BOSS，副本终点有副本 BOSS，野外有游荡的传说级 BOSS。击败 BOSS 不只是获得更高级的装备——更是解锁新区域、获得独家炼器材料、改变区域势力格局的关键事件。系统同时引入"BOSS 记仇"机制：撤退或谈判失败都会影响下次遭遇，让每一次相遇都带有叙事重量。

## 2. Player Fantasy

**"面对不可战胜之物"——每一次 BOSS 遭遇都是一场微型史诗。**

核心幻想是：当 BOSS 出场的那一刻——屏幕震动、名号浮现、专属 BGM 响起——玩家知道这不是普通战斗。这是一个"事件"。玩家需要暂停下来思考：我该怎么打？

### 2.1 具体时刻

**第一次见到 BOSS 的震撼**：你走进一个山洞深处，突然脚下地面开始震动。前方黑暗中亮起两只巨大的眼睛，宛如灯笼。屏幕中央浮现火焰般燃烧的字体——"千年火蛟 · 金丹期 · 烈焰谷领主"。一瞬间你的脑中只有一个念头：跑。但你没有跑——你开始仔细打量它的动作，寻找破绽。

**侦察弱点的侦探快感**：你花了一小时观察这个 BOSS，记录它的攻击模式。你发现它每次喷火后头部会有3秒的停顿——这就是弱点窗口。你不需要硬碰硬，你只需要找准时机。这不是数值碾压，这是"我比你聪明"的胜利。

**智取成功的成就感**：你没有正面战斗——你把 BOSS 引到悬崖边的捕兽陷阱上，让它自己踩进去。或者你找到了一株它最讨厌的草药，在上风处点燃，烟雾驱散了它的护体灵气。BOSS 没有被打败——是被"搞定"了。这比打死它更让人满足。

**谈判的博弈感**：面对一个智慧的 BOSS——一个活了千年的树精、一个被封印的古代修士——你可以选择对话。你交出了之前任务中获得的宝物，换取了和平通过。你不知道这个选择是对是错，但你在赌。当 BOSS 让开道路时，那种"我凭着话语而非武力征服了它"的感觉无与伦比。

**逃跑的尊严**：你打不过它。你判断了形势，认清了实力的差距，在 BOSS 还剩70%血量时选择了撤退。这并非失败——这是"明智的撤退"。BOSS 记住你了。下次来的时候，它会在你踏入区域第一秒就认出你，直接进入狂暴状态。但你也记住了它的所有招数——公平。

**击败的狂欢**：当 BOSS 最后一阶段倒下时，屏幕中央出现"击杀！"的大字，慢动作、金色光柱冲天而起、附近所有玩家收到公告。掉落物不是平淡地出现——是炸裂开的，伴随着 BOSS 最后的怒吼、叹息或遗言。你获得的不仅是一件装备——是这个区域的一段传说的终结者称号。

### 2.2 幻想关键词

| 关键词 | 对应的玩家体验 |
|--------|--------------|
| 震撼 | BOSS出场时那一刻的视觉冲击和BGM切换 |
| 侦察 | 观察和学习BOSS行为模式的侦探感 |
| 智取 | "不是最强的人赢，而是最聪明的人赢" |
| 博弈 | 谈判时的选择困境——交出还是战斗？ |
| 尊严 | 逃跑不是失败，是战术选择 |
| 狂欢 | 击败瞬间的视觉和音效爆发 |
| 传说终结 | 每个BOSS都是一段区域的传说的终点 |

## 3. Detailed Rules

### 3.1 BOSS 分类

| 类型 | 特征 | 位置 | 刷新规则 | 示例 |
|------|------|------|---------|------|
| 区域领主 | 该区域的顶点生物，击败后区域稳定度提升 | 区域最深处/最高处 | 3-7游戏日刷新 | 烈焰谷的火蛟 |
| 副本 BOSS | 副本终点 | 副本最后一间房 | 每次副本重置 | 血池中的尸王 |
| 野外游荡 BOSS | 在特定路线巡逻，不固定位置 | 区域内巡逻路线 | 7-14游戏日刷新 | 流沙荒漠的沙蝎王 |
| 世界 BOSS | 全服事件触发，需要多人 | 特殊事件位置 | 触发后限时存在 | 虚空入侵者 |
| 隐藏 BOSS | 满足特定条件才会出现 | 隐藏区域 | 唯一（不刷新） | 上古剑灵 |
| 任务 BOSS | 特定任务链的终点 | 任务指定位置 | 不刷新 | 叛逃的长老 |

### 3.2 BOSS 数据结构

```
BossDef
├── bossId: string                    — 唯一标识
├── displayName: string               — BOSS名号
├── title: string                     — 称号（如"烈焰谷领主"）
├── realm: int                        — 境界等级
├── bossType: enum                    — 类型
│
├── maxHP: int                        — 最大生命值
├── phases: PhaseDef[]                — 阶段转换定义
├── weaknesses: WeaknessDef[]         — 弱点列表
├── mechanics: MechanicDef[]          — 独特机制列表
│
├── detectRange: float                — 索敌范围
├── aggroRange: float                 — 进入战斗范围
├── leashRange: float                 — 脱离战斗范围
│
├── diplomacy: DiplomacyDef | null    — 外交选项
├── stealthVulnerable: bool           — 是否可潜行绕过
├── environmentalHazards: string[]    — 可利用的环境陷阱
│
├── drops: DropTable                  — 掉落表
├── firstKillRewards: SpecialReward   — 首杀奖励
│
├── respawnTime: int                  — 刷新间隔（游戏天）
├── spawnCondition: string | null     — 特殊出现条件
│
├── factionAffiliation: string | null — 所属势力
└── storyContext: string              — BOSS的背景故事
```

### 3.3 BOSS 行为机制

#### 3.3.1 基础行为循环

所有 BOSS 遵循统一的行为循环：

```
巡逻（待机）→ 发现玩家 → 警戒（出场动画）→ 战斗（多阶段）→ 胜利/撤退/死亡
```

**巡逻（待机）：**
- 区域领主：在领地内按固定路线巡逻
- 野外游荡：在巡逻路线上移动
- 副本 BOSS：在终点房间内待机，玩家进入房间后触发
- 隐藏 BOSS：在触发条件满足前完全不可见

**发现与警戒：**
- 玩家进入 `detectRange` 时 BOSS 感知到玩家
- 不立即攻击——BOSS 进入警戒状态
- 播放出场动画（3-5秒）：屏幕震动、名号浮现、BGM 切换
- 出场动画期间玩家可操作：选择撤退、准备战斗、或尝试绕行

**进入战斗：**
- 玩家进入 `aggroRange` 或主动攻击 → 战斗开始
- 封闭战斗区域：入口封锁直到战斗结束
- 开放战斗区域：玩家可自由进出

#### 3.3.2 阶段转换（Phase Transition）

每个 BOSS 至少有1个阶段转换点（至少2个阶段），最多4个阶段。

**触发条件：**

| 触发类型 | 说明 | 默认值 |
|---------|------|-------|
| 血量阈值 | BOSS 血量降至 X% 时触发 | 70% → 二阶段，35% → 三阶段 |
| 时间触发 | 战斗持续超过 X 秒后触发 | 300秒 → 狂暴阶段 |
| 行为触发 | 玩家完成特定行为后触发 | 破坏护盾 → 虚弱阶段 |
| 环境触发 | 环境变化后触发 | 夜晚降临、事件引爆 |

**阶段转换定义：**

```
PhaseTransition
├── triggerType: enum           — HP / Time / Behavior / Environment
├── triggerValue: float         — 触发值
├── newMechanics: MechanicDef[] — 新增机制
├── removedMechanics: string[]  — 移除机制
├── newAttacks: AttackDef[]     — 新增攻击技能
├── visualChange: VisualDef     — 外观变化
├── dialogue: string            — 阶段台词
└── dropCheckpoint: bool        — 是否在此阶段生成阶段性掉落
```

**阶段设计原则：**
- 每个阶段增加招式复杂度，而非单纯增加数值
- 阶段间有"模式变化"的明显视觉提示（颜色、特效、模型变化）
- 阶段转换时 BOSS 有几秒不可攻击的动画窗口——玩家的"喘息窗口"
- 阶段台词提供机制提示（"你以为这就结束了？"暗示还有更多）

#### 3.3.3 BOSS 独特机制

每个 BOSS 应有至少1个（通常2-3个）独特机制。

**灵气大陆主题机制库（可扩展）：**

| 机制名称 | 描述 | 应对方式 |
|---------|------|---------|
| 灵气护盾 | BOSS 被灵气护盾保护，吸收常规伤害 | 摧毁场景中的灵气水晶解除护盾 |
| 地火涌动 | 战斗中地面随机喷发火焰 | 观察地面裂缝预判并躲避 |
| 召唤护卫 | BOSS 周期性召唤小怪助战 | 控制小怪或优先处理召唤点 |
| 吸取灵力 | BOSS 每10秒吸取玩家灵力 | 储备灵力药或使用"封灵"技能 |
| 镜像复制 | BOSS 生成玩家镜像 | 调整装备或控制输出节奏 |
| 环境锁定 | BOSS 锁死天气/时间（如"永夜"） | 利用变化触发机制转换 |
| 弱点暴露 | 特定攻击后弱点暴露X秒 | 抓住时机爆发输出 |
| 天雷引 | BOSS 引天雷轰击全区域 | 躲入避雷位置 |
| 阵法领域 | 地面展开阵法领域，领域内属性增强 | 破坏阵眼或拉出范围 |
| 神魂链接 | 链接到场景物体，链接期间部分免伤 | 优先破坏场景物体 |

#### 3.3.4 BOSS 弱点系统

每次 BOSS 遭遇之前（或战斗初期），玩家可以"侦察"BOSS 的弱点。

**弱点获取方式：**

| 方式 | 成功率 | 信息量 | 风险 |
|------|--------|-------|------|
| 远距离观察 | 自动 | 基础（攻击模式） | 无 |
| 望气术技能 | 高 | 中等（属性和弱点类型） | 消耗灵力 |
| NPC 购买情报 | 100% | 完整（含推荐打法） | 花费灵石 |
| 战斗试探 | 中 | 中等 | 受到伤害 |
| 前置任务链 | 100% | 完整+额外信息 | 任务耗时 |

**弱点类型：**

| 弱点类型 | 效果 | 示例 |
|---------|------|------|
| 属性相克 | 特定属性攻击 ×2 伤害 | 冰系克火蛟 |
| 时机弱点 | 特定动作后 X 秒内增伤50% | 喷火后头部僵直 |
| 部位破坏 | 攻击特定部位可中断机制 | 击破尾部阻止扫尾 |
| 道具克制 | 使用特定道具削弱 BOSS | "避火丹"让火伤-50% |
| 环境利用 | 场景陷阱造成额外伤害 | 引 BOSS 撞击钟乳石 |
| 恐惧因素 | BOSS 害怕某种事物 | 火蛟怕麒麟吼 |

**弱点对战斗的影响：**
- 发现弱点后 UI 显示弱点提示（"弱点：冰系攻击 ×2"）
- 针对弱点的攻击有额外视觉特效
- 弱点利用成功时有额外奖励（击退、打断、额外掉率）
- 完全使用所有弱点击败 BOSS → 触发"完美狩猎"（掉落品质提升一档）

### 3.4 四种应对路径

这是 BOSS 系统的核心设计。面对 BOSS 时，玩家有四种选择：

#### 路径一：正面战斗（Fight）

**流程：**
1. 侦察弱点
2. 准备克制道具/丹药/装备
3. 进入战斗区域触发战斗
4. 经过多阶段战斗击败 BOSS

**奖励：** 100% 掉落 + 修为 + 区域声望 + "击败者"称号

**风险：** 死亡惩罚、消耗大量资源

**适用玩家：** 战力充足的玩家、需要完整掉落、追求成就感

#### 路径二：外交谈判（Diplomacy）

**适用条件：** BOSS 必须有 `diplomacy` 字段（非狂暴型、有智慧的 BOSS）。

**流程：**
1. 在警戒范围外选择"尝试对话"
2. BOSS 回应并提出的条件（物品/信息/承诺）
3. 玩家选择接受或拒绝：
   - 接受条件 → BOSS 让路，和平通过
   - 拒绝条件 → 战斗（BOSS 被激怒，初始阶段+1）
   - 试图欺骗 → 交涉判定，失败则战斗且仇恨翻倍

**谈判条件示例：**
- 交出特定物品（任务道具、稀有灵材、灵石）
- 承诺办一件事（杀其他 BOSS、解除区域诅咒）
- 提供情报（关于虚空的线索）
- 发誓不破坏该区域的环境

**奖励/结果：**
- 无掉落（BOSS 没死）
- BOSS 好感度+50（下次谈判更容易、可能解锁隐藏剧情）
- 获得该区域的"安全通行权"
- BOSS 可能提供稀有情报或任务线索
- 不获得修为

**注意：** 谈判后 BOSS 所属势力对该玩家声望+50，对立势力声望-30。

#### 路径三：智取规避（Stealth / Cheese）

**适用条件：** BOSS 视野可被遮蔽、有环境可以利用。

**规避方式：**

| 方式 | 基础成功率 | 要求 |
|------|-----------|------|
| 潜行绕过 | 60% | 潜行技能 |
| 机关陷阱 | 70% | 关键道具 |
| 引开 BOSS | 80% | 引诱道具 |
| 环境遮蔽 | 90% | 特定技能或天气 |
| 发现隐藏路径 | 100% | 探索发现 |

**判定公式：**
```
StealthSuccess = 0.6 × (1 + 潜行等级×0.01 + 装备潜行加成) - BOSS感知 × 0.02
```

**奖励/结果：**
- 少量经验（"成功规避危险"）
- 无掉落、无修为
- BOSS 不记仇
- 区域声望 +5

**失败后果：**
- 潜行被发现：进入战斗，BOSS 好感度-30
- 机关失败：BOSS 第一阶段攻击力+20%
- 引诱失败：BOSS 警戒状态延长

#### 路径四：召唤援军（Summon Allies）

**援军类型：**

| 类型 | 获取方式 | 数量 | 战力 | 消耗 |
|------|---------|------|------|------|
| NPC 盟友 | 任务结交的NPC | 1-2 | 中等 | 援军额度 |
| 门派弟子 | 门派贡献召唤 | 2-5 | 随门派等级 | 门派贡献值 |
| 召唤符 | 道具消耗 | 1-3 | 符咒决定 | 符咒本身 |
| 临时组队 | 区域喊话 | 3-5 | 不等 | 掉落分配 |

**流程：**
1. 战斗开始前或战斗中使用援军道具/技能
2. 援军出现在战场并投入战斗
3. 援军有自己的 AI，会受伤也会撤退
4. 援军倒下后无法再次召唤

**奖励/结果：**
- 掉落正常获得
- 修为略微稀释（-10%~-30%）
- NPC 盟友好感度提升
- 门派贡献消耗

### 3.5 战斗环境

#### 3.5.1 战斗区域类型

| 类型 | 进入锁定 | 逃跑机制 | 示例 |
|------|---------|---------|------|
| 封闭区域 | 战斗开始后入口关闭 | 必须击败BOSS或使用逃脱道具 | 副本BOSS房间 |
| 开放区域 | 不锁定 | 跑出leashRange即可 | 野外BOSS |
| 半封闭区域 | 入口关闭但可绕行 | 有隐藏出口 | 山洞中的区域领主 |

#### 3.5.2 环境交互

每个 BOSS 战斗区域至少包含1个环境互动要素：

- **可破坏物体**：石柱（砸到 BOSS 造成眩晕）
- **可利用陷阱**：预设捕兽夹、坠落陷阱
- **灵气节点**：引导灵气对 BOSS 造成额外伤害
- **治疗泉**：玩家可短暂恢复
- **战术掩体**：可躲避范围攻击

### 3.6 BOSS 掉落与材料

#### 3.6.1 掉落表结构

```
DropTable
├── guaranteed: DropEntry[]       — 必定掉落
├── normal: WeightedDrop[]        — 概率掉落
├── conditional: ConditionDrop[]  — 条件掉落
├── lootLevelModifier: float      — 玩家境界影响系数
├── partySizeModifier: float      — 组队影响系数
└── firstKillBonus: SpecialDrop[] — 首杀专属
```

**必定掉落：**
1. BOSS 独特材料（炼器系统的高级配方输入）
2. 灵石（数量与 BOSS 境界成正比）
3. 修为结晶（直接增加修为）

**概率掉落：**
- 装备（SR / SSR / 极小概率 UR）
- 配方卷轴（本 BOSS 相关的炼器配方）
- 稀有材料（装备强化用）
- 技能书/功法残页

**条件掉落（需额外达成）：**
- 无伤击败：掉率+20%
- 完美狩猎（所有弱点利用）：UR 材料 100% 掉落
- 首杀：专属称号 + 特殊物品
- 五分钟内击杀：额外稀有物品

#### 3.6.2 BOSS 材料与炼器系统联动

BOSS 掉落物是 SSR/UR 级炼器的核心材料来源。

| BOSS 名 | 核心掉落材料 | 关联配方 |
|---------|-----------|---------|
| 千年火蛟 | 火蛟鳞片、火蛟内丹 | 火蛟鳞甲(SSR)、烈焰丹(SSR) |
| 冰原狼王 | 冰牙、狼王毛皮 | 冰霜之刃(SSR)、冰心丹(SSR) |
| 上古剑灵 | 剑意碎片、灵核 | 剑意传承(UR)、灵蕴护符(SSR) |
| 虚空入侵者 | 虚空结晶、混沌核 | 虚空之刃(UR)、混沌之戒(UR) |

**设计原则：**
- 每个 BOSS 至少产出2种独特材料
- 这些材料是特定 SSR/UR 配方的"必需材料"（不可替代）
- BOSS 材料有"品质"——击杀表现越好材料品质越高（影响最终炼器品质）
- 材料可交易——形成玩家间的 BOSS 材料市场

### 3.7 BOSS 记仇系统

BOSS 的"记忆"和"态度"是该系统的核心叙事层。

#### 3.7.1 记仇触发

| 行为 | 记仇值 | 说明 |
|------|--------|------|
| 战斗中逃跑（跑出leashRange） | +1 | "你逃了" |
| 谈判反悔后攻击 BOSS | +2 | "你欺骗了它" |
| 潜行被发现 | +0.5 | 累积性 |
| 击杀 BOSS 同族 | +3 | "你杀了它的同类" |
| 击杀 BOSS 子嗣 | +4 | 上限触发 |

#### 3.7.2 记仇等级效果

| 记仇等级 | 条件 | 效果 |
|---------|------|------|
| 0 | 无 | 正常状态 |
| 1（警惕） | ≥1 | BOSS 视野+15%，潜行更难 |
| 2（记恨） | ≥2 | BOSS 初始狂暴，额外招式+1 |
| 3（仇恨） | ≥3 | 索敌范围翻倍，优先攻击该玩家 |
| 4（宿敌） | ≥4 | 跳过出场动画直接进入最终阶段 |

#### 3.7.3 记仇恢复

| 方式 | 恢复量 | 说明 |
|------|--------|------|
| 成功击杀 BOSS | 归零 | BOSS 死了，记仇清零 |
| 完成和解任务 | 归零 | 接受 BOSS 的考验任务 |
| 每30天不进入该区域 | -1 | "时间冲淡一切" |
| 使用易容术/改名符 | 归零 | 更换身份 |

### 3.8 战斗撤退规则

撤退不是"逃跑"——它是有代价的选择。

| 撤退方式 | 成功率 | 代价 |
|---------|--------|------|
| 直接转身跑出leashRange | 需不被追上 | BOSS记仇+1，受追击伤害 |
| 使用逃脱道具（遁地符） | 100% | 消耗道具，BOSS记仇+1 |
| 使用传送 | 战斗中不可用 | — |
| 谈判脱身 | 需BOSS可谈判 | 付出谈判代价 |

**撤退后：**
- BOSS 血量恢复至满血
- 如果 BOSS 是区域领主且被激怒：该区域普通怪物攻击性+20%，持续1游戏日
- BOSS 的仇恨列表锁定玩家 ID

### 3.9 组队战斗规则

- 最多5人组队
- BOSS 的 HP 按人数缩放：`HP = BaseHP × (1 + (PartySize-1) × 0.4)`
- 伤害不缩放（组队不是让战斗更容易，而是让更多人可以参与）
- 仇恨系统按威胁值计算（非随机）
- 掉落分配：自由拾取 / 队伍分配 / 需求优先

### 3.10 BOSS 与地图/事件联动

**击败区域领主后的区域影响：**
- 普通怪物密度-20%（持续到BOSS刷新）
- 区域探索度+5%
- 区域声望对所有玩家+20（持续3游戏日）
- 可能解锁新的隐藏区域（BOSS守护的入口）

**BOSS 与动态事件：**
- 主动型：事件中召唤或加强 BOSS
- 被动型：事件影响 BOSS 行为
- 连锁型：击败某BOSS触发后续事件

## 4. Formulas

### 4.1 BOSS 基础属性公式

```
BossHP = BaseHP × RealmMultiplier × PartySizeMultiplier
BossAttack = BaseAttack × RealmMultiplier
BossDefense = BaseDefense × RealmMultiplier
```

**RealmMultiplier（境界系数）：**
```
练气=1.0, 筑基=1.5, 金丹=2.5, 元婴=4.0, 化神=6.5, 渡劫=10.0, 大成=16.0
```

**PartySizeMultiplier（组队系数）：**
```
1人=1.0, 2人=1.4, 3人=1.8, 4人=2.2, 5人=2.6
```

### 4.2 境界压制公式

```
DamageMultiplier = 
  玩家境界 > BOSS境界：1.0 + (玩家境界 - BOSS境界) × 0.15
  玩家境界 = BOSS境界：1.0
  玩家境界 < BOSS境界：1.0 - (BOSS境界 - 玩家境界) × 0.25 (最低0.1)
```

示例：
- 筑基玩家（境界2）打金丹 BOSS（境界3）：1.0 - (3-2) × 0.25 = **0.75**（75%伤害）
- 练气玩家（境界1）打元婴 BOSS（境界4）：1.0 - (4-1) × 0.25 = 0.25，但最低0.1 → **0.1**（10%）

### 4.3 弱点加成公式

```
WeaknessDamage = 原始伤害 × WeaknessMultiplier
```

| 弱点利用 | WeaknessMultiplier |
|---------|-------------------|
| 属性相克 | 2.0 |
| 时机弱点 | 1.5 |
| 部位破坏 | 1.3 |
| 道具削弱 | BOSS防御降低30%（间接增伤） |
| 环境陷阱 | BOSS最大HP的5%-15%固定伤害 |

**完美狩猎判定：**
```
PerfectHunt = 使用了≥3个已知弱点 + BOSS未进入狂暴阶段 + 玩家未撤退
→ 掉落品质强制提升一档（SR→SSR, SSR→UR）
```

### 4.4 掉落概率公式

```
ItemDropChance = BaseChance × LuckMultiplier × PartyBonus × PerfectHuntBonus × FirstKillBonus

其中：
  BaseChance = 掉落表定义的基础概率（0~1）
  LuckMultiplier = 1.0 + 玩家幸运×0.01
  PartyBonus = 1.0 + (PartySize-1) × 0.1
  PerfectHuntBonus = 完美狩猎时 ×1.5
  FirstKillBonus = 首次击败 ×2.0
```

**SSR/UR 基础掉落概率（对照表）：**

| BOSS 类型 | SSR 基础概率 | UR 基础概率 |
|-----------|-------------|-------------|
| 区域领主 | 15% | 3% |
| 副本 BOSS | 12% | 2% |
| 野外游荡 | 10% | 2% |
| 世界 BOSS | 25% | 8% |
| 隐藏 BOSS | 30% | 15% |

### 4.5 记仇值公式

```
GrudgeLevel = Clamp(累计记仇值, 0, 4)

衰减规则：
  if 未进入该BOSS区域 ≥30天: GrudgeLevel -= 1 (最多减至0)
  if 完成和解任务: GrudgeLevel = 0
  if 击败BOSS: GrudgeLevel = 0 (BOSS死亡)
```

### 4.6 谈判判定公式

```
NegotiateSuccess = 0.5 + CharismaBonus + ReputationBonus - GrudgePenalty

其中：
  CharismaBonus = 玩家魅力 × 0.005
  ReputationBonus = 玩家在该BOSS所属势力的声望/1000 (最高+0.3)
  GrudgePenalty = GrudgeLevel × 0.1
```

### 4.7 潜行规避公式

```
StealthSuccess = 0.6 + StealthLevel × 0.01 + EquipmentBonus - BossPerception × 0.02
```

- `StealthLevel` = 玩家潜行技能等级
- `EquipmentBonus` = 潜行装备加成（0~0.3）
- `BossPerception` = BOSS 感知属性（20~100）

### 4.8 BOSS 击杀修为公式

```
BossKillXP = BaseRealmXP × FirstKillMultiplier × ContributionMultiplier × PartySizePenalty

其中：
  BaseRealmXP：练气=500, 筑基=2000, 金丹=8000, 元婴=32000, 化神=128000
  FirstKillMultiplier：首次击杀×2，之后×1
  ContributionMultiplier：玩家对BOSS的伤害占比（0~1）
  PartySizePenalty：1人=1.0, 2人=0.7, 3人=0.5, 4人=0.4, 5人=0.3
```

## 5. Edge Cases

### 5.1 玩家比 BOSS 境界高出太多

**场景**：大成期玩家回来打练气期的区域领主。

**处理规则：**
- 境界差超过2级时 DamageMultiplier 上限10倍
- BOSS 几乎被秒杀
- 掉落不受影响
- 但 BOSS 不产出高境界装备（仍是低级材料）
- 系统提示："这个 BOSS 对你来说已经不够格了。"（避免刷低级 BOSS 成为最优解）

### 5.2 其他玩家干扰 BOSS 战

**场景**：玩家 A 正在打 BOSS，玩家 B 路过并加入战斗或抢怪。

**处理规则：**
- 首次攻击 BOSS 获得"所有权"（持续30秒无攻击则失去）
- 非组队加入：BOSS 不增加血量
- 掉落归属：对 BOSS 造成伤害最高者获得所有权
- PVP 区域：其他玩家可攻击正在打 BOSS 的玩家
- 非 PVP 区域：BOSS 区域保护（无法攻击打 BOSS 的人）

### 5.3 组队队员中途离开

**场景**：组队打到一半，一个队员掉线或主动退出。

**处理规则：**
- BOSS 的 HP 不重新缩放
- 剩余队员获得离队者的"遗留贡献"——伤害占比重新计算
- 队长退出：自动转让给下一个在线队员
- 全员离线：BOSS 重置，无掉落（视为全员撤退）

### 5.4 BOSS 被引出活动区域

**场景**：玩家把 BOSS 引出了它的 `leashRange`。

**处理规则：**
- 超出 `leashRange` 后 BOSS 停止追击
- BOSS 播放返回动画后快速回到起始位置
- 返回途中 BOSS 不可攻击
- 回到原位后血量恢复至满血
- 记仇+1

### 5.5 谈判后立即攻击

**场景**：玩家与 BOSS 完成谈判交易后立刻攻击。

**处理规则：**
- 谈判后设有"和平窗口期"（默认30秒）
- 窗口期内攻击 → 触发"背叛"事件：
  - BOSS 记仇直接+4（仇恨上限）
  - BOSS 进入"背叛狂暴"——跳过第一阶段直接进入第二阶段
  - 谈判能力在该 BOSS 所属势力中永久降低
  - 区域声望 -100
- 窗口期后攻击：正常战斗，BOSS 因警觉额外记仇+1

### 5.6 多 BOSS 同时激活

**场景**：玩家同时引到两个邻近 BOSS。

**处理规则：**
- BOSS 有各自的势力范围，通常不会主动走进其他 BOSS 的区域
- 如果真的触发共存：两个 BOSS 互不攻击，玩家同时面对两套机制
- 如果两个 BOSS 为敌对势力：触发"BOSS 互斗"，玩家可坐收渔翁之利

### 5.7 BOSS 刷新时玩家占据刷新点

**场景**：BOSS 刷新时间已到，但玩家站在刷新位置上。

**处理规则：**
- BOSS 刷新时产生"空间挤出"效果——周围5m的玩家/物体被弹开
- 如果站位被锁定控制：BOSS 在最近的可通行位置刷新

### 5.8 环境变化影响 BOSS

**场景**：火蛟 BOSS 在雨天被挑战（火系被克制）。

**处理规则：**
- 环境对 BOSS 有 ±10% HP/攻击修正
- 特定 BOSS 与环境强关联：
  - "火蛟在雨天时火焰伤害-20%，但雷系伤害+20%"
  - "冰狼在月圆之夜全属性+30%"
  - "树精在干旱季节移动速度-50%但恢复+100%"
- 环境变化在出场侦察时即可发现（"天象：雨天，火蛟行动受阻"）

### 5.9 隐藏 BOSS 错过

**场景**：玩家在不满足条件时经过了隐藏 BOSS 的位置。

**处理规则：**
- 隐藏 BOSS 在触发前完全不可见
- 触发了条件但未触发战斗就离开：BOSS 等待——下次来时同样条件仍触发
- 唯一性隐藏 BOSS（一次性）：一旦触发并完成，永久消失
- 如果错过的隐藏 BOSS 是某配方的必需材料来源：提供替代渠道（但难度更高）
