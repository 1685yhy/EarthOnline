## Chapter 1: Overview

多世界系统是地球Online的叙事主骨架，也是所有世界特定系统（修炼、神豪、异能、机甲、神格）的顶层容器。它定义了一套统一的跨世界框架——玩家以"穿越者"身份在不同世界间穿梭，将每个世界获得的力量带回，最终聚合为拯救地球的本钱。

### 1.3 设计原则

1. **一魂多界**：玩家的灵魂（意识）是穿越的唯一载体。每个世界的身体都是在该世界规则下生成的"化身"。灵魂层面的属性（意志力、因果值、记忆）可跨世界携带；物质层面的属性（修为、金钱、异能等级）在本世界独立。
2. **各自精彩**：每个世界的玩法体系完全独立——修真世界的战斗系统、都市世界的商业系统、末日世界的生存系统——玩家在不同世界玩不同的游戏，但因为"同一个灵魂"的叙事锚点而产生归属感。
3. **力量可迁移但需适应**：穿越者可将A世界获得的力量带到B世界，但B世界的规则会"压制"外来力量，需经过适配过程才能还原。适配代价和速度由多个因素决定（见第4章公式）。
4. **世界递进**：解锁顺序有方向性——从低规则密度世界到高规则密度世界（灵气大陆→都市世界→末日废土→星际纪元→神话纪元），但已解锁的世界可自由往返。
5. **因果共通**：玩家在不同世界的行为共同影响一个全局"因果值"——善行和恶行跨世界累计，影响隐藏解锁条件、NPC态度、甚至世界事件的触发概率。

## Chapter 2: Player Fantasy

### 2.1 初临异世幻想

"我在灵气大陆修炼了三百年，终于渡劫大成——等来的不是飞升，而是一道白光将我拉回了穿越者大厅。屏幕上显示：'新世界已解锁：都市世界 1997。'下一秒，我站在深圳南山区的一栋写字楼前，口袋里有500块钱和一张身份证。修真界的元婴修为被压制成了一丝微弱的直觉——我能在谈判中感知对方的真实意图。这就是穿越者的优势吗？'

### 2.2 万界穿梭幻想

"末日废土的异能等级已经升到S级了。但我发现了一个问题——异能到了星际纪元完全不起作用，那里的规则认为'超自然力量不存在'。但我把末日的战斗经验和星际的机甲知识结合起来，设计了一套全新的机甲战斗风格。当我在星际角斗场用废土的搏杀技巧击败纯机械流选手时，观众疯了——'那个从低级世界爬上来的怪物！'"

### 2.3 力量归宗幻想

"五大世界全部通关。神话纪元，我的神格升到主神级。我站在万神殿顶端，面前浮现了最后一个传送门——地球。传送门的另一边是2026年的北京。地球意志的声音在脑海中响起：'你准备好了。'我走进传送门，身上还带着灵气大陆的天雷印记、都市世界的商业直觉、末日废土的战斗本能、星际纪元的旗舰AI、神话纪元的诸神祝福。地球上那个威胁我的存在，你准备好了吗？"

### 2.4 专精一路幻想

"我就待在都市世界。不想去末日那种没外卖没网络的地方。灵气大陆？修炼太累了。我把所有其他世界的传送门任务都放着不做——都市世界的商业帝国已经够我玩一辈子了。系统偶尔弹出'新世界已解锁'，我看一眼，关掉。穿越者联盟里有人骂我浪费名额。但我觉得，在都市世界当首富也是拯救地球的一种方式——我有的是钱雇佣别人去那些危险世界卖命。"

**设计要点：** 专精一路也是一条合法路径。不强制穿越，但需要制造"诱惑"让玩家愿意尝试新世界（每个世界都在解锁后提供初期资源包、福利Buff、或者只有穿越才能获得的稀有物品）。

### 2.5 幻想关键词

| 关键词 | 对应的玩家体验 |
|--------|--------------|
| **跨世界身份** | 在修真世界是剑尊，在都市世界是上市公司CEO，在末日世界是S级幸存者——多重身份带来的身份丰富度 |
| **力量反差** | 把修真功法带到末日世界用异能的方式施展，或把商业手段用到星际贸易中——跨世界创造力奖励 |
| **收集癖** | 五个世界的独特系统、独特装备、独特成就——收集完整世界观带来极大满足感 |
| **叙事深度** | 不同世界的文明差异、规则差异、历史背景——满足探索欲望 |
| **终极救赎** | 穿越的最终目的是拯救地球——所有力量汇聚于最终目标，形成史诗感 |

## Chapter 3: Detailed Rules

### 3.1 穿越者大厅（Transmigrator Hall）

穿越者大厅是贯穿始终的中枢场景，也是玩家在不同世界之间的"转场空间"。它是一个悬浮在混沌虚空中的平台，外观风格随玩家在五个世界的进度而变化。

#### 3.1.1 大厅功能

| 功能 | 说明 |
|------|------|
| **世界之门** | 显示已解锁和未解锁的世界传送门，已解锁世界以发光门扉呈现，可随时进入 |
| **穿越者印记** | 显示玩家的灵魂属性（意志力、因果值、穿越次数、在途时间等跨世界属性） |
| **跨界仓库** | 存放可跨世界携带的通用物品（每个世界独立背包，但跨界仓库有共享空间） |
| **穿越者手册** | 收集到的各世界情报、世界观记录、已完成的主要任务记录 |
| **地球意志低语** | 随着玩家穿越次数增多，地球意志的碎片信息逐步解锁，揭示真正的威胁本质 |

#### 3.1.2 大厅解锁

- 玩家完成灵气大陆主线第1章（"觉醒"）后，首次返回穿越者大厅
- 大厅在世界解锁动画完成后自动出现
- 在任何世界死亡/濒死时，可选择"返回大厅"（代价：该世界当前主线进度回退至上一个检查点）
- 玩家随时可通过系统菜单中的"返回大厅"按钮主动回到大厅（非战斗状态下可用）

### 3.2 世界解锁与递进

#### 3.2.1 初始世界选择

**创建角色时，玩家从5个世界中选择一个作为起始世界。** 每个起始世界提供不同的初始体验和资源包：

| 起始世界 | 初始资源包 | 初始金手指 | 推荐玩家类型 |
|---------|-----------|-----------|-------------|
| 灵气大陆（默认推荐） | 灵石×100 + 基础修炼功法 | 修炼亲和（修炼速度+20%） | 传统RPG爱好者 |
| 都市世界 | 启动资金¥50,000 + 商业许可证 | 商业嗅觉（交易利润+15%） | 模拟经营爱好者 |
| 末日废土 | 基础装备包 + 安全屋坐标 | 危机感知（危险预警范围+50%） | 生存游戏爱好者 |
| 星际纪元 | 基础机甲 + 矿物采集许可证 | 机械亲和（机甲操控效率+15%） | 科幻/机甲爱好者 |
| 神话纪元 | 信徒×10 + 小型神庙 | 信仰共鸣（信徒忠诚度+20%） | 策略/文明爱好者 |

**注意：** 灵气大陆被标记为"默认推荐"是因为其修炼体系最接近传统RPG，学习曲线最平滑。但玩家完全可以选择任何世界作为起点。

**起始世界对应的新手引导：**
- 系统根据玩家选择的起始世界加载对应的新手引导流程
- 灵气大陆：门派指引 → 修炼引导 → 基础战斗
- 都市世界：公司注册 → 第一桶金 → 商业网络
- 末日废土：营地建设 → 资源采集 → 异能觉醒触发
- 星际纪元：机甲驾驶教学 → 矿物采集 → 空间站贸易
- 神话纪元：神庙管理 → 信徒传播 → 第一个神迹

#### 3.2.2 世界解锁条件

每个新世界需要完成前置条件才能解锁。**世界解锁呈渐进式递进**——从已知世界到未知世界，难度和规则复杂度逐渐提升。

| 世界 | 解锁条件 | 解锁后获得的福利 |
|------|---------|-----------------|
| W1 灵气大陆 | 默认解锁（起始可选） | — |
| W2 都市世界 | 灵气大陆主线第3章完成 OR 直接作为起始世界 | 穿越者启动资金包（根据已穿越世界数递增） |
| W3 末日废土 | 完成任意2个世界的主线第2章 | 生存物资包 + 安全屋坐标 |
| W4 星际纪元 | 完成任意3个世界的主线第3章 | 基础机甲 + 星际跳跃许可 |
| W5 神话纪元 | 完成所有其他4个世界的主线第4章 | 神格碎片 ×1 + 传承神殿坐标 |

**例外规则：**
- 如果玩家将W2选为起始世界，则W1（灵气大陆）的解锁条件变为"都市世界主线第2章完成"
- 解锁条件以"已解锁世界"为计数基准——穿越者大厅中有几个发光门扉就满足几个
- 解锁条件对所有世界独立检测，不因选择了不同起始世界而改变解锁难度

#### 3.2.3 世界解锁动画

首次解锁新世界时触发过场动画：
1. 穿越者大厅中对应世界的传送门从灰色变为发光状态
2. 地球意志的声音提供该世界的基础情报（一句话世界观介绍）
3. 传送门打开，显示该世界的标志性画面（cutscene）
4. 玩家可选择"立即前往"或"稍后探索"
5. 如果是被动解锁（玩家正在其他世界活动时触发），在任务日志中添加高亮提醒

### 3.3 世界穿越机制

#### 3.3.1 穿越方式

| 方式 | 触发条件 | 限制 |
|------|---------|------|
| **主动穿越** | 在穿越者大厅点击对应世界的传送门 | 无限制，随时可穿 |
| **任务触发** | 当前世界的主线任务引导至新世界 | 不可跳过（但可延迟） |
| **紧急召回** | 当前世界濒死/死亡时选择"返回大厅" | 主线进度回退至上一个检查点 |
| **跨世界道具** | 使用特定跨界道具（如"时空锚点"） | 稀有消耗品，可获取途径有限 |
| **强制穿越** | 特殊剧情事件（如天道崩坏、世界毁灭事件） | 不可控，触发时自动执行 |

#### 3.3.2 穿越冷却

- 主动穿越冷却：**2小时（现实时间）**——防止玩家在多个世界间快速切换导致叙事碎片化
- 任务触发穿越：无冷却（剧情引导）
- 紧急召回穿越：无冷却但受惩罚（进度回退）
- 跨世界道具穿越：无视冷却

#### 3.3.3 穿越过程

1. 触发穿越 → 屏幕渐变（1.5秒白色过渡动画）
2. 加载目标世界的场景资源（后台进行，主画面显示混沌虚空飞越效果）
3. 如果首次进入该世界 → 触发世界intro叙事（文本+环境展示，约5-10秒）
4. 玩家出现在目标世界的**最后一个安全区域**（存档点）
5. 如果是首次进入 → 出现在该世界的起始位置
6. 系统弹窗：当前世界规则摘要 + 力量适配状态

### 3.4 跨世界物品与能力规则

这是多世界系统最核心的规则体系——什么能带走，什么不能，什么需要适配。

#### 3.4.1 数据结构

`WorldConfig.cs` 中的字段已定义了每个世界的货币体系、社会结构、成长体系。在此基础上，每个世界持有以下运行时数据：

```
WorldInstanceData {
    worldId: string
    sceneName: string
    playerInventory: Inventory (世界专属背包)
    playerProgress: QuestProgress (世界专属任务进度)
    playerLevel: any (世界专属成长等级——修为/财富/异能/机甲/神格)
    worldSpecificData: Dictionary<string, any> (世界特有数据)
    lastSavedAt: DateTime
    entranceCount: int (进入次数)
    totalPlaytime: float (在该世界的累计游戏时长)
}
```

#### 3.4.2 物品分类规则

所有物品分为三类——按能否跨世界携带判定：

| 类别 | 标识 | 定义 | 示例 | 跨世界规则 |
|------|------|------|------|-----------|
| **通用物品** | `Tag = "Universal"` | 在任何世界都能正常使用的物品 | 穿越者印记、因果币、时空锚点、记忆碎片 | 可自由携带，不衰减 |
| **世界绑定物品** | `worldId 字段` | 在该世界规则下生成的物质物品 | 修真世界的飞剑、都市世界的房产证、末日的异能结晶 | 可携带但不可使用（显示为灰色），需适配或转化 |
| **灵魂绑定能力** | `isSoulBound = true` | 穿越者灵魂层面掌握的能力或知识 | 战斗经验、语言能力、精神力强度、认知能力 | 可携带但受世界规则压制，需要适配还原 |

#### 3.4.3 跨世界物品规则详表

| 动作 | 通用物品 | 世界绑定物品 | 灵魂绑定能力 |
|------|---------|-------------|-------------|
| **带入新世界** | ✅ 完全可用 | ✅ 可携带（背包显示但物品图标灰色，显示"不可用"） | ✅ 自动携带，初始压制率按新世界规则计算 |
| **在新世界使用** | ✅ 正常使用 | ❌ 不可使用（显示"该物品在本世界规则下无法生效"） | ⚠️ 部分可用（压制率决定百分比） |
| **在新世界丢弃/交易** | ✅ 可丢弃/交易 | ❌ 不可丢弃/交易（防止跨世界货币套利） | N/A |
| **转化（新世界适配）** | N/A | ⚠️ 可通过特定任务/道具将绑定物品转化为新世界等价物 | ⚠️ 通过训练/任务逐步降低压制率 |
| **带回原世界** | ✅ | ✅ 恢复完全可用状态 | ✅ 恢复完全效力 |

#### 3.4.4 跨世界物品转化示例

| 原世界物品 | 目标世界 | 转化方式 | 转化结果 |
|-----------|---------|---------|---------|
| 灵石×1000 | 都市世界 | 通过地下黑市渠道（都市世界主线任务） | 等值人民币约500万（含汇率损失约50%） |
| 修真功法《天罡剑诀》 | 末日废土 | 解读功法中的"剑气"原理 → 与异能理论结合 | 领悟异能"剑气释放"（C级→B级可成长） |
| S级异能"重力操控" | 星际纪元 | 机甲改造：将异能感应器接入机甲操作系统 | 获得机甲技能"重力场发生器"（稀有模块） |
| 商业人脉网络 | 神话纪元 | 信徒传播：将商业传播逻辑应用于信仰传播 | 信徒增长速度+20%（基础速度加成） |
| 机甲操作手册 | 灵气大陆 | 参悟"机关术"关联——将机甲原理纳入炼器体系 | 解锁新型机关傀儡图纸（可载人型） |

#### 3.4.5 专属系统规则

每个世界拥有完全独立的成长系统和玩法循环。穿越到新世界时：

1. **初始状态重置**：新世界中，玩家以"凡人"身份开始——不继承前一个世界的等级/财富/装备（灵魂能力和通用物品除外）
2. **新手过渡期**：首次进入新世界时，获得"异界来客"buff（持续2小时游戏时间），效果为：
   - 基础学习速度+30%（帮助适应新规则）
   - 初始声望+20（该世界的原住民对"神秘来客"感到好奇）
   - 额外剧情对话选项（穿越者的独特知识储备）
3. **专属系统激活**：进入新世界后，自动激活该世界的专属系统UI模块

### 3.6 力量适配系统（Power Adaptation）

这是跨世界平衡的核心机制。当玩家从一个世界携带灵魂绑定能力到另一个世界时，目标世界的规则会"压制"外来力量，需要一个适配过程才能还原。

#### 3.6.1 压制率计算

进入新世界时，所有灵魂绑定能力（来自已穿越的其他世界）初始受到压制：

```
初始压制率 = BaseSuppression × WorldAffinityModifier × PowerTypeModifier
```

| 参数 | 说明 |
|------|------|
| BaseSuppression | 基础压制率（目标世界规则强度系数） |
| WorldAffinityModifier | 源世界与目标世界的规则亲和度修正 |
| PowerTypeModifier | 能力类型与被压制世界的规则兼容性 |

**基础压制率表（目标世界决定了压制强度）：**

| 目标世界 → 源世界 ↓ | 灵气大陆 | 都市世界 | 末日废土 | 星际纪元 | 神话纪元 |
|---------------------|---------|---------|---------|---------|---------|
| **灵气大陆** | 0%（原生） | 80% | 60% | 75% | 55% |
| **都市世界** | 85% | 0%（原生） | 55% | 50% | 70% |
| **末日废土** | 65% | 55% | 0%（原生） | 60% | 65% |
| **星际纪元** | 75% | 50% | 60% | 0%（原生） | 65% |
| **神话纪元** | 50% | 70% | 65% | 65% | 0%（原生） |

**解读：** 压制率越高，力量在该世界越难发挥。
- 灵气大陆的修真力量在都市世界被压制80%（科学世界观不承认灵气存在）→ 但5%的残存力量表现为"直觉"或"运气"
- 都市世界的商业经验在星际纪元仅被压制50%（星际贸易也需要商业技能）
- 神话纪元对灵气大陆的压制最低（50%）——修真与神格在"超自然"层面有共通性

#### 3.6.2 适配还原

玩家可通过以下方式逐步降低压制率：

| 方式 | 压制率降低 | 达成条件 |
|------|-----------|---------|
| **基础适应期** | -10%/天（游戏内） | 在该世界连续停留，自动适应 |
| **专项训练** | -5%/次 | 在该世界训练场/道馆进行1小时专项训练（可重复） |
| **世界规则学习** | -15% | 完成世界设定相关的知识收集任务（每个世界1次） |
| **主线任务解锁** | -20%/章 | 每完成该世界主线的一章（每个世界最多4章，即-80%） |
| **特殊契合事件** | -25% | 触发特定剧情事件（如"在末日废土用修真剑术砍变异兽"——找到两个世界规则的结合点） |
| **因果之力** | -压制率×0.5 | 消耗因果值（每个世界限1次，高因果值时更有效） |

**最低压制率：** 每种能力在各世界最低保留5%压制率（即最高95%还原），除非完成该世界的终章主线任务解锁"规则共鸣"——将压制率降至0%。

#### 3.6.3 压制状态的玩家体验

- **HUD显示**：进入新世界后，屏幕左上角显示当前所有异世界力量的压制率列表
- **功能感受**：被压制的能力不是完全消失——而是以"弱化版本"或"变异版本"的形式存在
  - 修真剑气（在都市世界）→ "直觉气场"：谈判时感知对方底牌的能力
  - 异能操控火焰（在星际纪元）→ "热能管理优化"：机甲散热效率+15%
  - 商业谈判技巧（在末日废土）→ "交易话术"：以物易物时获得10%价值加成
- **适应反馈**：每次压制率降低时，弹出小提示显示"你的[能力名称]在该世界恢复了一部分力量"

### 3.7 世界递进与难度曲线

#### 3.7.1 推荐穿越路径

虽然没有强制顺序，但设计上推荐玩家的穿越路径呈难度递增：

```
灵气大陆  ──→  都市世界  ──→  末日废土  ──→  星际纪元  ──→  神话纪元
(新手友好)    (经济模拟)    (生存挑战)    (策略战斗)    (终极考验)
```

**设计理由：**
- 灵气大陆是传统RPG体验，学习曲线最平缓
- 都市世界节奏相对轻松，可作为"休息世界"（在废土打累了回都市经商）
- 末日废土是第一个真正有求生压力的世界
- 星际纪元需要一定的策略和微操
- 神话纪元是集大成者——需要理解前四个世界的规则才能充分发挥

#### 3.7.2 力量汇聚效应

随着玩家穿越世界增多，后期世界的难度会因"力量汇聚"而部分缓解：

```
跨世界力量加成 = 已解锁世界数 × 5%
（适用于所有世界的全属性修正，在新世界中作为隐藏Buff生效）
```

- 已解锁2个世界：全属性+10%
- 已解锁4个世界：全属性+20%
- 已解锁5个世界（全解锁）：全属性+25%

这个加成在到达一个新世界时表现为"穿越者经验直觉"——灵魂经历了多个世界的淬炼，学习新规则更快。

### 3.8 返回之前的世界

#### 3.8.1 返回条件

- 已解锁的世界，可随时通过穿越者大厅的传送门返回
- 返回无冷却（但与主动穿越共享2小时主冷却——从一个世界穿越到另一个世界算一次穿越）
- **例外：** 如果在目标世界处于"战斗状态"或"剧情锁定"，响应返回按钮灰色不可用

#### 3.8.2 返回后的状态

- 返回到之前的世界后，所有该世界专属的能力/物品恢复至离开时的状态
- 原本的成长等级、装备、资产完全保留
- 时间流逝：每个世界的"时间线"独立推进——在A世界活动时，B世界的NPC会按照简单的时间模拟机制推进（区域事件、任务过期等）
- 如果在离开期间该世界发生了时间推进事件（如"门派战"、"城市经济周期"），返回后玩家会通过日志或NPC对话了解到变化

#### 3.8.3 力量膨胀保护

穿越多个世界后返回早期世界时，**需要防止"满级大佬屠新手村"的体验破坏**：

| 保护机制 | 说明 |
|---------|------|
| **力量上限软锁定** | 返回低等级世界时，玩家能力被压制到不超过该世界规则上限的120%（仍然强于原住民，但不至于无敌） |
| **世界意志关注** | 过于强大的外来者会触发"世界排斥"——全地图NPC敌意+20%，隐藏BOSS主动追击，稀有掉落率降低50% |
| **低回报循环** | 在低级世界刷资源的收益递减（如大成期修士在练气期副本不掉落任何有用物品） |
| **专属挑战** | 每个世界为回归的"强者"提供特殊挑战内容（如"隐藏BOSS·穿越者猎杀者"） |
| **成就限制** | 在该世界完成特定成就需要在该世界的"自然规则下"完成——带其他世界力量完成的不计入成就统计 |

**设计意图：** 玩家回访旧世界应该是有目的的（收集遗漏的成就、触发跨世界剧情、利用该世界的特产为其他世界做准备），而不是"回去把新手村屠一遍"。

## Chapter 4: Formulas

### 4.1 跨世界力量压制率

```
压制率 = BaseSuppression × (1 - WorldAffinityModifier) × PowerCompatibilityFactor

BaseSuppression: 目标世界的基础压制系数（0.5~0.85——来自3.6.1节矩阵）
WorldAffinityModifier: 两世界规则相似度（0~0.3）
  - 同类型（修真→神话）：0.3
  - 有交集（都市→星际）：0.2
  - 完全不同（修真→都市）：0.0

PowerCompatibilityFactor: 能力类型适应性（0.8~1.2）
  - 经验类（战斗技巧、商业嗅觉）：×0.8（经验适应性高）
  - 规则类（修为、神力）：×1.0
  - 物理类（机甲、装备）：×1.2（物质层面的能力更难跨世界）
```

### 4.2 压制率降低速度

```
第n天的压制率 = 初始压制率 × (1 - 0.10)^n - 已完成的专项训练次数×0.05

其中：
  n = 连续停留天数（游戏内）
  专项训练次数上限 = 5次/世界

最低压制率 = max(5%, 当前压制率 - 主线任务解锁折扣 - 特殊契合事件折扣)
```

### 4.3 跨世界力量加成

```
全属性加成系数 = 1 + (已解锁世界数 × 0.05)

例：已解锁3个世界 → 全属性 × 1.15
例：已解锁5个世界 → 全属性 × 1.25
```

### 4.4 世界绑定物品转化汇率

```
转化价值 = 物品在原世界的等价价值 × 世界汇率系数 × 适配任务折扣

世界汇率系数：
  灵石 → 人民币: 0.5（官方汇率为1灵石=10000元，但实际到手约5000元）
  人民币 → 星际信用点: 0.7（1元≈0.7Cr，基于购买力平价）
  异能结晶 → 信仰之力: 0.3（物质到精神的转化效率低）
  机甲模块 → 修真傀儡图纸: 0.6（技术到炼器的转化）

适配任务折扣 = 0.5~1.0（由转化任务的完成品质决定）
  - 任务失败/粗糙完成：0.5
  - 标准完成：0.8
  - 完美完成：1.0
```

### 4.5 穿越冷却公式

```
穿越冷却(秒) = 
    主冷却(7200秒=2小时) - 已解锁世界数 × 600秒(10分钟)
    + 惩罚冷却(如果有最近紧急召回：+3600秒)

主冷却上限：不低于3600秒（最少1小时）
最少下限：已解锁5个世界 + 无召回记录 → 7200 - 3000 = 4200秒(70分钟)
```

### 4.6 回归力量软锁定

```
返回低级世界后的力量上限 = 该世界终极BOSS战力 × 1.2

如果玩家当前战力 > 该上限：
    玩家在该世界的实际有效战力 = 该世界终极BOSS战力 × 1.2
    超出部分显示为灰色（被封印状态），但不损失
    离开该世界后封印自动解除
```

### 4.7 世界时间独立推进

```
玩家在A世界每度过1小时（现实时间）：
    B世界推进 = 2小时（游戏内时间）
    C世界推进 = 2小时
    ...

时间推进的上限：离开某个世界后最多推进168小时（7天游戏内时间）
    - 超过168小时后，该世界进入"时间冻结"状态，等待玩家返回后一次性结算
    - 结算内容：任务过期通知、NPC状态变更摘要、资源产出汇总

时间推进的影响：
    - 过期任务：未完成的主线/支线任务可能自动失败
    - 资源产出：有持续产出的设施（灵石矿、工厂、农场）产出累计
    - NPC变动：友好NPC可能离开/死亡，敌对NPC可能变强
    - 事件推进：世界级事件按照时间线推进（不论玩家是否在场）
```

## Chapter 5: Edge Cases

### 5.1 玩家在新世界陷入死局

如果玩家在某个世界中主线推进到无法继续（战力不足、资源耗尽、关键NPC死亡）：

| 解决方案 | 条件 | 说明 |
|---------|------|------|
| **跨世界求助** | 已解锁≥2个世界 | 从A世界携带资源/能力进入B世界，打破死局（如带修真丹药去末日废土换物资） |
| **返回修整** | 无 | 返回穿越者大厅 → 进入已解锁的其他世界提升实力 → 再回来 |
| **强制重置** | 付费（游戏内货币）或消耗因果值 | 重置该世界主线至上一章，保留装备和等级 |
| **最坏情况** | 无 | 如果所有世界都陷入死局 → 触发"地球意志干预"——强制重置所有世界的最新检查点（终极保底） |

**设计原则：** 不应当出现玩家因死局而彻底无法推进游戏的状况。穿越者大厅的存在本身就是"终极保底"——只要有另一个世界可去，就不算死局。

### 5.2 世界绑定物品在错误世界

玩家将A世界的绑定物品带到B世界时，物品在B世界显示为"不可用"状态：

- **视觉表现**：物品图标变灰 + 右下角显示"⛔ 本世界不可用"标记
- **交互限制**：不可装备、不可使用、不可交易、不可丢弃（防止通过丢物品实现跨世界资产转移）
- **转化途径**：在B世界找到对应"转化师"NPC（每个世界有1-2个），通过任务/付费将该物品转化为B世界的等价物
- **返回恢复**：返回A世界后，物品自动恢复为可用状态

**特殊处理：** 如果玩家试图将A世界的绑定物品在B世界的商店出售：
- NPC对话选项变灰或显示"我们不收异界的东西"
- 如果有地下黑市渠道（特定任务解锁），可以折价出售（价格约为原价的30%）

### 5.3 多世界存档管理

```
SaveData {
    saveVersion: string
    timestamp: DateTime
    transmigratorMark: TransmigratorMark  // 灵魂属性（跨世界共享）
    
    worlds: Dictionary<string, WorldSaveData>  // 每个世界独立存档
}

WorldSaveData {
    worldId: string
    sceneName: string
    playerPosition: Vector3
    inventory: Item[]  // 世界专属背包
    progress: Dictionary<string, any>  // 任务进度（世界专属）
    levelData: any  // 世界专属等级数据
    lastSavedAt: DateTime
    entranceCount: int
    totalPlaytime: float
    
    // 世界特有的存档字段
    worldSpecificData: Dictionary<string, any>
}
```

| 边缘情况 | 处理方式 |
|---------|---------|
| **存档写入时机** | 离开世界时自动保存 + 每15分钟自动保存 + 手动保存 |
| **存档冲突** | 两个WorldSaveData间的冲突不可能发生（数据完全独立） |
| **跨世界回档** | 回档到穿越者大厅的存档点——所有世界的存档独立回档 |
| **存档损坏** | 单个世界的WorldSaveData损坏不影响其他世界的存档；损坏的世界可通过"重置该世界进度"恢复（代价：该世界进度归零） |
| **多设备同步** | 以穿越者大厅为同步锚点——每次进入穿越者大厅时触发云端同步 |

### 5.4 玩家在一个世界离线

| 情况 | 处理方式 |
|------|---------|
| **离线前在该世界安全区** | 无影响。下次上线时在安全区醒来。 |
| **离线前在战斗状态** | 系统判定为"穿越者紧急撤离"——消耗1次"紧急召回"机会，将该世界进度回退至上一个检查点。 |
| **离线前在穿越过程中** | 视为穿越完成——出现在目标世界起始位置。 |
| **离线期间其他世界的时间推进** | 正常推进（见4.7节）。返回时一次性结算变化。 |

### 5.5 起始世界选择后的反悔

- 创建角色选择起始世界后，**前30分钟游戏时间可免费更换一次**起始世界（进度保留在初始世界）
- 超过30分钟后，更换起始世界需完成该世界的主线第1章（解锁穿越者大厅）后才能去其他世界
- **无法删除已创建的角色**（每个角色绑定唯一的穿越者印记）

### 5.6 新世界主线前置被另一个世界阻断

**场景：** W3末日废土需要"完成任意2个世界的主线第2章"，但玩家在W1和W2都无法推进主线第2章。

**处理方式：**
1. 系统检测到这种情况（2个世界的主线均阻塞）后，自动在玩家的穿越者大厅中激活"地球意志指引"事件
2. 引导玩家返回其中一个阻塞世界，提供明确的下一步指引
3. 如果阻塞问题是跨世界性的（如需要某个道具但该道具在其他世界），系统提供"临时跨界通道"（限时1小时）让玩家从A世界跨越到B世界取道具再返回

**核心理念：** 永远给玩家一条出路，不让世界解锁条件变成"死锁"。

### 5.7 在未完成当前世界主线时就"跳"世界

玩家可以选择在任何时候前往已解锁的其他世界，即使当前世界的主线尚未完成。

- **允许，但不推荐。** 系统会在穿越前弹出提示："你当前在[世界名]的主线进度为[第X章/共Y章]。是否确认前往其他世界？你可以随时回来继续。"
- **任务日志保留**：未完成的任务保留在日志中，标记为"暂停中"
- **跨世界因果关系**：在A世界未完成的某些任务可能会因你在B世界的选择而自动解决或自动失败（如"保护XX人物"任务——你在B世界停留太久，A世界的时间推进导致该人物已死亡）
- **完成度奖励**：鼓励完成主线后再走——完成一个世界的完整主线后，该世界提供的"永久跨世界加成Buff"会翻倍

### 5.8 神话纪元终极通关后的状态

玩家完成神话纪元的主线第5章（神格达到神王级）后：

1. **终局事件触发**：地球意志完全现身，揭示最终威胁的真相
2. **最终战开启**：从穿越者大厅出现一扇通向"现实·地球"的传送门
3. **通关后自由模式**：玩家仍然可以自由穿越所有世界，但主线目标变更为"收集万界之力巩固地球防御"
4. **跨世界权限全部解锁**：所有压制率限制解除，所有世界绑定物品变为通用物品
5. **新游戏+（New Game+）**：可选择保留所有能力重新开始——所有世界的主线重置，但难度提升2倍，掉落和奖励提升3倍

### 6.4 依赖关系图

```
穿越者大厅 (枢纽场景)

├── EnterWorld(worldId)

PowerAdaptationSystem
├── 计算压制率 → 根据源世界/目标世界

└── 压制率变更通知 → UI更新

各世界独立系统 ───→ 实现各自 IWorldSystem 接口
```

### 6.5 统一的 IWorldSystem 接口

为了便于WorldManager统一调度，所有世界系统需要实现以下接口：

```csharp
public interface IWorldSystem
{
    string WorldId { get; }
    void OnEnterWorld(WorldConfig config);
    void OnExitWorld();
    void OnTimePassed(float gameHours);     // 玩家不在时的时间推进
    SaveData.WorldSaveData GetSaveData();
    void LoadFromSave(SaveData.WorldSaveData data);
    bool IsMainQuestComplete { get; }       // 主线是否完成
    int MainQuestChapter { get; }           // 当前主线章节
    float PowerLevel { get; }               // 该世界的"战力"指数（用于力量压制计算）
}
```

**附录B：Unrealized Worlds 扩展方案**

多世界系统设计时已考虑了未来的扩展性。如需增加第6个及更多世界：

1. 新建 `WorldConfig` ScriptableObject，填入对应世界数据
2. 创建该世界的Unity场景和专属系统
3. 在 `WorldManager` 的世界列表中注册新世界
4. 设定该世界的解锁条件（任一：前置世界主线完成 / 特定道具触发 / 隐藏事件发现）
5. 在 `WorldManager` 的压制率矩阵中添加新行和新列
6. 为穿越者大厅增加一个新传送门

**扩展约束：**
- 最多支持9个世界（穿越者大厅UI按3×3排列设计）
- 第6~9个世界建议作为"隐藏世界"（解锁条件不与主线直接挂钩，需要玩家探索发现）
- 隐藏世界的压制率矩阵自动使用"中等相似度"的默认值，上线后通过数据调整
