## Chapter 1: Overview

门派系统是地球Online灵气大陆的"社会层"。它不锁技能、不锁成长路线——门派是**身份标识 + 资源渠道 + 社交圈层**的三位一体。

玩家初至灵气大陆可以选择：(1) 加入一个门派，获得资源扶持和保护，但承担义务和站队约束；(2) 以散修身份自由探索，无绑定关系但缺少门派独有资源。

### 核心设计哲学

- **门派不是"选职业"：** 不锁技能树，不锁成长路线。剑修可叛逃后学拳，拳修可偷学剑术。门派福利有差异但不出"你选错了就重来吧"的惩罚。
- **选择即代价：** 加入有福利也有义务，退出有代价但不阻止。每个选择都有可感知的收益与成本。
- **不阻断主线链：** 散修可独立完成全部纵向主线链（新地图探索 → 采集灵材 → 丹药炼器 → 装备强化 → BOSS战 → 渡劫），无需加入任何门派。
- **6系统联动：** 门派系统横跨所有其他系统提供社交关系、任务目标、资源倾斜，但不是任何系统的硬性前置。

### 现有基础

`FactionSystem.cs` 已定义5个门派的声望框架（-100到100）和势力关系（同盟/敌对）。本GDD在其之上新增身份管理、加入/退出流程、贡献与晋升体系、叛逃与追杀、跨门派周旋等完整玩法闭环。

### 现存的问题（本GDD要解决的）

当前 `FactionSystem.cs` 仅有声望增减，缺少：
- 玩家门派身份标识（谁是哪个门派的弟子）
- 加入/退出/叛逃的完整流程
- 门派贡献度和职级体系
- 偷学、门派战等深层玩法
- 散修路线的完整体验

## Chapter 2: Player Fantasy

### 2.1 正道弟子幻想

"我拜入天元宗，每日完成师门任务赚贡献。攒了三个月终于换到一本《天罡剑诀》。某日我在藏经阁偷看到一本禁术——《血炼大法》。修还是不修？修了被发现就是叛门大罪，但威力实在太诱人了……"

### 2.2 宗门叛徒幻想

"我在天元宗偷学禁术被发现了。执法堂长老带着三个弟子追杀我。我逃到妖兽森林，利用地形和妖兽甩掉追兵，又辗转逃到法外之地投靠了散修联盟。但天元宗的追杀令没撤销——每到一个新地图都可能触发追兵遭遇。我得想办法洗掉神魂印记……"

### 2.3 多面间谍幻想

"我表面是青云门弟子，暗地里帮商盟走私丹药，还偷偷交好了御兽遗族。天元宗和青云门开战了——我两边都有人脉，两边都能拿到情报。但我走钢丝——一旦暴露就是三面通缉。"

### 2.4 散修至尊幻想

"我谁的门派也不加。一个人采药、炼丹、刷副本、打BOSS。没有门派庇护？我自己就是门派。散修联盟的悬赏榜上，我的名字从任务接取者变成了悬赏发布者——我给新人发任务。渡劫时没有护法？我渡了三次才过，但第四次成功后获得的天赋是独一无二的『无根道体』。"

### 2.5 门派领袖幻想

"我从外门弟子做起，一步步做到掌门。天元宗在我手里从正道之首变成……我还没想好变成什么。但我有权力决定门派的对外策略：和青云门结盟还是吞并？对散修的态度是拉拢还是驱逐？"

**核心原则：** 以上所有幻想路径都是合法的，玩家路径不应被系统预设阻断。

## Chapter 3: Detailed Rules

### 3.1 加入门派 (Join)

#### 3.1.1 准入条件

每个门派设置1~3条基础准入条件（境界门槛、声望门槛、特定任务前置）：

| 门派 | 境界门槛 | 声望门槛 | 额外条件 |
|------|---------|---------|---------|
| 天元宗 | 筑基期 | 天元宗声望 >= 0 | 通过入门考核（战斗试炼） |
| 青云门 | 筑基期 | 青云门声望 >= 0 | 通过入门考核（采集+炼丹试炼） |
| 商盟 | 练气期 | 商盟声望 >= 10 | 完成"投名状"任务（上缴一批材料） |
| 御兽遗族 | 练气期 | 御兽遗族声望 >= 0 | 通过灵兽亲和测试 |
| 散修联盟 | 无 | 无 | 默认身份，无需加入流程 |

#### 3.1.2 加入流程

1. 玩家找到门派接引NPC，对话触发"申请加入"
2. 系统检查准入条件——不满足时显示缺失项（不是"你不能加入"，而是"你需要达到XX"）
3. 满足条件：进入考核场景（小型副本，5~10分钟可完成）
4. 考核通过 → 弹出门派身份面板 → 获得门派令牌（物品）→ 解锁门派UI界面
5. 考核不通过 → 不影响声望，冷却7天后可再次申请

#### 3.1.3 同时加入多个门派

- **默认规则：不允许同时加入多个正式门派。** 加入新门派时自动退出旧门派（视为"退出"，非"叛逃"）
- **例外：** 散修联盟不视为正式门派，任何正式门派成员可同时是散修联盟成员
- **隐藏路线：** 玩家可通过特定机缘获得"双面身份"道具，允许同时属于两个门派（被发现后触发双倍叛门惩罚）

### 3.2 退出门派 (Leave)

#### 3.2.1 和平退出

- 玩家主动与掌门/接引NPC对话选择"退出门派"
- 条件：当前无未完成的师门任务 / 门派贡献不为负值 / 非叛逃状态
- 后果：
  - 门派贡献度保留50%（未来回归可继承）
  - 门派声望 -30
  - 收回门派信物（装备槽空出）
  - 已学习的门派专属功法保留但无法升级（需通过其他途径补全整本功法）
  - 7天内不可再加入同一门派

#### 3.2.2 强制退出（被逐出）

- 门派贡献降至 -100 → 被逐出门派
- 后果：门派贡献清零 / 门派声望归零 / 收回所有门派装备 / 加入敌对门派声望 +10

### 3.3 叛逃 (Betray)

#### 3.3.1 触发条件

玩家在执行以下任一行为后，可选择触发叛逃（或被迫叛逃）：

| 行为 | 叛逃等级 | 说明 |
|------|---------|------|
| 偷学门派禁术被发现 | 中~重度 | 根据禁术等级决定 |
| 击杀门内NPC（长老） | 重度 | 无法挽回 |
| 击杀门内NPC（弟子） | 轻度 | 赔偿可降低 |
| 窃取门派宝物 | 中度 | 视宝物价值 |
| 向敌对门派泄露机密 | 中度 | 视情报价值 |
| 双面身份暴露 | 重度 | 两个门派都视为叛徒 |

#### 3.3.2 叛逃流程

1. **触发事件** → 系统判定叛逃等级（轻度/中度/重度）
2. **进入"逃亡"游戏阶段：**
   - **轻度叛逃：** 原门派发布通缉，派2~3名执法弟子追杀，追兵境界与被叛逃者同级
   - **中度叛逃：** 原门派发布悬赏令，全地图NPC都可能告发，执法长老（高1~2境）亲自追杀
   - **重度叛逃：** 原门派掌门级战力出动，触发至少3场强制战斗事件
3. **逃亡结束条件（满足任一即可）：**
   - 到达法外之地（特定地图，消除追兵标记）
   - 渡劫成功后净化神魂印记（渡劫系统联动）
   - 原门派被灭（门派战联动）
   - 支付巨额赔偿（原门派声望恢复到 -50 以上）

#### 3.3.3 叛逃后果

- 原门派声望锁定为 -100（不共戴天）
- 原门派贡献度归零
- 已学习的门派专属功法保留但威力降低30%（缺心法配合）
- 获得"叛徒"标签，其他正道门派初始声望 -20
- 散修联盟欢迎度 +20（越叛越受欢迎）
- 原门派的同盟门派声望 -50

### 3.4 散修 (Rogue Cultivator)

#### 3.4.1 散修身份特性

- **默认身份：** 无需加入任何门派，游戏开始时自动获得散修身份
- **资源限制：** 无法使用门派专属资源（功法、丹方、锻造图纸、洞府灵气加速）
- **渡劫惩罚：** 无人护法，基础失败率 +20%
- **渡劫补偿：** 成功后获得的道体特性稀有度权重提升——天道补偿无门派的修士

#### 3.4.2 散修联盟

散修联盟不是正式门派，而是一个松散互助组织：

- **成员身份不冲突：** 正式门派弟子也可加入
- **提供功能：** 悬赏榜（任务系统）/ 坊市摊位（交易系统）/ 情报交换（信息解锁）
- **联盟声望：** 影响可接任务的质量和情报价格
- **无退出惩罚：** 可随时退出，不影响任何声望

#### 3.4.3 散修转门派

- 散修任何时候可申请加入正式门派（满足条件即可）
- 加入后自动失去散修身份，但保留散修联盟声望
- 保留"曾在散修联盟"的历史标签

### 3.5 偷学 (Secret Learning)

#### 3.5.1 偷学途径

| 途径 | 风险等级 | 说明 |
|------|---------|------|
| 藏经阁潜入 | 中 | 夜晚/深夜时段守卫减少，可翻阅禁书 |
| 偷听讲道 | 低 | 躲在讲经堂暗处，获取功法片段 |
| 贿赂内应 | 中 | 用灵石/材料收买内部弟子 |
| 战场捡漏 | 低 | 门派战后拾取散落的功法残页 |

#### 3.5.2 偷学风险

- 每次偷学行为有基础被发现概率（25%）
- 增加被发现概率的因素：

| 因素 | 加成 |
|------|------|
| 功法等级高于当前境界 | 每高1境 +20% |
| 玩家门内声望低 | 每 -10 声望 +5% |
| 目标门派警戒度高 | 天元宗 +15%，御兽遗族 -10% |
| 门派战争状态 | +15% |

- 被发现后的处理：

| 概率范围 | 处理方式 |
|---------|---------|
| 低（< 30%） | 警告：扣声望 -20，逐出藏经阁 |
| 中（30%~70%） | 关禁闭：72小时内无法行动，贡献度扣50 |
| 高（> 70%） | 强制叛逃：触发3.3叛逃流程 |

#### 3.5.3 偷学收益

- 获得功法残篇（50%~80%进度，需自行推演补全剩余部分）
- 禁术偷学可获得常规途径无法获得的特殊技能
- 每成功偷学10次获得"鬼才"称号（学习速度 +5%）

### 3.6 门派战 (Sect War)

#### 3.6.1 宣战条件

- 门派声望等级 >= 3级（见第4章量表）的门派可对其他门派宣战
- 宣战消耗：灵石 × 10000 + 材料 × 若干（可配置）
- 宣战后双方进入"战争状态"，持续72小时（现实时间）

#### 3.6.2 战争形式

| 形式 | 说明 |
|------|------|
| 门派战场 | 独立战场副本，双方弟子自由入场，积分制 |
| 资源点争夺 | 地图上刷新资源点，双方争夺控制权 |
| 刺杀任务 | 发布悬赏刺杀对方高层NPC |

#### 3.6.3 胜负判定

- **积分制：** 击杀敌方弟子 +10分，摧毁敌方旗帜 +100分，击杀敌方掌门/长老 +500分
- **时长：** 72小时后积分高者胜
- **胜方奖励：** 获得败方赔偿（灵石），参战弟子获得额外门派贡献（胜利加成 2×）
- **败方惩罚：** 支付赔款，失去部分势力范围（地图控制权变更）

### 3.7 门派贡献 (Contribution)

#### 3.7.1 贡献获取途径

| 行为 | 贡献度 | 限制 |
|------|--------|------|
| 完成师门任务 | 10~50/次 | 每日最多5次 |
| 上缴灵材/丹药 | 价值 × 0.1 | 品质加成（上品+50%，极品+200%） |
| 参加门派战 | 50~500 | 按战功表现 |
| 指点低阶弟子 | 5~10/次 | 需职级 >= 3 |
| 建设门派设施 | 100~500 | 大型共建项目（周期性） |

#### 3.7.2 贡献消耗途径

| 行为 | 消耗贡献 |
|------|---------|
| 兑换门派功法 | 200~2000（按功法等级） |
| 兑换丹药/材料 | 50~500 |
| 使用洞府灵气加速 | 10/小时 |
| 请求门派庇护 | 300/次（可抵消一次追杀） |
| 兑换门派专属装备 | 500~3000 |

#### 3.7.3 负贡献与衰减

- 连续7天未完成任何师门任务 → 每日 -5 贡献（衰减）
- 击杀同门弟子 → -50 贡献
- 贡献降至 -100 → 被逐出门派

### 3.8 晋升 (Rank Up)

#### 3.8.1 职级体系

每个门派设5个内部职级（名称因门派而异）：

| 职级 | 天元宗对应名 | 解锁条件 | 特权 |
|------|------------|---------|------|
| 1 | 外门弟子 | 加入即可 | 基础任务、藏经阁1层 |
| 2 | 内门弟子 | 贡献 >= 200 + 入派 >= 7天 | 中等任务、藏经阁2层、洞府加速 |
| 3 | 核心弟子 | 贡献 >= 500 + 境界 >= 金丹 | 高级任务、藏经阁3层、商铺折扣(9折) |
| 4 | 长老席位 | 贡献 >= 2000 + 境界 >= 元婴 + 推荐 | 禁术权限、门派决策投票权 |
| 5 | 掌门 | 特殊事件触发（前掌门退位/战死/禅让） | 门派全部资源、宣战权、外交决策 |

#### 3.8.2 晋升考核

- **1 → 2：** 自动晋升（达到条件后接晋升任务，完成后自动升级）
- **2 → 3：** 通过门派内部晋级试炼（战斗 + 理论考核）
- **3 → 4：** 完成一个门派级大型任务（如清剿某妖兽巢穴、炼制指定丹药）
- **4 → 5：** 非日常晋升，需触发特殊事件（如门派危机中拯救门派、前任掌门指定）

#### 3.8.3 各门派职级名称差异

| 职级 | 天元宗 | 青云门 | 商盟 | 御兽遗族 |
|------|--------|--------|------|---------|
| 1 | 外门弟子 | 外门弟子 | 学徒 | 幼兽行者 |
| 2 | 内门弟子 | 内门弟子 | 伙计 | 兽灵行者 |
| 3 | 核心弟子 | 真传弟子 | 掌柜 | 兽魂行者 |
| 4 | 长老 | 长老 | 大掌柜 | 兽王长老 |
| 5 | 掌门 | 掌门 | 总会长 | 兽神 |

## Chapter 4: Formulas

### 4.1 声望计算公式

```
声望变化 = 基础值 × (1 + 同盟系数 - 敌对系数)

基础值标准表：
  完成门派任务          +5 ~ +15
  击杀敌对门派弟子       +3
  被敌对门派击杀         -5
  叛逃                   -80
  和平退出               -30
  偷学被发现（同门派）   -20
  偷学被发现（其他门派）  +5（本派声望上升）

同盟系数：0.5（同盟门派获得50%同向变化）
敌对系数：0.5（敌对门派获得50%反向变化）
```

### 4.2 叛逃追杀强度

```
追杀强度 = 基础等级 + 叛逃者境界 × 0.5 + 偷学功法等级 × 0.3 + 叛逃前职级 × 0.2

基础等级判定：
  轻度叛逃（盗窃、打架）：             1 ~ 3
  中度叛逃（偷学禁术、杀内门弟子）：     4 ~ 6
  重度叛逃（杀长老、勾结外敌）：         7 ~ 10

追兵境界 = 叛逃者境界 + floor(追杀强度 / 3)
追兵人数 = min(5, 1 + floor(追杀强度 / 2))
```

### 4.3 偷学成功概率

```
偷学成功率 = 基础成功率(25%) + 潜行技能加成 - 警戒度 + 时段加成

潜行技能加成：玩家隐匿类技能等级 × 2%
目标门派警戒度：
  门内声望每高10级  -2%（越受信任越不易被怀疑）
  门派战争状态     +15%
时段加成：
  白天   0%
  夜晚  +10%
  深夜  +20%
```

### 4.4 贡献兑换折扣

```
实际消耗 = 基础消耗 × (1 - 职级折扣率)

职级折扣率：
  1级（外门弟子）：   0%
  2级（内门弟子）：   0%
  3级（核心弟子）：   10%
  4级（长老席位）：   20%
  5级（掌门）：       30%（消耗门派资源，非个人贡献）
```

### 4.5 跨门派声望联动

```
玩家加入门派A时：
  门派A的盟友   声望 +10（爱屋及乌）
  门派A的敌人   声望 -20（阵营对立）

玩家背叛门派A加入门派B时：
  门派A         声望 -80（保底 -100）
  门派A的盟友   声望 -40
  门派B         声望 +20（接纳叛徒）
  门派B的敌人   声望 -10（怀疑立场）
```

### 4.6 功法叛逃威力衰减

```
叛逃后功法威力 = 原威力 × (1 - 衰减系数)

衰减系数 = 0.3（默认）
  若叛逃至散修联盟：衰减系数 0.35（更缺少心法指导）
  若叛逃至敌对门派：衰减系数 0.2（新门派可部分补全心法）
  渡劫净化后：衰减系数 0（恢复完全威力）
```

## Chapter 5: Edge Cases

### 5.1 门派被灭

- 门派在门派战中失败且资源降至 0 时进入"衰败"状态
- 衰败状态下：无法接收新弟子 / 现有弟子贡献获取速度减半 / 藏经阁被封锁
- 衰败状态持续30天（现实时间）后，门派消失
- 该门派弟子自动转为散修，损失50%已消耗的门派贡献
- 玩家可通过"重建门派"系列任务复兴衰败门派（需消耗大量资源）

### 5.2 掌门叛逃

- 掌门不能通过常规"退出"实现，只能走叛逃流程
- 掌门叛逃触发门派最大危机：
  - 全门派声望 -50
  - 所有弟子获得"耻辱"debuff（修炼效率 -15%，持续7天）
  - 自动触发"新掌门选举"事件
- 掌门叛逃后自动降为散修，无法再加入原门派

### 5.3 门派合并

- 同盟状态超过30天（现实时间）且双方同意 → 触发合并事件
- 合并后两派合为一个新门派，主从关系由贡献总值决定
- 原门派名称可保留为分支/堂口
- 成员职级按原职级在新门派的对应关系映射

### 5.4 多身份/卧底

- 玩家加入门派A后获得情报，可假装投靠门派B做卧底
- 卧底状态下：同时显示两个门派的身份面板，但只有玩家知道真相
- 卧底暴露：触发双倍叛逃惩罚（两个门派都视为叛逃）
- 卧底身份不会被常规"检查双身份"检测到

### 5.5 存档异常与断线

- 门派战进行中服务器离线：自动判定为平局，退还50%宣战消耗
- 叛逃途中存档：重新上线时继续逃亡状态（追兵刷新时间和位置重置）
- 加入门派条件变化（如声望突变）：以申请提交时的快照为准，不因途中条件变化否决

### 5.6 NPC门派成员自然变化

- NPC也会晋升、叛逃、战死——门派不是静态的
- 每7天（游戏内）刷新一次门派NPC状态
- 关键NPC（传授功法的长老）战死/叛逃后，该功法暂时不可学习，直到接任者出现
- 门派人丁兴旺程度影响任务发布频率和资源产出量

## Chapter 6: Dependencies

### 6.1 前置系统

| 系统 | 依赖类型 | 说明 |
|------|---------|------|
| 新地图区域 | 强依赖 | 门派据点必须预留在5个以上的地图区域 |
| 修炼系统 | 强依赖 | 境界是门派准入条件和晋升门槛 |
| 声望系统 | 复用+扩展 | `FactionSystem.cs`现有声望框架需要扩展 |

| 物品系统 | 强依赖 | 门派令牌、专属装备、功法物品 |

### 6.2 被本系统影响的系统

| 系统 | 影响方式 |
|------|---------|
| 副本实例 | 门派专属副本入口、门派任务链触发副本事件 |
| BOSS战 | 门派任务链触发专属BOSS、门派战中的BOSS级NPC |
| 渡劫 | 门派护法降低渡劫难度、叛逃者需渡劫净化印记 |
| 丹药炼器 | 门派丹方库提供独家配方、贡献兑换高阶图纸 |
| 新地图 | 门派势力范围影响地图区域的控制权/准入权限 |

### 6.3 依赖关系图

```
新地图 ──→ 门派据点位置 ──→ 加入/退出逻辑
声望系统 ──→ 跨门派周旋 ──→ 双身份/卧底
修炼系统 ──→ 境界门槛 ──→ 准入和晋升条件
NPC系统 ──→ 门派人员 ──→ 任务发布/教学/追杀

门派系统 ──→ 副本实例（门派任务→副本入口）
门派系统 ──→ BOSS战（门派战→BOSS级NPC）
门派系统 ──→ 渡劫（护法/净化印记）
门派系统 ──→ 丹药炼器（配方/兑换）
门派系统 ──→ 新地图（势力范围/控制权）
```

## Chapter 8: Acceptance Criteria

### AC-1：基础加入/退出流程

- [ ] 玩家可找到任意门派的接引NPC并触发"申请加入"
- [ ] 不满足条件时显示明确的缺失项列表（不是"不能加入"）
- [ ] 满足条件后进入考核场景，通过后获得门派令牌
- [ ] 和平退出保留50%贡献，声望-30，7天内不可再加
- [ ] 贡献降至-100时被逐出门派

### AC-2：叛逃全流程

- [ ] 至少3种触发叛逃的行为（偷学被发现、杀同门、双身份暴露）
- [ ] 叛逃后触发追兵事件，追兵境界和人数按公式生成
- [ ] 叛逃后原门派声望锁定为-100
- [ ] 至少有3种方式结束逃亡状态（法外之地/渡劫净化/赔偿）

### AC-3：散修路线完整性

- [ ] 散修可不加入任何门派正常推进游戏
- [ ] 散修可接散修联盟悬赏任务
- [ ] 散修渡劫失败率+20%，成功后获得更稀有道体
- [ ] 散修可随时满足条件后加入正式门派

### AC-4：偷学系统

- [ ] 至少2种偷学途径（潜入藏经阁/贿赂内应）
- [ ] 偷学有基础25%的概率被发现
- [ ] 被发现后不同严重程度有不同的处理方式（警告/禁闭/叛逃）
- [ ] 偷学成功获得功法残篇（50%~80%进度）

### AC-5：门派战

- [ ] 声望3级以上门派可宣战
- [ ] 至少2种战争形式（战场副本/资源点争夺）
- [ ] 72小时后判定胜负
- [ ] 胜方获得赔偿，败方失去势力范围

### AC-6：贡献与晋升

- [ ] 至少4种贡献获取途径和4种消耗途径
- [ ] 5个职级各有不同的解锁条件和特权
- [ ] 晋升需要完成考核任务或特殊事件
- [ ] 职级名称因门派而异

### AC-7：跨门派联动

- [ ] 同盟门派之间的声望联动生效
- [ ] 加入一个门派影响其他门派的初始态度
- [ ] 双身份/卧底机制可触发（隐藏路线）
- [ ] 门派人丁兴旺程度影响任务频率

### AC-8：边缘情况处理

- [ ] 门派被灭后弟子自动转为散修
- [ ] 掌门叛逃触发最大危机
- [ ] 门派合并逻辑可正常运转
- [ ] 存档恢复后逃亡状态继续保持
- [ ] NPC门派成员的自然变化在游戏内生效
