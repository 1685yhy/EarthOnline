# UI 三大 P0 系统设计文档

> **项目：** 地球Online（Earth Online）
> **引擎：** 团结引擎 1.9.3（Tuanjie / Unity 2022.3）
> **设计角色：** CCGS UI Designer
> **美术风格：** 修仙水墨 + 现代游戏 UI 融合
> **文档日期：** 2026-07-11
> **设计来源：** UI Designer 聊天输出（2026-07-11），Lead Designer UX 审查结论（2026-07-10）

---

## 设计背景

Lead Designer 审查后判断：现有 UIManager 本质是"事件日志查看器"（屏幕右上角 Debug.Log 文字滚动），不具备真正的游戏 UI 反馈能力。三位一体 P0 改造计划：**Toast 通知系统**替代所有 Debug.Log 输出，**HUD 仪表盘**提供玩家实时状态感知，**对话 Panel** 承载 NPC 交互的核心视觉呈现。

### 三系统屏幕分区

```
┌──────────────────────────────────────────────────┐
│                                        ┌──────┐ │
│                                        │Toast │ │
│                                        │通知  │ │
│                                        └──────┘ │
│                                                   │
│                                                   │
│                                                   │
│                                                   │
│                                                   │
│                                                   │
│  ┌───────┐                              ┌────────┐│
│  │ HUD   │                              │对话Panel││
│  │仪表盘 │                              │底部居中 ││
│  └───────┘                              └────────┘│
└──────────────────────────────────────────────────┘
```

- **Toast：** 右上角（滑入弹出）
- **HUD：** 左下角（始终驻留）
- **对话 Panel：** 底部居中（按需出现）

三者屏幕空间严格分区，无重叠冲突。

### 三系统联动规则

- **UIManager** 作为调度中心：接收 GameEvent，按类型分发到对应系统
- **Toast→HUD 联动：** 战斗 Toast（"灵石-500"）出现时，HUD 灵石计数器同时播放减少动画
- **Dialogue→Toast 联动：** 对话中出现关键信息（获得物品、触发事件），对应 Toast 在对话掩体期间进入"待处理队列"，对话结束后按序弹出
- **对话面板打开时：** Toast 通知降低至 30% 透明度（视觉降级避免干扰），HUD 保持全屏可见，背景叠加 `#00000040` 全屏蒙版

## 一、Toast 通知系统

### 1.1 功能概述

替代所有 Debug.Log 输出的游戏反馈系统。轻量级瞬时通知，右上角浮出，自动消失。支持 4 种颜色分级。

### 1.2 布局规格

| 属性 | 值 |
|------|-----|
| 定位 | 右上角，距上边缘 20px，距右边缘 20px |
| 容器 | 垂直 Stack，最新在上，依次下推 |
| 单条尺寸 | 宽 360px × 高 56px |
| 最大可见 | 4 条，更早的自动消失 |
| 内部结构 | [图标 24×24] [消息文字] [底部计时条] |

### 1.3 颜色分级

| 类型 | 主色 | 边框色（左侧 3px 竖条） | 图标 | 使用场景 |
|------|------|------------------------|------|----------|
| **战斗** | `#EF4444` 朱砂红 | `#EF4444` 血红 | 剑交叉 | 受到伤害、击杀、暴击 |
| **修炼** | `#3B82F6` 天青蓝 | `#3B82F6` 靛蓝 | 莲花/打坐 | 突破、功法升级、灵力恢复 |
| **灵石** | `#F59E0B` 琥珀金 | `#F59E0B` 金色 | 铜钱/灵石 | 灵石获得、交易、掉落 |
| **事件** | `#22C55E` 翠竹绿 | `#22C55E` 翠绿 | 卷轴/信笺 | 奇遇、任务更新、剧情触发 |

- 通知背景：`#111827E0`（深靛蓝，88% 不透明度）
- 文字颜色：`#F0F0F0`（暖白）
- 底部计时条：使用对应类型色，从 100% 宽度缩至 0%，表示 2 秒倒计时

### 1.4 动画

| 阶段 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| **入场** | 从右侧滑入（translateX: 100px → 0）+ 轻微弹性缩放（1.0→1.05→1.0） | 0.3s | ease-out |
| **驻留** | 静止显示，计时条匀速缩短 | 2.0s | linear |
| **消失** | 淡出 + 缩小至 scale 0.8 + 右移 30px | 0.25s | ease-in |
| **堆叠联动** | 新 Toast 出现时，旧 Toast 下移 72px | 0.2s | spring |

### 1.5 交互

- **Hover：** 暂停计时条，显示完整文字（支持超长文本截断展开）
- **点击：** 立即关闭
- **防刷屏：** 连续同类型通知合并显示——首条消失后同类型下一条才出现
- **键盘：** 无焦点交互（纯被动通知）

## 二、HUD 仪表盘

### 2.1 功能概述

玩家实时状态仪表盘，位于屏幕左下角。展示修真核心数值：境界、生命、灵力、灵石、灵韵、双魂状态。

### 2.2 布局规格

| 属性 | 值 |
|------|-----|
| 定位 | 左下角，距左边缘 20px，距下边缘 20px |
| 面板宽度 | 300px |
| 面板背景 | `#0A0F18CC`（深空蓝黑，88% 不透明） |
| 面板边框 | 1px `#334155`，左上角传统云纹装饰（5% 透明度） |
| 内部间距 | 各元素之间 8px 间隔，左右内边距 12px |

### 2.3 元素排列

```
┌──────────────────────────────────┐
│         当前境界：筑基初期          │  ← 境界栏
│  ████████████████░░░░░░░░  62%   │  ← 修炼进度条
├──────────────────────────────────┤
│  ♥  2340 / 3400                  │  ← 血条
│  ████████████████████░░░░░       │
├──────────────────────────────────┤
│  ✦  1560 / 2000                  │  ← 灵力条
│  ████████████████░░░░░░░░░       │
├──────────────────────────────────┤
│  ◆  灵石：12,450                  │  ← 灵石计数器
├──────────────────────────────────┤
│  ◉  灵韵：78%                     │  ← 环形弧指示器
├──────────────────────────────────┤
│  ◉◉ 双魂：阳魂（活跃）│ 阴魂（沉寂）│  ← 双球并排
└──────────────────────────────────┘
```

### 2.4 各元素详细设计

#### 2.4.1 境界栏

| 属性 | 值 |
|------|-----|
| 布局 | 左侧标签"当前境界"，右侧境界名称 |
| 标签文字 | "当前境界"，色值 `#8899AA`，字号 9pt |
| 境界名称 | 如"筑基初期"，色值 `#FBBF24` 金色，字号 15pt bold |
| 进度条 | 2px 高，底色 `#1A1A2E`，填充 `#FBBF24` 金色 |
| 可突破提示 | 达到突破条件时，金色脉动发光动画（1.5s 周期） |

#### 2.4.2 血条

| 属性 | 值 |
|------|-----|
| 底色 | `#1A0A0A` |
| 填充 | 渐变 `#EF4444 → #DC2626`（朱砂红至深红） |
| 高度 | 16px，圆角 3px |
| 图标 | 左侧 16×16 心形图标 |
| 数值文字 | 居中："2340 / 3400"，色值 `#F0F0F0`，字号 11pt |
| 受伤动画 | 整条闪烁白边（0.1s × 2 次），血量平滑过渡 0.3s |
| 危险提示 | 生命 ≤ 30% 时，红色缓慢脉动（2s 周期） |

#### 2.4.3 灵力条

| 属性 | 值 |
|------|-----|
| 底色 | `#0A0A2A` |
| 填充 | 渐变 `#3B82F6 → #6366F1`（天青蓝至靛蓝） |
| 高度 | 14px，圆角 3px |
| 图标 | 左侧莲花/元气图标 |
| 数值文字 | 居中格式同血条 |
| 满灵力提示 | 蓝光呼吸效果（2s 周期，opacity 0.7→1.0） |

#### 2.4.4 灵石计数

| 属性 | 值 |
|------|-----|
| 展示 | 图标 + 文字："灵石：12,450" |
| 文字样式 | 色值 `#FBBF24` 金色，字号 12pt semibold |
| 获得动画 | 数字逐位递增（每位 0.1s），金色闪光粒子飞出 |
| 失去动画 | 短暂红色着色 + 抖动 0.2s |

#### 2.4.5 灵韵

| 属性 | 值 |
|------|-----|
| 展示 | 240° 环形弧指示器 + 百分比文字 |
| 弧颜色 | `#14B8A6` 青绿色 |
| 文字 | "灵韵 78%"，字号 11pt |
| 满值提示 | 100% 时全弧发光 + 涟漪扩散动画（3s 周期） |

#### 2.4.6 双魂状态

| 属性 | 值 |
|------|-----|
| 展示 | 两个直径 20px 圆球并排，间距 8px |
| 阳魂（活跃） | 色值 `#A78BFA` 紫色，脉冲呼吸动画（2s 周期） |
| 阴魂（沉寂） | 色值 `#F472B6` 粉色，半透明 `#F472B680` 静置 |
| 切换动画 | 当前魂缩小淡出（0.2s），目标魂放大淡入（0.25s），中间漩涡粒子过渡 |

### 2.5 响应式行为

- **宽屏（>1920）：** 面板右上角可扩展小地图
- **窄屏（<1280）：** 数字精简显示（如 12.4k），可配置卷轴收起

## 三、对话 Panel

### 3.1 功能概述

NPC 交互的核心视觉呈现。底部居中弹出式面板，包含 NPC 头像、NPC 名称、打字机效果对话文字、选项按钮。

### 3.2 布局规格

| 属性 | 值 |
|------|-----|
| 定位 | 底部居中，距下边缘 40px |
| 面板宽度 | 70% 屏宽（min 480px, max 900px） |
| 面板背景 | `#0B1120D9`（深空蓝黑，85% 不透明） |
| 面板边框 | 顶边 2px `#4ADE80` 翠绿装饰线，其余三边 1px `#334155` |
| 圆角 | 8px（顶部两角） |

### 3.3 布局结构

```
┌───────────────────────────────────────────────────────────┐
│  ┌──────────┐  [NPC 名称 · 称号]                         │
│  │          │  ─────────────────────────────────────────  │
│  │ NPC 头像 │  "对话文字对话文字对话文字对话文字对话文字    │
│  │ 100×100  │   对话文字对话文字对话文字对话文字"          │
│  │ 圆形遮罩 │                                              │
│  │          │  ▸ [1] 选项一                                │
│  │          │  ▸ [2] 选项二                                │
│  │          │  ▸ [3] ◆ 选项三（◆ = 重要选择）            │
│  └──────────┘                                              │
└───────────────────────────────────────────────────────────┘
```

### 3.4 NPC 头像

| 属性 | 值 |
|------|-----|
| 形状 | 圆形遮罩 |
| 尺寸 | 直径 100px |
| 边框 | 2px，颜色随 NPC 情感变化 |
| 边框色映射 | 中性 = `#FBBF24` 金色 / 敌对 = `#EF4444` 红色 / 友善 = `#4ADE80` 绿色 |
| 呼吸待机 | 轻微缩放 0.98→1.02，4s 周期 |
| 说话动画 | 随重音轻微上下浮动 |

### 3.5 对话文字区

| 属性 | 值 |
|------|-----|
| NPC 名称 | 18px bold；重要 NPC = `#F0E6C5` 暖金色，普通 NPC = `#C0C0C0` 灰白 |
| 名称下分割线 | `#334155` 1px |
| 对话正文 | 16px，色值 `#E8E0D8`（暖白护眼），行高 1.6 |
| 最大行数 | 超过 4 行时自动上滚，底部渐隐遮罩 |

### 3.6 文字揭示动画（打字机效果）

| 属性 | 值 |
|------|-----|
| 速度 | 每字 30ms 逐字出现 |
| 跳过 | 点击或按 Space/Enter 瞬间显示当前句子全部文字 |
| 句子间隔 | 0.3s 停顿 |
| 多句逻辑 | 若当前句子已全部显示，点击直接进入下一句 |

### 3.7 选项按钮

| 状态 | 样式 |
|------|------|
| **默认** | 背景 `#1E293BCC`，边框 `#475569` 1px，文字 `#C0C8D0` 15px |
| **Hover** | 背景 `#334155`，边框发光 `#3B82F6`，文字 `#FFFFFF` |
| **已选** | 边框改为 `#4ADE80` 翠绿，左侧 +4px 实心色条 |
| **不可用** | 灰色 `#6B728050`，不可点击 |

- 按钮尺寸：高度 40px，宽度自适应（min 200px）
- 热键：`[1]` `[2]` `[3]` `[4]` 对应键盘数字键
- 重要选项标记：◆ 字符 + 金色光泽
- 5 个以上选项时：增加滚动，底部渐变遮罩
- 排列：垂直堆叠，左对齐

### 3.8 完整动画序列

| 阶段 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| **面板入场** | 从下方上滑 30px + 淡入 | 0.35s | ease-out |
| **头像入场** | 从左侧滑入 + 淡入（延迟 0.1s） | 0.3s | ease-out |
| **文字揭示** | 逐字打字机效果 | 30ms/字 | — |
| **选项入场** | 逐个从底部 10px 弹入 + 淡入 | 间隔 0.05s | spring |
| **面板退场** | 淡出 + 下移 20px | 0.25s | ease-in |
| **跳过** | 文字瞬间填满，下一句/选项弹入 | 0.1s | — |

### 3.9 退出

- **ESC：** 关闭对话面板（相当于"结束对话"）
- **选项选择：** 选完后自动关闭或进入下一轮对话

## 五、UI Manager 集成要点

### 5.1 事件分发

```
GameEvents（游戏逻辑层）
    │
    ▼
UIManager（调度中心）
    ├── Toast 通知系统（右上角）
    ├── HUD 仪表盘（左下角）
    └── 对话 Panel（底部居中）
```

### 5.2 优先级与遮挡

| 场景 | Toast | HUD | 对话 Panel | 遮罩层 |
|------|-------|-----|-----------|--------|
| 自由探索 | 可见 | 可见 | 隐藏 | 无 |
| 对话中 | 30% 不透明 | 可见 | 可见 | `#00000040` 全屏 |
| 战斗中 | 可见 | 可见 | 隐藏 | 无 |
| 事件触发 | 可见 | 可见 | 可能弹出 | 按需 |

### 5.3 与现有系统关系

- 现有 UI Manager 框架做 Panel 注册、开关和生命周期管理
- Toast / HUD / Dialogue 各为独立子系统，各自管理内部状态
- 数值驱动：HUD 数值由 PlayerStats 系统推送，不直接轮询
- 对话内容由 NPC Dialogue Tree 系统提供，Panel 仅做渲染
