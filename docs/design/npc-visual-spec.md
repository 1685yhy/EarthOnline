# NPC视觉规范 — Primitive角色设计

> 项目：地球Online（Earth Online）
> 引擎：团结引擎 1.9.3 (Unity 2022.3)
> 风格：低多边形修真风，仅用 Cube / Sphere / Cylinder 三种Primitive组合
> 2026-07-11

---

## 一、差异化规则总纲

### 1.1 颜色规则

| 维度 | 规则 | 取值 |
|------|------|------|
| **肤色** | 4个色阶标识年龄/劳作程度 | Pale(#E8D5C4) / Fair(#F0E0C8) / Tan(#C4A882) / Weathered(#8B7355) |
| **衣色主调** | 19色轮盘，同场景NPC主色至少相差60度色相 | 见各NPC条目 |
| **修为印记** | 高阶修士(金丹+)衣色饱和度+0.2，凡人/低阶饱和度-0.2 | 基准0.5，±0.2 |
| **道德暗示** | 正直NPC用暖色(红/黄/棕)，阴险NPC用冷色(紫/蓝/灰) | 色相关系 |
| **双魂标记** | 双魂系NPC在配饰中带紫色(#7B68AE)小元素 | 腰带/发饰/挂件一处即可 |

### 1.2 体型规则

| 维度 | 层级 | 取值 |
|------|------|------|
| **身高** | 3级 | 矮(0.8x) / 中(1.0x) / 高(1.2x) |
| **体宽** | 3级 | 瘦(0.7x) / 中(1.0x) / 壮(1.3x) |
| **姿态** | 3种 | 挺拔 / 放松 / 佝偻 |
| **综合** | 同屏NPC不得重复"身高+体宽+姿态"组合 | 自动检查 |

### 1.3 Primitive上限

| 优先级 | NPC数量 | Primitives上限 |
|--------|---------|----------------|
| **重要NPC** | 5 + 3双魂 = 8个 | ≤ 10个 |
| **普通NPC** | 10个 | ≤ 5个 |

### 1.4 计件规则

```
每个GameObject Primitve = 1件
包括：身体、头、四肢、服装配件、头饰、武器、装饰品、光环
不包括：眼球(color=white的小球不计入上限，仅属视觉细化)
```

## 七、实现指引

### 7.1 CharacterBuilder扩展

现有 `CharacterBuilder.BuildNPC(name, skinColor, clothColor, role)` 已支持6种角色类型：
`elder / merchant / guard / healer / warrior / peasant`

**建议扩展方向：**

1. 新增 `role` 类型：
   - `female_scholar` (苏念雪类型)
   - `master` (玄清真人/天玄子类型)
   - `drunkard` (陈玄默类型)
   - `child` (小药童类型)

2. 新增参数 `BuildNPC(name, skinColor, clothColor, accentColor, role, posture)`：
   - `posture` = `straight | relaxed | hunched | tilted`
   - 控制身体整体旋转/倾斜

3. 保留原有6种角色类型不变，新角色类型追加。

### 7.2 材质建议

- 所有Primitive使用Standard Shader
- 衣物材质：Emission强度 0.05（微光，非自发光效果）
- 修为光环：Sphere + Standard Shader半透明(alpha=0.1) + Emission(亮度0.3~0.6)
- 修真者（有修为印记的NPC）统一加蓝色/紫色半透明光环
- 化神期（玄清真人）：光环亮度加倍，色温偏金

### 7.3 命名规范

```
NPC_[角色英文名] → 根GameObject
   ├── Torso (Cube)
   ├── Head (Sphere)
   │   ├── Eye_L (Sphere)      // 不占额度
   │   ├── Eye_R (Sphere)      // 不占额度
   │   └── [头饰配件]
   ├── LeftArm (Cylinder)
   ├── RightArm (Cylinder)
   ├── LeftLeg (Cylinder)
   ├── RightLeg (Cylinder)
   ├── [服装配件]
   ├── [武器/道具]
   └── Aura (Sphere)            // 不占额度
```

### 7.4 碰撞器规则

- 所有视觉Primitive的Collider必须移除（`DestroyImmediate`）
- NPC主体保留 `CharacterController`（已有）
- 交互范围由 `NPCBase.interactionRange` 控制，不依赖碰撞体
