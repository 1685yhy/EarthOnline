## 1. 经济设计总纲

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **每日净盈余** | 活跃玩家日净收入 = 修为/5（灵石），随境界提升线性增长 |
| **通货膨胀锚** | 灵石产出 ≈ 灵石消耗 × 1.05（5%温和通胀，激励活跃） |
| **灵石/灵韵隔离** | ConvertToEssence 10:1 保持不变，修炼消耗走灵韵通道 |
| **境界门槛递增** | 每境修炼总成本 ≈ 上一境 × 3 |
| **新玩家追赶** | 前7天有加速保护，30天可追平初始差距 |
| **PVP/PVE分流** | 击杀掉落以材料为主，灵石主要来自任务/签到/领地 |

### 1.2 经济周期设计

```
┌─────────────────────────────────────────────────────────────┐
│                   日经济循环 (24h 游戏时间)                    │
├─────────────┬──────────────────┬────────────────────────────┤
│  收入构成    │  固定收入          │  浮动收入                   │
│  ─────────  │  ─────────        │  ─────────                  │
│  签到(10%)  │  领地税收          │  击杀掉落/出售              │
│  任务(25%)  │  签到基础          │  随机事件                   │
│  出售(20%)  │  固定任务奖励      │  市场波动差价               │
│  击杀(15%)  │  境界奖励          │  金手指产出                 │
│  领地(10%)  │                    │                            │
│  事件(20%)  │                    │                            │
└─────────────┴──────────────────┴────────────────────────────┘
```

## 2. 灵石获取速度

### 2.1 境界-日收入曲线

核心公式（每日净灵石收入基准）：
```
日净收入 = 境界系数 × 10 + (玩家等级 × 2)

境界系数：
  凡人期    = 1
  练气期    = 2
  筑基期    = 3
  金丹期    = 5
  元婴期    = 8
  化神期    = 12
  渡劫期    = 18
  大成期    = 25
```

### 2.2 各收入渠道产出率

#### 2.2.1 签到系统（保底收入）

| 连续天数 | 基础奖励(灵石) | 占日收入比(练气) | 占日收入比(金丹) |
|---------|---------------|-----------------|-----------------|
| 1 | 10 | 33% | 14% |
| 2 | 20 | 67% | 29% |
| 3 | 30 | 100% | 43% |
| 4 | 50 | 167% | 71% |
| 5 | 80 | 267% | 114% |
| 6 | 120 | 400% | 171% |
| 7 | 200 | 667% | 286% |

> **断签惩罚**：超过48小时未签到 → 连续天数归零
> **7日循环**：签到天数=8时重置为第1天奖励(10)，但累计总奖励保持
> 实际上我们改为**周重置**：每周一第7天拿到200后，下周从10开始。

## 3. 灵石消耗速度

### 3.1 消耗渠道总览

灵石消耗分三大类：
1. **修炼转化**（灵石→灵韵）：核心消耗，占比~60%
2. **购买消耗品**：占比~20%
3. **领地/势力投资**：占比~15%
4. **其他**（传送/罚款/复活手续费）：占比~5%

### 3.2 修炼转化消耗（核心消耗）

#### 每日修炼消耗上限

为了控制"土豪玩家一夜间耗尽资源"，修炼转化有每日上限：

| 境界 | 每日最大转化(灵石→灵韵) | 每日最大灵韵获取 |
|-----|----------------------|----------------|
| 凡人 | 100灵石 → 10灵韵 | 10 |
| 练气 | 200灵石 → 20灵韵 | 20 |
| 筑基 | 400灵石 → 40灵韵 | 40 |
| 金丹 | 800灵石 → 80灵韵 | 80 |
| 元婴 | 1500灵石 → 150灵韵 | 150 |
| 化神 | 2500灵石 → 250灵韵 | 250 |
| 渡劫 | 4000灵石 → 400灵韵 | 400 |
| 大成 | 6000灵石 → 600灵韵 | 600 |

> **设计理由**：日转化上限 ≈ 日收入的150%-200%，确保玩家有盈余但不会过度囤积
> **瓶颈控制**：修炼速度 = min(灵韵存量, 每日上限, 修为增长公式)

#### 境界总修炼成本

| 境界(从→到) | 所需总灵韵 | 所需总灵石 | 按日上限所需天数 |
|------------|----------|-----------|----------------|
| 凡人→练气 | 50 | 500 | 5天 |
| 练气→筑基 | 200 | 2000 | 10天 |
| 筑基→金丹 | 800 | 8000 | 20天 |
| 金丹→元婴 | 2500 | 25000 | 31天 |
| 元婴→化神 | 6000 | 60000 | 40天 |
| 化神→渡劫 | 15000 | 150000 | 60天 |
| 渡劫→大成 | 40000 | 400000 | 100天 |

> **注意**：以上为理论最大速度（满额每日转化），实际玩家因灵石收入限制
> 修炼周期会比理论值长30%-50%

### 5.3 市场供需波动机制

当前已有的 `MarketSystem` 基础上增强：

**价格计算公式**（保留现有逻辑，增强参数）：
```
实际价格 = 基准价 × (1 + 稀缺系数 × 需求系数 × 波动幅度)
稀缺系数 = 1 - (当前库存 / 最大库存)
需求系数 = 物品基础需求 + 当日修正

波动范围：基准价 × (1 ± 波动幅度)
```

**每日波动逻辑**：

| 影响因素 | 效果 | 刷新频率 |
|---------|------|---------|
| 玩家购买量 | 库存↓ → 价格↑ | 实时 |
| 玩家出售量 | 库存↑ → 价格↓ | 实时 |
| NPC补货 | 每天补充20%最大库存 | 每日 |
| 随机事件 | 相关商品价格±20% | 事件期间 |
| 区域控制 | 领地所有者享有±10%价差 | 持续 |
| 名声影响 | 善名→低价，恶名→高价 | 持续 |

### 5.4 制作配方经济合理性

**配方经济公式**：
```
制作成本 = Σ(材料基准价 × 数量) + 制作手续费(总成本×10%)
制品价值 = 制作成本 × (1 + 利润率)
推荐利润率：R=20%, SR=35%, SSR=50%
```

需要验证的几个关键配方：

- 萌新期：NPC商店8折
- 过渡期：NPC商店9折

**4. 领地保护**
- 萌新期：不可被其他玩家抢夺领地
- 过渡期：被抢夺概率降低50%

**5. 竞技保护**
- 练气期以下不可被高境界玩家攻击
- 筑基期以下PVP失败不损失灵石
