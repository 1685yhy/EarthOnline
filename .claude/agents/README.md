# 地球Online — 48 Agent 游戏工作室

按 Claude Code Game Studios 模板构建的三层 Agent 架构。

## 总监层 (Director)
- creative-director: 创意总监 — 整体愿景、网文穿越体验一致性
- technical-director: 技术总监 — 架构、性能、Unity/Tuanjie优化
- producer: 执行制作人 — 进度管理、资源调配、里程碑

## 部门负责人 (Department Lead)  
- lead-engineer: 主程 — Unity C#, EventBus, MCP集成
- lead-designer: 主策 — 战斗/经济/修炼数值平衡
- lead-artist: 主美 — 视觉风格、4K标准、特效审核
- lead-narrative: 叙事总监 — 主线/反派/金手指故事线
- lead-audio: 音监 — BGM/SFX/Narration方案执行
- lead-qa: QA总监 — 测试计划、bug追踪、性能验证

## 专家层 (Specialist)
- combat-designer: 战斗策划 — 修真战斗手感、连击系统
- economy-designer: 经济策划 — 灵石/灵韵/市场平衡
- npc-designer: NPC策划 — 对话树、记忆系统、羁绊
- quest-designer: 任务策划 — 主线/支线任务链
- level-designer: 关卡策划 — 地图设计、区域规划
- ui-designer: UI设计师 — UIManager、HUD、交互反馈
- vfx-artist: 特效师 — 灵击弹道、命中爆发、境界突破
- character-artist: 角色美术 — 模型、材质、发光分级
- environment-artist: 场景美术 — Terrain、粒子、氛围
- audio-designer: 音频设计 — 38音频文件方案执行
- narrative-writer: 文案 — 物品故事、NPC对话、世界文本
- backend-engineer: 后端 — 多人预留、存档、数据
- tools-engineer: 工具 — Editor脚本、CharacterBuilder
- gameplay-tester: 游戏测试 — 黑盒测试、平衡验证
