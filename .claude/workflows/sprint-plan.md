# 开发冲刺流程

## 每日检查
1. creative-director 审查最新推送 → 确认方向是否偏离
2. lead-qa 运行全量编译+play模式测试
3. producer 更新进度追踪

## 每版本流程
1. creative-director 提出V2.x目标
2. lead-designer + lead-engineer 拆解为具体任务
3. 专家层 Agent 并行领取任务
4. lead-qa 验证 → lead-designer 审查 → lead-engineer 代码审查
5. producer 确认完成后合并

## 角色分配
- 代码实现: tools-engineer + lead-engineer
- 内容设计: quest-designer + npc-designer + economy-designer
- 视觉音频: vfx-artist + character-artist + audio-designer
- 质量控制: lead-qa + gameplay-tester
